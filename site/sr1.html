要重建的是什麼

一顆腫瘤不是一群一模一樣的細胞。它從一個細胞開始，一邊分裂一邊累積 somatic 變異somatic variant 體細胞變異在非生殖系細胞譜系中、通常於受精後取得的變異；可只存在於部分細胞，通常不由親代遺傳給子代。癌症基因體學常分析此類變異。A variant acquired outside the germline, usually after conception. 這些群之間有先後關係：某一群是從另一群長出來的。 把「誰從誰長出來」畫成圖，就是一棵樹 —— 節點是一群細胞，邊代表「在祖先已有的變異之上，又多拿到一個」。 這棵樹叫 clone treeclone tree 克隆演化樹描述腫瘤內各群細胞祖先關係的樹：節點是一群帶有相同變異組合的細胞，邊代表在祖先之上又多拿到變異。要注意同一組群集常常有多棵樹同時相容。A tree describing ancestral relationships among cell populations in a tumour: nodes are groups of cells sharing a mutation set, edges represent additional mutations acquired on top of an ancestor. Multiple trees are often compatible with the same clusters.完整條目 →，它就是這兩頁要重建的東西。

難處在圖的中間那一格。我們手上沒有那棵樹，也沒有任何一顆完整的細胞： bulk 定序把所有細胞打碎混在一起，交給我們的只有片段與頻率。要從那裡把樹推回來。

為什麼值得重建

  • 用藥 —— 兩個可標靶的變異若在同一群細胞裡，一種藥可能同時打到； 分在兩群就不行。這正是 M0 開頭那個問題。
  • 抗藥 —— 治療後長回來的，通常是原本就存在的某一小群。 知道有哪些群、各佔多大，才知道要防的是哪一群。
  • 時序 —— 最早發生的那個變異，往往就是驅動這顆腫瘤長起來的那一個。

M9 已經做過一次，只是規模很小

M9 用兩個位點示範過整件事：細胞只會多拿到變異、不會退回去， 所以狀態從 00 變成 10 再變成 11； bulk read 在這兩個位置上就是一個 0／1 向量； 重建就是在狀態方格上，找一條從 00 出發、每一步只翻一個位元、 能走到所有觀測狀態而且步數最少的樹。

這兩頁做的是同一件事放大 —— 從兩個位點放大到幾千個變異， 從一個區域放大到整個基因體。放大之後會冒出兩個在小規模看不到的問題， 而這兩頁就是在處理那兩個問題。

概念與互動

這條路線的四個轉折

先看整條路怎麼走過來的。四個轉折各自解決了前一階段的一個問題， 也各自留下新的問題給下一階段。

第一步：把一堆變異的頻率畫成一張圖 —— mutation frequency spectrum

假設你手上有一份腫瘤樣本、幾千個 somatic 變異，每一個都有自己的 VAFVAF 變異等位基因頻率在某個位點上，支持 alt allele 的 read 佔全部 read 的比例。VAF 不等於帶有這個突變的細胞比例。Variant Allele Frequency: the fraction of reads supporting the alternate allele. Not the same as the fraction of cells carrying it.完整條目 →。 把這幾千個 VAF 畫成直方圖，會得到一張有結構的圖 —— 這張圖叫 mutation frequency spectrummutation frequency spectrum 突變頻率譜把一份樣本裡所有 somatic 變異的 VAF 畫成直方圖後得到的分布。分布上的峰與肩對應不同大小的細胞群，最低頻端的尾巴斜率則被用來判斷有沒有天擇。The distribution obtained by histogramming the VAFs of all somatic variants in a sample. Not necessarily a deletion.完整條目 → 的區段 —— 因為只有那裡的 VAF 好解釋。PyClone（2014）改成用 Dirichlet process（不必預先固定群數的分群模型）對 「帶有這個變異的細胞比例」分群，把 拷貝數copy number 拷貝數某段基因體在細胞內的拷貝數。多數正常常染色體區段為 2，可再分為 major 與 minor allele copy number。How many copies of a genomic segment a cell carries; a typical diploid autosomal segment has two. It can be split into major- and minor-allele copy numbers.完整條目 →與正常細胞混入一起放進模型。 PhyloWGS（2015）再往前一步，把分群與建樹合成同一個推論。

2016 年有人問了不一樣的問題：不去分群，直接看分布的形狀。 機制是這樣的：腫瘤指數成長時，越早發生的變異會出現在越多細胞裡，而這樣的變異本來就越少。 把「出現在至少 f 這個比例以上的變異」數出來，這個累積數量在中性演化下正比於 1/f —— 所以累積曲線對 1/f 作圖是一條直線。 在 14 種癌別、904 個腫瘤裡，有 323 個符合這條直線。

兩件事很容易搞錯，要特別分清楚。 第一，直線是累積曲線的性質，不是直方圖的性質 —— 直方圖本身的形狀是 1/f²（累積曲線的微分），直接量直方圖的斜率會得到錯的指數。 第二，原始研究刻意只在 VAF 0.12 到 0.24 這一段擬合： 更低頻的一端混著假陽性，更高頻的一端已經進入 clonal 峰。

後續研究指出符合中性的比例可能被高估 —— driver 變異的頻率天生偏向 0 與 1 兩端，很難在中間頻率被抓到， 所以「這條線是直的」不等於「沒有天擇」。

從 VAF 到 CCF：分母要自己湊出來

上面說的分群，其實不是對 VAF 分群，而是對 CCFcancer cell fraction 癌細胞比例帶有某個特定突變的腫瘤細胞佔全部腫瘤細胞的比例。用來區分 clonal（≈1）與 subclonal（<1）突變。不等於 VAF。The fraction of tumour cells carrying a given mutation; distinguishes clonal from subclonal. Not the same as VAF.完整條目 → 分群。 理由 M8 講過：VAF 是「帶變異的 read 佔多少」，CCF 是「帶變異的癌細胞佔多少」，兩者差一段換算。

所以頻率路線的第一層不確定性，來自換算：CCF 是三個估計值的商， 而三個都可能錯。這一層在 M8 已經標成「重要區分 #3：VAF 不等於 cancer cell fraction」。

群集之後：clone tree 還是不唯一

假設換算完全正確，得到三群變異，CCF 分別是 1.0、0.6、0.3。 現在要把這三群排成一棵 clone treeclone tree 克隆演化樹描述腫瘤內各群細胞祖先關係的樹：節點是一群帶有相同變異組合的細胞，邊代表在祖先之上又多拿到變異。要注意同一組群集常常有多棵樹同時相容。A tree describing ancestral relationships among cell populations in a tumour: nodes are groups of cells sharing a mutation set, edges represent additional mutations acquired on top of an ancestor. Multiple trees are often compatible with the same clusters.完整條目 → —— 誰是誰的祖先。

可用的約束只有一條，它是純粹的算術：一群細胞不可能比它的祖先還多。 所以子節點的 CCF 不能超過父節點；如果一個節點有兩個子節點，兩個子節點的 CCF 之和也不能超過它。

被卡住的時候，方法必須引入額外的偏好。最常用的偏好是 簡約parsimony 簡約法在所有與資料相容的解裡，選步數（或成本）最少的那一個。它是一個偏好而不是證據 —— 當多個解並列時，簡約法決定選哪一個，但資料本身沒有排除其他解。Choosing, among all solutions compatible with the data, the one requiring the fewest steps or lowest cost. It is a preference rather than evidence: when several solutions tie, parsimony picks one, but the data has not ruled the others out.完整條目 →： 在所有相容的樹裡選步數最少的那一棵。這是一個很合理的偏好 —— 但它是偏好，不是證據。 有時候為了讓樹連得起來，還必須補進沒有被任何資料直接支持的中間狀態， 這種節點叫 latent nodelatent node 潛在節點建樹時為了讓圖連得起來而補進的中間狀態，沒有被任何 read 直接觀測到。它是模型的產物，不能當成「還沒觀察到的細胞」。An intermediate state added during tree construction to keep the graph connected, not directly observed in any read. It is a product of the model and must not be read as an unobserved cell population.完整條目 →。

用兩個位點就看得到它為什麼一定會出現。假設你只觀測到 00 與 11 兩種狀態 —— 沒有任何一條 read 是 10，也沒有任何一條是 01。 但一步只能加一個突變，所以從 00 走到 11 中間必須經過 10 或 01。方法只能補一個進去，而它補的那個是 「模型為了連通而假設的」，不是看到的。

所以 latent node 讀起來要很小心：它不是「一群還沒被觀察到的細胞」。 它可能對應真的中間世代（那群細胞後來被取代了），也可能只是這個模型的記帳需要。 而且這裡有兩個並列的補法（補 10 或補 01），資料同樣沒辦法選。

重要區分 #11：頻率群集不等於 clone tree

看到一張「腫瘤演化樹」圖時，要分清楚圖上有兩種東西： 群集（有幾群、每群多大）與樹（誰是誰的祖先）。

群集比樹穩定一些，但也只是一些 —— 同一份資料換一個程式， 連 subclone 的數量都可能不一樣，而且真實的 subclone 越多、樣本有 whole-genome doubling 時， 程式越傾向少報。

樹更糟 —— 同一組群集常常有多棵樹同時相容，是方法用簡約性或其他偏好挑了一棵。 多數工具只輸出那一棵，不告訴你另外幾棵也成立。

所以「這棵樹顯示 A 發生在 B 之前」這種說法，強度取決於相容的樹有幾棵。 只有一棵時它是結論；有五棵時它是選擇。這也是本頁開頭那場評比中， 換程式就換答案的直接原因。

根因：頻率是 marginal distribution，樹要的是 joint distribution

上面兩層不確定性看起來是兩個獨立的麻煩，其實是同一個。用兩個位點就講得完。

一個區域裡有兩個 somatic 位點 S1、S2。頻率告訴你的是兩個數字： S1 出現在 50% 的細胞裡、S2 出現在 30% 的細胞裡。 這兩個數字各自描述一個位點，這樣的分布叫 marginal distributionmarginal distribution 邊際分布只描述單一變數的分布。VAF 與甲基化 β 值都是邊際統計：它們各自只講一個位點有多少比例帶有標記，不講兩個位點在同一個分子或同一個細胞上的搭配情形。A distribution over a single variable. VAF and methylation beta values are both marginal statistics: each describes one site in isolation and says nothing about how two sites co-occur on the same molecule or cell.完整條目 →。

但樹要回答的問題是：同時帶有 S1 與 S2 的細胞佔多少？ 這是兩個位點一起看的分布，叫 joint distributionjoint distribution 聯合分布多個變數一起看的分布，也就是「哪些組合各出現多少」。演化樹的形狀取決於聯合分布，而不是邊際分布；長讀的價值在於一條分子上的組合是直接觀測到的。A distribution over several variables jointly, i.e. how often each combination occurs. Tree topology depends on the joint distribution, not the marginals; the value of long reads is that combinations on one molecule are observed directly.完整條目 →。 而從邊際分布推不出聯合分布 —— 這不是統計技巧不夠，是資訊真的不在裡面。

精確一點說，邊際不是完全沒有用，它給出一個區間： 同時帶有兩者的比例最多不會超過 0.30（不可能比帶 S2 的還多）， 最少也不會低於 0.50 ＋ 0.30 − 1 ＝ 0（兩者可以完全不重疊）。 所以邊際把答案夾在 0 到 0.30 之間，然後就再也縮不動了。 而樹的形狀在這個區間的兩端完全不同。

現在回頭看前面兩層不確定性，它們是同一件事的兩個面： CCF 換算是在估計邊際，簡約性是在猜聯合。 短讀路線的每一個模型假設，都是在補聯合分布那一格。

甲基化也有同一個病：β 值與 epiallele

既然序列上的頻率不夠，換一種標記會不會好一些？甲基化5mC 5-甲基胞嘧啶胞嘧啶第 5 個碳上的甲基化修飾。這是常見的 DNA 甲基化形式，主要見於 CpG；可影響轉錄調控，效應依基因組位置與細胞類型而異。5-methylcytosine, the commonest DNA methylation mark, usually at CpG sites. Affects expression without changing sequence.完整條目 →是很自然的候選。

先講它為什麼吸引人。epimutationepimutation 表觀突變細胞分裂時甲基化狀態的隨機翻轉。文獻常引的量級是每個 CpG、每次分裂 10⁻⁵ 到 10⁻⁴，而 DNA 突變約每鹼基 10⁻⁹ 到 10⁻¹⁰，同量級對比約差五個數量級，所以甲基化是解析度更高的譜系時鐘。要注意這個速率隨位點與量測方式差異很大（有估到 10⁻³ 的），應當成量級而非定值。A stochastic flip of methylation state during cell division. Commonly cited at 10⁻⁵–10⁻⁴ per CpG per division versus 10⁻⁹–10⁻¹⁰ per base for DNA mutation — roughly five orders of magnitude faster like-for-like — which makes it a higher-resolution lineage clock. Treat it as an order of magnitude, not a constant: estimates vary by site and assay, up to ~10⁻³.完整條目 →（甲基化狀態的隨機翻轉）發生的速率， 文獻常引的量級是每個 CpGCpG序列上一個 C 後接一個 G（p 代表兩者之間的磷酸鍵）。哺乳類多數 5mC 位於 CpG，特定細胞或情況亦可見非 CpG 甲基化。A cytosine followed by a guanine. 這個速率要當成量級而不是常數：它隨位點與量測方式差很多， 專門被挑出來當時鐘用的位點有估到 10⁻³ 這個量級的。 所以「甲基化快得多」很穩，但「快幾個數量級」不要當定值引用。

這個想法已經走到規模化。2015 年一項研究拿 19 位低度膠質瘤病人的原發與復發檢體， 各自用甲基化與用突變建樹，兩棵樹高度吻合（相關係數 0.56 到 0.90）， 說明甲基化攜帶的譜系訊號是真的 —— 但那是「高度吻合」而不是「同一棵樹」， 研究裡也有病人的甲基化訊號跨越了基因型上已經分開的分支。 2025 年的一項研究更進一步：只用 bulk 甲基化資料，在 1,976 個淋巴系癌樣本上推估出 腫瘤的生長速率與發生年齡，不需要定序基因體。

但是甲基化的常規讀法有一模一樣的病。一個 CpG 位點的甲基化程度寫成 β 值 —— 這個位點上所有分子中，甲基化的比例。那也是一個邊際。

重要區分 #12：兩群 epiallele 不一定是兩群細胞

上圖右邊那種「一群全甲基、一群全不甲基」的乾淨分裂，最直覺的解讀是兩群細胞。 但同一群細胞的兩條 haplotype 也會產生完全一樣的圖形 —— 一條甲基化、另一條不甲基化。這件事有名字，叫 allele-specific methylation， 在 imprinting 的區域是常態而非例外。

怎麼分開？把 epiallele 的分群跟 HP tagHP tagBAM 裡標示某條 read 屬於哪一條 haplotype 的 tag。LongPhase-S 的 germline haplotag 寫成整數 HP:i:1；somatic haplotag 與 LongPhase-TO 則寫成字串 HP:Z:1-1。BAM tag assigning a read to a haplotype. Integer HP:i:1 for germline haplotag; string HP:Z:1-1 for somatic.完整條目 → 對一下： 兩群剛好對上 HP1 與 HP2 → 是同一群細胞的兩條染色體； 兩群都落在同一個 HP 裡 → 才是兩群細胞。

這正是為什麼這條路線把甲基化放在單倍型家族之內看，而不是直接看整個位點。 少了這一步，最常見的生物現象會被讀成 subclone。

2014 年的 methclone 就是在做這件事：它從 read 直接數 epiallele 的組成， 再用組成的熵變化量去衡量兩個時間點之間譜系結構的改變。

它的要求值得看清楚，因為那是整類做法都躲不掉的形狀，只是每個工具挑的數字不同。 methclone 要求一條 read 跨過 4 個相鄰的 CpG（於是有 2⁴ ＝ 16 種可能組合）， 並且該位置要有 60× 以上的深度，組成的比例才估得準。 換句話說，你需要的是「同一條分子上有足夠多的 CpG，而且這樣的分子要足夠多」—— 4 是 methclone 的選擇，不是自然常數。

但狀態表的每一列是分子，不是細胞 —— 這件事很容易讀錯。 一個細胞的兩條染色體會產生兩條不同 haplotype 的 read，同一條染色體也可能被多條 read 覆蓋。 所以「狀態 11 有 6 條 read」不等於「有 6 個細胞同時帶有兩個變異」。 這是 M0 那個「read 是分子片段的觀測，不是細胞標籤」的警告，在這條路線上的具體後果。

代價：分析單位變成「區域 × 單倍型家族」

聯合觀測不是免費的。它只在一條 read 跨得到的距離內成立。 兩個位點如果相距 100 kb，沒有任何一條 read 同時蓋到它們， 那兩個位點之間的聯合分布就跟短讀時代一樣是未知的。

這件事的量級可以自己算一遍，算完就知道為什麼 k 幾乎都是 2 或 3。 一般實體腫瘤的突變負荷大約每 Mb 有 1 到 10 個 somatic 變異。 取 5 個／Mb、read 跨距 20 kb，那麼一個區域裡的變異數平均是 0.1 個。 用 Poisson 算「至少有 2 個」的機率是 0.5% 左右 —— 3.1 Gb 切成 15 萬多個區域，只有幾百個區域夠格。

還要再打一個折。分析單位是「區域 × 單倍型家族」， 所以兩個變異不只要落在同一個區域，還得落在同一條 haplotype 上，才湊得成 k＝2 的狀態表。 一對變異落在同一家族的機率大約是 ½，於是 0.5% 再減半到 0.24%。

但突變負荷高的樣本完全是另一回事。同樣的算法，50 個／Mb 時平均是 1 個／區域， 「至少有 2 個」的機率跳到 26%，打完家族那個折之後仍有兩三萬個可用單位。 所以這條路線的可用性直接綁在樣本的突變負荷上 —— 這不是參數調整能改變的。

read-AF：頻率沒有被丟掉，只是換了位置

最後要說明一件容易誤會的事：長讀路線並沒有拋棄頻率。 頻率從「用來分群」變成「用來在並列的候選裡排序」。

M8 提過這個量叫 read-AFread-AF read 層級的 ALT 比例在同一個分析區域、同一個單倍型家族的 read 之中，某個 somatic 位點帶 ALT 的比例。分母已限縮到同一條 haplotype 的同一段區域，所以不必經過純度與拷貝數換算；用途是在步數並列的候選樹之間排序。The fraction of reads carrying the ALT allele at a somatic site, computed within one analysis window and one haplotype family. Because the denominator is already restricted, no purity or copy-number correction is needed; it is used to rank candidate trees of equal cost.完整條目 →：在同一個區域、同一個單倍型家族的 read 裡面， 某個 somatic 位點的 ALT 佔多少。它跟全基因體 VAF 的差別是分母被限縮了 —— 只算同一段區域、同一條 haplotype 的 read。

這裡要講清楚一件很容易講錯的事：限縮分母並沒有讓純度消失。 同一條 haplotype 的 read 裡面也有來自正常細胞的分子（它們在這個位點是 REF）， 所以 read-AF 大約是「純度 × 帶有這個變異的腫瘤細胞比例」，不是後者本身。 read-AF 之所以不必換算，是因為它只被拿來比大小：同一個區域、同一個單倍型家族裡的 兩個位點共用同一個純度，比較兩者時純度是共同因子，會被約掉。 M8 已經把這件事列為方法的適用範圍限制 —— 兩個位點的局部拷貝數或 multiplicity 若不同，就約不掉。

用法很直接：先發生的變異應該出現在更多分子上。 所以候選樹裡若有兩條路徑步數相同，read-AF 遞減的那一條更合理。 關鍵是順序：先用聯合觀測把候選集合縮到最小成本解，再用 read-AF 排序。 反過來做就會退回頻率路線的老問題 —— 用邊際去猜聯合。

那這條路線的「頻率譜」長什麼樣？

要比較兩條路線，得先注意一件事：前面那些既有做法，沒有一個是在單一位點上做推論的。 SciClone、PyClone、PhyloWGS 都是把幾千個變異的 VAF 堆成一張直方圖， 再從那張圖的形狀讀出結論；1/f 中性檢定量的也是同一張圖的尾巴。 所以該比的是頻譜這一層，不是「一個位點看得準不準」。

長讀這一側也有一張頻率譜，做法完全一樣 —— 一樣把整批數字堆成直方圖，橫軸一樣是頻率。 換掉的只有被數的那個東西：不再是「一個位點的 ALT 佔多少」， 而是「一條單倍型佔多少分子」。單倍型就是 somatic haplotagging 給的那些標籤 （HP1、HP1-1、HP1-2…），每一條代表一組變異的特定組合。

換掉之後，兩張圖會長得不一樣 —— 而且不一樣的地方剛好就決定了樹。 用同一組 SNV 看。先看原始的 read，這樣後面兩張圖的每一個數字都追得回來：

左邊：六個 SNV 各給一個 VAF。A、B、C 都是 0.35，D、E、F 都是 0.20， 堆成兩根高度為 3 的長條。讀出來是「有兩群，各佔 0.35 與 0.20」—— 但這兩個數字同時相容於兩棵樹（0.20 ≤ 0.35 ✓；0.35 ＋ 0.20 ≤ 1 ✓），所以分不出來。 這跟前面那組 1.0／0.6／0.3 是同一件事。

右邊：三條單倍型各給一個頻率，每根長條高度都是 1。兩件事跟著出現：

  • 0.45 那一根，左邊根本畫不出來。那群細胞在這個區域沒有任何 somatic 變異 —— 沒有變異就沒有 VAF。可是它是這個區域裡最大的一群，而且它正是另外兩群的祖先。 VAF 頻率譜看得到後代，看不到祖先。
  • 標籤帶著隸屬關係。HP1-1 與 HP1-2 都直接掛在 HP1 底下，是兄弟不是祖孫。 而這件事是從 read 上數出來的（沒有分子同時帶 A B C 與 D E F），不是猜的。 於是分支那棵樹是唯一解。

所以差別可以講得很精確：左邊每一根長條數的是「變異」，右邊數的是「細胞群」； 左邊的頻率是邊際，右邊的頻率帶著隸屬關係。 同一組 SNV，換掉頻率的單位之後，連樹的形狀都跟著定下來了。

一個技術細節要先講清楚，否則兩張圖不對等：左邊那種圖通常是全基因體的 （幾千個位點全丟進去），這裡畫的是一個區域。要做成全基因體的版本， 就是把每個區域各自算出來的單倍型頻率全部倒進同一張直方圖 —— 標籤是區域性的（跨區域的 HP1-1 並不是同一條，重要區分 #13 就是這件事的極端版本）， 但頻率值可以匯總。

所以這條路線要問的是一個很具體的問題： 把頻率的單位從單一位點換成多位點的單倍型，重建出來的樹會不會不一樣？ 上面那個例子說會。而因為同一顆腫瘤兩種都算得出來，這件事可以直接比 —— 下篇講的就是本實驗室的實作怎麼把這些單倍型頻率取出來，以及它現在卡在哪裡。

三條路線各自看得到什麼

最後這一點值得停一下，因為它決定了這條路線該用來回答什麼問題。 它不產出「這個腫瘤有 4 個 subclone、佔比分別是多少」這種全域結論。 它產出的是幾萬筆局部陳述，每一筆的形式是 「在這個區域、這條 haplotype 上，這幾個變異的先後順序有哪些候選」。

而 M0 那個用藥問題正好是局部的：兩個變異在不在同一群細胞裡。 這種問題只需要那兩個位點附近的聯合分布，不需要整棵樹。

先提出預測，再查看解答

一份腫瘤樣本，換算後得到三群 somatic 變異，CCF 分別是 1.00、0.55、0.40。 請問：CCF 0.40 那一群，是 CCF 0.55 那一群的後代，還是它的兄弟？

展開答案

分不出來，而且不是資料量不夠的問題。

兩種解都通過那條算術檢查：當後代時 0.40 ≤ 0.55 ✓；當兄弟時 0.55 ＋ 0.40 ＝ 0.95 ≤ 1.00 ✓。 如果程式只給你一棵樹，那棵樹是它的偏好（通常是簡約性）挑出來的，不是資料挑出來的。

要真正分開，需要的不是更多變異、也不是更深的定序， 而是另一種資訊：同時帶有這兩群變異的細胞佔多少。 這是聯合分布，而 CCF 是邊際分布。

怎麼拿到？三條路。single-cell 直接在細胞層級觀測共現。 多個時間點或多個部位取樣可以縮小可能的樹的數量 —— 兄弟關係在不同部位常有不同比例，後代關係則同步變化。 長讀在兩群變異剛好落在同一條 read 跨距內時，直接數出聯合計數。 注意第三條有條件：兩群變異必須夠近。距離 100 kb 的話，長讀也幫不上。

答案比直覺短很多。一個單位的有效樣本數不是它的總 read 數， 而是「每一個位點對各自有幾條 read 同時蓋到」—— 在本實驗室既有實作的真實輸出裡，一個 194 條 read 的單位， 三個位點對的跨越深度分別是 20、17 與 3，而那棵樹的三個祖先關係就是由這三個數字決定的。 下篇從這件事出發，指出三個要改的地方。

本模組術語

5mC（5-甲基胞嘧啶）
胞嘧啶第 5 個碳上的甲基化修飾。這是常見的 DNA 甲基化形式，主要見於 CpG；可影響轉錄調控，效應依基因組位置與細胞類型而異。
CpG
序列上一個 C 後接一個 G（p 代表兩者之間的磷酸鍵）。哺乳類多數 5mC 位於 CpG，特定細胞或情況亦可見非 CpG 甲基化。
HP tag
BAM 裡標示某條 read 屬於哪一條 haplotype 的 tag。LongPhase-S 的 germline haplotag 寫成整數 HP:i:1；somatic haplotag 與 LongPhase-TO 則寫成字串 HP:Z:1-1。
LOH（異型合子性喪失）
原本 heterozygous 的區域變成只剩一種 allele。LOH 不等於缺失 —— 也可能是一條 haplotype 遺失後另一條被複製（copy-neutral LOH）。
VAF（變異等位基因頻率）
在某個位點上，支持 alt allele 的 read 佔全部 read 的比例。VAF 不等於帶有這個突變的細胞比例。
cancer cell fraction（癌細胞比例）
帶有某個特定突變的腫瘤細胞佔全部腫瘤細胞的比例。用來區分 clonal（≈1）與 subclonal（<1）突變。不等於 VAF。
clone（克隆）
源自共同祖先細胞，並共享一組可辨識 somatic mutations 的細胞群。
clone tree（克隆演化樹）
描述腫瘤內各群細胞祖先關係的樹：節點是一群帶有相同變異組合的細胞，邊代表在祖先之上又多拿到變異。要注意同一組群集常常有多棵樹同時相容。
copy number（拷貝數）
某段基因體在細胞內的拷貝數。多數正常常染色體區段為 2，可再分為 major 與 minor allele copy number。
epiallele（表觀等位型）
同一條分子上一組相鄰 CpG 的甲基化組合，例如四個 CpG 的 1101。逐位點的 β 值看不到它 —— 要算 epiallele 的組成，一條 read 至少得跨過 4 個 CpG。
epimutation（表觀突變）
細胞分裂時甲基化狀態的隨機翻轉。文獻常引的量級是每個 CpG、每次分裂 10⁻⁵ 到 10⁻⁴，而 DNA 突變約每鹼基 10⁻⁹ 到 10⁻¹⁰，同量級對比約差五個數量級，所以甲基化是解析度更高的譜系時鐘。要注意這個速率隨位點與量測方式差異很大（有估到 10⁻³ 的），應當成量級而非定值。
haplotype（單倍型）
同一條實體染色體拷貝上，具有一致相位的一組 alleles 或 variants。HP1 與 HP2 是任意的相對標籤。
joint distribution（聯合分布）
多個變數一起看的分布，也就是「哪些組合各出現多少」。演化樹的形狀取決於聯合分布，而不是邊際分布；長讀的價值在於一條分子上的組合是直接觀測到的。
latent node（潛在節點）
建樹時為了讓圖連得起來而補進的中間狀態，沒有被任何 read 直接觀測到。它是模型的產物，不能當成「還沒觀察到的細胞」。
long read（長讀）
單條可達數千至數萬鹼基的定序片段（例如 ONT、PacBio）。若可靠地同時覆蓋多個 variant，可提供它們位於同一 DNA 分子上的直接觀測證據。
marginal distribution（邊際分布）
只描述單一變數的分布。VAF 與甲基化 β 值都是邊際統計：它們各自只講一個位點有多少比例帶有標記，不講兩個位點在同一個分子或同一個細胞上的搭配情形。
mutation frequency spectrum（突變頻率譜）
把一份樣本裡所有 somatic 變異的 VAF 畫成直方圖後得到的分布。分布上的峰與肩對應不同大小的細胞群，最低頻端的尾巴斜率則被用來判斷有沒有天擇。
mutation multiplicity
在帶有某突變的細胞中，該突變所占的拷貝數；是 VAF 與 cancer cell fraction 換算時的重要參數。
parsimony（簡約法）
在所有與資料相容的解裡，選步數（或成本）最少的那一個。它是一個偏好而不是證據 —— 當多個解並列時，簡約法決定選哪一個，但資料本身沒有排除其他解。
phase block
一段可建立連續相位關係的區域。read 長度不足、缺少 informative heterozygous 位點或證據不一致時，可能形成不同 phase blocks。
read-AF（read 層級的 ALT 比例）
在同一個分析區域、同一個單倍型家族的 read 之中，某個 somatic 位點帶 ALT 的比例。分母已限縮到同一條 haplotype 的同一段區域，所以不必經過純度與拷貝數換算；用途是在步數並列的候選樹之間排序。
somatic haplotype
在 germline haplotype 之下再細分出來的層級。某條 HP1 的 read 若帶有 somatic 突變，就屬於 HP1-1；HP2 的則是 HP2-1。無法判定來源的歸為 HP3。
somatic variant（體細胞變異）
在非生殖系細胞譜系中、通常於受精後取得的變異；可只存在於部分細胞，通常不由親代遺傳給子代。癌症基因體學常分析此類變異。
subclone（次克隆）
clone 內取得額外變異並擴增的子群；治療後可能富集具有抗性的 subclone。
tumour purity（腫瘤純度）
樣本中腫瘤細胞所佔的比例。purity 越低，somatic 訊號被正常細胞稀釋得越嚴重，偵測越困難。
