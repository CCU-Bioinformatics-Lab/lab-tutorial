Somatic variant calling：tumor–normal 與 tumor-only

說明配對正常樣本提供的個體基線，以及 tumor-only 分析在 germline 與技術性 artifact 判斷上的限制。

約 55 分鐘建議先修：Phasing

本模組學習目標

  • 說明配對正常樣本提供了什麼，以及沒有它時失去什麼
  • 區分本教材使用的 PON 與 GATK 語境中的 PoN，並說明兩者的限制
  • 解釋 TINC 為什麼會讓直接以 tumor／normal VCF 差集判定的直覺失效
  • 以一句話概括 tumor-only calling 的核心困難
  • 說明 copy number 如何影響 VAF，並以簡化 triplet graph 示範分子連結證據

為什麼重要

本模組比較兩種分析設計：有配對正常樣本的 tumor–normal（TN）模式， 以及只有腫瘤樣本的 tumor-only（TO）模式。是否有 matched normal 會改變可用的對照證據與不確定性。

差異不只是少一個輸入檔案；它會改變可辨識的變異類型與後續判讀方式。

沒有正常樣本的時候

在部分臨床或研究情境，matched normal 可能因成本、檢體量或取得條件而缺失。 此時可採用 tumour-onlytumour-only 僅腫瘤只有腫瘤樣本、沒有配對正常樣本。在成本或檢體受限時很常見，但少了 germline 對照，分析難度會大幅提高。Having only the tumour sample. Common for cost or specimen reasons, but much harder without a germline baseline.完整條目 →（TO）分析，但可用的 germline 對照較少。

沒有正常組織時，改用什麼當對照

替代方案可使用公開的族群資料庫，利用 allele frequency 與已知變異紀錄提供 germline 線索。 符合指定頻率、品質與 annotation 條件的候選可作為排除依據，但不能無條件排除資料庫中的所有項目。

TN calling 的實務限制

前述 TN 流程是簡化描述；實務上不能只以兩個 VCF 的差集判定 somatic。

重要區分 #6：matched-normal calling 不是把兩個 VCF 相減

以下因素都可能使直接差集判定失準：

  • TINCTINC 腫瘤污染正常樣本Tumour-in-normal contamination：配對正常樣本含有腫瘤來源訊號，使 genuine somatic 變異也可能在 normal 中被觀察到，因而可能被錯誤過濾。Tumour-in-normal contamination: tumour cells present in the matched normal, causing true somatic variants to produce signal there as well.完整條目 →（tumour-in-normal contamination）—— matched normal 中存在腫瘤來源訊號。 真正的 somatic 變異可能在 normal 中呈現低頻支持；若採用「normal 有訊號即排除」的規則，可能誤刪候選。
  • coverage 不對等 —— 若 normal coverage 較低（例如約 25×），somatic 變異在 normal 中未被觀察到， 可能只是深度不足，不代表它不存在。
  • copy numbercopy number 拷貝數某段基因體在細胞內的拷貝數。多數正常常染色體區段為 2，可再分為 major 與 minor allele copy number。How many copies of a genomic segment a cell carries; a typical diploid autosomal segment has two. It can be split into major- and minor-allele copy numbers.完整條目 → 造成的 allelic imbalance —— 讓 VAF 偏離預期，判斷門檻要跟著調。
  • caller 本身的不確定性 —— 兩邊的 caller 都可能漏掉或多報。

第一項可用下圖示意，提醒 paired normal 仍可能因污染而誤判：

VAF 可作為輔助訊息：簡單 diploid heterozygous germline 變異常接近 0.5，污染訊號可能較低； 但實際值取決於 purity、copy number、zygosity、multiplicity、clonality 與 depth。 因此不能只用「有沒有訊號」或固定門檻判定。

即使有配對正常樣本，仍需要結合多項品質與模型過濾條件。

一句話總結

tumor-only 的核心困難

配對正常樣本提供病人的 germline 對照；population database set 主要提供族群層級的 germline 證據。未涵蓋的 private germline 或尚未觀察到的 artifact 可能保留為額外候選，其中部分會成為 false positive，需結合其他證據判讀。

資料庫無法涵蓋所有個體特異變異，因此可加入 read-level phase／連結結構、 copy number、LOH 與品質等補充證據。在理想化的 triplet graphtriplet graphLongPhase-TO 用來評估 candidate 的局部結構：取候選點與左右兩個 germline 位點，觀察三個位置的 allele 組合如何由 reads 連結。在此方法的判定規則中，三位點可提供兩位點模型缺少的辨識資訊。LongPhase-TO's structure for judging a candidate: the candidate plus two flanking germline sites, and how their alleles link across reads.完整條目 → 示例中，這些資訊可能呈現 不同 pattern；但系統性 artifact 或 phasing error 仍可能造成例外，因此此結構只能作為補充證據，不能單獨定案。

展開答案

VAF 約 0.5 且未被族群資料庫涵蓋時，可優先考慮 private germline， 但不能排除 somatic 或其他來源。

在簡化的 diploid、單拷貝模型下，somatic VAF 可近似為 purity／2； 較一般的模型還受 purity、multiplicity 與 total copy number 影響，並會受到 normal DNA、 clonality、mapping bias 與 depth 影響，因此不能單獨依 VAF 分類。

應再檢查 read-level phase／連結結構、copy number、LOH、品質與獨立證據。 triplet graphtriplet graphLongPhase-TO 用來評估 candidate 的局部結構：取候選點與左右兩個 germline 位點，觀察三個位置的 allele 組合如何由 reads 連結。在此方法的判定規則中，三位點可提供兩位點模型缺少的辨識資訊。LongPhase-TO's structure for judging a candidate: the candidate plus two flanking germline sites, and how their alleles link across reads.完整條目 → 中的三種 pattern 是理想化示例，實務資料未必能完全區分， 系統性 artifact 或 phasing error 也可能造成例外。

本模組術語

ClairS
配對 tumor–normal 的 somatic variant caller。tumor-only 版本叫 ClairS-TO。
DeepSomatic
Google 的 somatic variant caller，同樣有 tumor-only 版本。
PON（正常樣本面板／族群資料庫（依流程而異））
PON 依分析流程有兩種用法，兩者不可互換：本教材的 tumor-only 流程以它指稱 population germline database set（如 1000G、CoLoRSdb、dbSNP、gnomAD 的聯集）；GATK Mutect2 的 Panel of Normals（PoN）則由多個正常樣本建立，用來標記反覆出現的技術性 artifact。兩者都不能完全取代同一病人的 matched normal。
TINC（腫瘤污染正常樣本）
Tumour-in-normal contamination：配對正常樣本含有腫瘤來源訊號，使 genuine somatic 變異也可能在 normal 中被觀察到，因而可能被錯誤過濾。
candidate（候選變異）
caller 提出、但尚未被確認的變異位點。本實驗室多數工具位於 caller 之後，進行再校正，處理的就是這些 candidates。
copy number（拷貝數）
某段基因體在細胞內的拷貝數。多數正常常染色體區段為 2，可再分為 major 與 minor allele copy number。
germline variant（生殖系變異）
在生殖系形成、通常存在於多數細胞的變異；可遺傳給子代，但不代表必然傳遞。
precision（精確率）
所有 calls 中實際為真陽性的比例：TP / (TP + FP)。後處理常以提升此指標為目標。
somatic variant（體細胞變異）
在非生殖系細胞譜系中、通常於受精後取得的變異；可只存在於部分細胞，通常不由親代遺傳給子代。癌症基因體學常分析此類變異。
triplet graph
LongPhase-TO 用來評估 candidate 的局部結構：取候選點與左右兩個 germline 位點，觀察三個位置的 allele 組合如何由 reads 連結。在此方法的判定規則中，三位點可提供兩位點模型缺少的辨識資訊。
tumour-normal（配對腫瘤／正常）
同時定序病人的腫瘤與正常組織；正常樣本提供個體 germline 背景，有助於辨識 somatic 候選。
tumour-only（僅腫瘤）
只有腫瘤樣本、沒有配對正常樣本。在成本或檢體受限時很常見，但少了 germline 對照，分析難度會大幅提高。
