模組 4 · Data literacy

資料格式讀寫能力

從 BAM 中的 read 觀測追溯到 VCF 紀錄，並使用 CIGAR 解碼器練習讀取對齊資訊。

約 60 分鐘建議先修：定序

本模組學習目標

  • 說出從 FASTQ 到 VCF 的每一個中間檔案各自負責什麼
  • 判讀一個 CIGAR 字串，並說出它消耗了多少參考序列與多少 read
  • 解釋 soft clip 是什麼，以及為什麼大量集中的 clipping 可作為結構變異斷點的候選訊號
  • 在 VCF 裡認出 GT、PS，並在 BAM 裡認出 HP 與 MM/ML tag
  • 區分一般 untagged read 與帶有 somatic signal 但來源未定的 somatic haplotype HP3

為什麼重要

CIGARCIGAR描述一條 read 如何對上參考基因體的緊湊字串。例如 5M1I5M 表示兩端各有 5 個對齊欄位，中間有 1 個相對於參考序列的插入；M 可能代表吻合，也可能代表錯配。A compact string describing how read bases and reference positions are consumed by an alignment. For example, 5M1I5M has five alignment columns, one insertion, then five alignment columns; M may contain matches or mismatches.完整條目 → 在正式課程中常被簡略帶過，但在判讀比對結果與變異證據時十分重要。 本教材的兩個案例會使用 CIGAR：一個以 clipping 分布協助定位染色體結構變異的候選邊界， 另一個將 CIGAR 編碼為影像供神經網路分析。理解 CIGAR 有助於解讀這些流程的輸入與限制。

本節以互動解碼與命令列操作為主，實作比例較高。

概念與互動

從樣本到變異的檔案鏈

檔案裝什麼一筆記錄通常代表
.fastareference genomereference genome 參考基因體用於比對的標準序列（人類資料常用 GRCh38）。所有座標均相對於指定版本；更換 build 會改變座標系，座標不可直接比較。The standard sequence everything is aligned to. All coordinates are relative to it, so changing build changes coordinates.完整條目 →一條染色體或 contig 的序列
.fastqFASTQ存放 read 序列與每個鹼基品質分數的文字格式；每筆紀錄由四行組成。Text format holding read sequences plus per-base quality scores; four lines per record.完整條目 →定序儀產生的 read一筆 read 記錄（序列與品質）
.bamBAM已比對到參考基因體的 read 的二進位格式（SAM 的壓縮版）。每一列是一條 read，帶著它的位置、CIGAR、品質與各種 tag。Binary format for reads aligned to the reference. One record per read, carrying position, CIGAR, quality and tags.完整條目 →已比對到參考的 read一筆 alignment record，含位置、CIGAR、tag
.vcfVCF存放 variant 的文字格式。每一列是一個位點，記錄位置、ref/alt allele、品質、FILTER 與各種 FORMAT 欄位。Text format for variants: one line per site with position, ref/alt alleles, quality, FILTER and FORMAT fields.完整條目 →變異一個位點，含 ref/alt、FILTER、FORMAT
.bed區間一段 chrom / start / end

注意 BAM 與 VCF 的記錄單位不同：BAM 以 alignment record 為單位，VCF 以變異位點為單位。 後續模組會反覆使用此區分；例如 LongPhase-S 將 somatic haplotypesomatic haplotype在 germline haplotype 之下再細分出來的層級。某條 HP1 的 read 若帶有 somatic 突變，就屬於 HP1-1；HP2 的則是 HP2-1。無法判定來源的歸為 HP3。A sub-level beneath the germline haplotype: HP1-1 and HP2-1 carry somatic mutations derived from HP1 and HP2; HP3 is unassignable.完整條目 → assignment 寫在 BAM 的 read 上， 而 LongPhase-TO 將判定寫在 VCF 的位點上。

CIGAR：read 與參考序列的對齊表示

CIGAR 是一串「數字＋字母」，描述 read 與參考序列的對應關係。 可在下方元件輸入 CIGAR，查看各操作碼對參考序列與 read 的消耗方式。

操作碼意思消耗參考消耗 read
M對齊（可能吻合，也可能錯配）✓✓
Iinsertion：read 有、參考沒有✗✓
Ddeletion：參考有、read 沒有✓✗
Ssoft clipsoft clippingread 端部未與參考序列對齊，但序列仍保留在 BAM 中（CIGAR 為 S）。大量 clipping 集中於同一位置時，可能提示結構變異斷點，仍需其他證據確認。A read end that failed to align but is retained in the BAM (CIGAR S). Clipping clustered at one position may suggest a structural breakpoint and needs corroborating evidence.完整條目 →：read 保留但沒對上✗✓
Hhard clip：該段序列未保留在 BAM 的 read 序列中✗✗

一個常見的誤解：M 不代表「吻合」，它只代表「有對齊」。 錯配（mismatch）在 CIGAR 上仍然是 M。若要判定實際鹼基差異，需查看 MD tag 或直接比對參考序列。

soft clipping 的判讀意義

當 read 的一端無法可靠地與參考序列對齊時，比對演算法通常會將該端標記為 S（soft clipping）。序列本身仍保留在 BAM 中，但不計入對齊區段。

LongPhase-TO 如何利用 clipping 協助界定 CNV / BFB 區間

LongPhase-TO 會統計 clipping 在基因體上的分布：覆蓋度上升的位置可能累積左端 soft clipping， 下降的位置可能累積右端 soft clipping。一組上升與下降可形成事件區間候選， 但仍需結合覆蓋度、序列脈絡與其他證據，確認該區段是否與參考基因體不同。

此訊號可在不使用預先呼叫的變異資訊時，從 read 與參考序列的對齊模式取得結構變異候選；完整流程會在後續模組中說明。

真實證據

前處理指令示範

以下示範一組前處理流程；請依所用版本文件、輸入路徑與分析平台調整參數後執行。

# 參考基因體索引
samtools faidx reference.fasta

# 比對。--MD 會寫入 MD tag（某些下游工具需要）
minimap2 --MD -ax map-ont -t 10 reference.fasta reads.fastq -o alignment.sam

# 排序與索引
samtools sort -@ 10 alignment.sam -o alignment.bam
samtools index -@ 10 alignment.bam

重比對時保留甲基化 tag

如果 BAM 帶有 MM／ML（甲基化）tag，重比對時若未使用保留 tag 的選項， 流程可能不會保留這些 tag。要保留它們，請明確處理：

# -T '*' 把所有 tag 帶進 FASTQ 的 header
samtools fastq -T '*' methylcall.raw.bam > methylcall.raw.fastq

# -y 讓 minimap2 把 FASTQ header 裡的 tag 寫回 BAM
minimap2 -ax map-ont -y reference.fasta methylcall.raw.fastq

若漏掉 -T '*' 或 -y，流程可能不會報錯，但輸出 BAM 的 MM/ML 欄位可能為空。 請在重比對後檢查 tag 是否仍存在，避免將缺失的甲基化資訊誤認為生物學結果。

判讀練習

一條 read 的 CIGAR 是 60S40M，比對位置是 chr7:1,000,000。

這條 read 總共多長？它覆蓋了參考基因體的哪一段？

展開答案

read 長 100 bp（60 + 40，soft clip 的序列仍在 read 裡）。

但它只覆蓋參考的 chr7:1,000,000–1,000,039，也就是 40 bp。 因為 S 不消耗參考序列。

此 read 顯示前 60 bp 未與參考序列可靠對齊，從 1,000,000 開始才進入對齊區段。 若多條 read 都在 1,000,000 出現相同方向的 clipping，可將此位置列為結構變異斷點候選； 被剪序列也可能與低品質、重複序列或其他比對問題有關，需結合其他證據確認。

完整字串可能超出元件的顯示範圍；可輸入 10S8M 觀察相同的消耗規則。

實作練習

由 BAM 回溯 VCF 位點證據

此練習將 VCF 位點與 BAM 的 read-level 證據連結起來。挑選一個 VCF 變異，再回到 BAM 檢查其支持情況：

# 1. 從 VCF 挑一個位點
bcftools view -H sample.vcf | head -3

# 2. 回到 BAM 看那個位置上的每一條 read
samtools view aln.bam chr1:1000000-1000000

# 3. 用 pileup 直接看每條 read 在那個位置的鹼基
samtools mpileup -f reference.fasta -r chr1:1000000-1000000 aln.bam

# 4. 檢查該位置附近的 CIGAR 型式
samtools view aln.bam chr1:1000000-1000000 | awk '{print $6}' | sort | uniq -c | sort -rn

第 4 步可用來檢查對齊型式：若同一位置的 CIGAR 型式高度多樣，可能表示重複序列或 indel 對齊不確定， 應結合 mapping/base quality 與 pileup 謹慎評估；型式一致也不代表證據必然可靠。

判讀時先掌握一項核心規則：查看每個操作碼消耗哪一側的序列。I 與 S 只消耗 read，D 只消耗參考序列，M 兩側都消耗。

本模組術語

BAM
已比對到參考基因體的 read 的二進位格式（SAM 的壓縮版）。每一列是一條 read，帶著它的位置、CIGAR、品質與各種 tag。
CIGAR
描述一條 read 如何對上參考基因體的緊湊字串。例如 5M1I5M 表示兩端各有 5 個對齊欄位，中間有 1 個相對於參考序列的插入；M 可能代表吻合，也可能代表錯配。
FASTQ
存放 read 序列與每個鹼基品質分數的文字格式；每筆紀錄由四行組成。
HP tag
BAM 裡標示某條 read 屬於哪一條 haplotype 的 tag。LongPhase-S 的 germline haplotag 寫成整數 HP:i:1；somatic haplotag 與 LongPhase-TO 則寫成字串 HP:Z:1-1。
MM/ML tag
BAM 中儲存每條 read 甲基化判讀的兩個 tag：MM 記錄位置、ML 記錄機率。在轉換或重新比對流程中可能遺失，需確認 tags 是否保留。
PS tag（phase set）
標示某群 variants 屬於同一 phase block 的編號。同一 PS 內的相位方向可相互比較；不同 PS 的 HP1/HP2 方向彼此獨立。
VCF
存放 variant 的文字格式。每一列是一個位點，記錄位置、ref/alt allele、品質、FILTER 與各種 FORMAT 欄位。
genotype（基因型）
某個 locus 上觀察到的 allele 組合；對一般二倍體常染色體位點，通常是兩份 allele。VCF 裡寫成 0/1（未定相）或 0|1（已定相）。
reference genome（參考基因體）
用於比對的標準序列（人類資料常用 GRCh38）。所有座標均相對於指定版本；更換 build 會改變座標系，座標不可直接比較。
soft clipping
read 端部未與參考序列對齊，但序列仍保留在 BAM 中（CIGAR 為 S）。大量 clipping 集中於同一位置時，可能提示結構變異斷點，仍需其他證據確認。
somatic haplotype
在 germline haplotype 之下再細分出來的層級。某條 HP1 的 read 若帶有 somatic 突變，就屬於 HP1-1；HP2 的則是 HP2-1。無法判定來源的歸為 HP3。
