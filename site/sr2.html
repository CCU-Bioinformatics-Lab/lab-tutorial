研究指引 · Subclone 系統發生重建 · Part 2 — implementation

下篇：區域拓撲重建，以及它現在錯在哪裡

從本實驗室既有實作的真實輸出出發：一個單位的有效樣本數是「每一個位點對各自的跨越深度」，不是該單位的總 read 數。由此得到三項修正 —— 缺席要有檢定力撐著、類別比例要先扣掉覆蓋幾何、頻率該用來排序候選拓撲而不是拿去分箱。

建議先修：Subclone 重建

本模組學習目標

  • 說出 95% 與 5% 的區域各自貢獻什麼：一個定峰的位置，一個定峰之間的關係
  • 列出三種可以從多變異區域收出來的約束，以及每一種在全基因體重建裡各自解決什麼問題
  • 說明為什麼「兩群大小相同」在 VAF 頻率譜上是結構性盲點，而一條「不可同群」就能打破它
  • 說出為什麼假約束比沒有約束更糟，以及兩道品質閘門各自擋的是什麼
  • 算出在給定突變負荷下能收到幾條約束，並說明為什麼那個數量已經夠用

為什麼重要

這一頁的目標只有一個：把全基因體的 subclone 系統發生重建做得更好 —— 不是再多產出幾萬筆局部陳述。

上篇的結論給了一個不太舒服的起點。20 kb 視窗、每 Mb 5 個變異時， 含變異的區域有 95% 只有一個變異；那種區域裡「一條單倍型」就等於「一個變異」， 所以把標籤丟掉之後，單倍型頻率譜幾乎就塌回 VAF 頻率譜。 換句話說，頻率值本身不是這條路線的賣點。

但反過來看，剩下那 5% 給的東西性質完全不同：它給的不是更多資料點， 而是資料點之間的關係 —— 哪兩個變異不可能屬於同一群、哪一群是哪一群的祖先。 而關係不需要多：一棵 clone treeclone tree 克隆演化樹描述腫瘤內各群細胞祖先關係的樹：節點是一群帶有相同變異組合的細胞，邊代表在祖先之上又多拿到變異。要注意同一組群集常常有多棵樹同時相容。A tree describing ancestral relationships among cell populations in a tumour: nodes are groups of cells sharing a mutation set, edges represent additional mutations acquired on top of an ancestor. Multiple trees are often compatible with the same clusters.完整條目 → 要定的是群與群之間那幾個關係， 不是一萬五千個變異各自的歸屬。

而這一頁真正的出發點是下面這件事： 本實驗室現行的實作，其實已經在算右邊那一欄了。 它對每一個「區域 × 單倍型家族somatic haplotype在 germline haplotype 之下再細分出來的層級。某條 HP1 的 read 若帶有 somatic 突變，就屬於 HP1-1；HP2 的則是 HP2-1。無法判定來源的歸為 HP3。A sub-level beneath the germline haplotype: HP1-1 and HP2-1 carry somatic mutations derived from HP1 and HP2; HP3 is unassignable.完整條目 →」都判過是串接還是分岔 —— 那些判定就是約束，只是它們停在區域層級，從來沒有被送到全基因體那一層。

所以要做的事有兩件，順序不能顛倒：

  1. 把那些判定變得可信。直接拿現行輸出當約束會出事 —— 真實資料裡有相當比例的判定是在證據不足的情況下做出來的，而錯的約束比沒有約束更糟。
  2. 把它們接到全基因體的混合模型上。頻率定位置，約束定個數、寬度、比例與先後。

這一頁不是教材。它假設你讀完上篇，給的是式子、參數與失敗模式。 範圍限定在單倍型；甲基化只在最後出現一次，而且是當成解讀上限，不是一條資料通道。

概念與互動

一、5% 能做的三件事

用途一：打破一維上的簡併

VAF 頻率譜有一個結構性的盲點：兩群細胞如果佔的比例一樣， 它們在頻率軸上就是同一個點。這不是精度問題 —— 加深定序、增加變異數、 換更好的 caller 都沒有用，因為那個方向上的似然本來就是平的。

但只要有一對變異落在同一個區域、分屬那兩群，而且觀測到沒有分子同時帶兩者， 就得到一條硬約束：這兩個變異不可能屬於同一群。混合模型被迫把那根峰拆成兩個成分。 這是可辨識性的改變，不是精度的改變 —— 也是這條路線最強的一個論點。

用途二：直接量出「峰應該多寬」

這一項不需要任何假設，值得優先做。

在 VAF 頻率譜裡，一群的寬度 ＝ 生物學上的離散 ＋ 技術雜訊，兩者混在一起分不開。 但是同一條單倍型上的幾個變異，真實頻率完全相同 —— 它們就在同一批分子上，生物學離散恰好是零。 所以那幾個變異之間觀測到的離散度，就是純粹的技術雜訊，是量出來的，不是假設的。

按深度與拷貝數分層估出來，就得到一條經驗性的「點擴散函數」。 拿它去對全基因體的頻率譜做解卷積，峰會變窄 —— 峰變窄，本來被埋掉的小群就浮得出來。

用途三：不需要純度的相對位置

同一個單位裡兩條單倍型的比值與純度、拷貝數無關（第八節寫清楚為什麼）。 所以每一個巢狀對都直接給出「兩群的細胞比例之比」。 把這些比值匯總起來，群與群的相對位置就定下來了， 純度只剩下一個整體縮放因子的角色。

這把上篇說的第一層不確定性（換算需要純度、拷貝數與 multiplicitymutation multiplicity在帶有某突變的細胞中，該突變所占的拷貝數；是 VAF 與 cancer cell fraction 換算時的重要參數。How many mutant-allele copies are present in a cell carrying the mutation; a necessary term when converting VAF to cancer cell fraction.完整條目 → 三個估計值）降級成一個純量： 換算錯了，整排群一起平移，相對關係不變。

三、但約束不能照單全收

一個單位的有效樣本數不是它的總 read 數， 而是每一個位點對各自有幾條 read 同時蓋到。 上圖那個單位的三個位點對，跨越深度分別是 20、17 與 3 —— 而那個 n = 3 的位點對，照樣產出了一條約束。

假設那條譜系裡有三成的分子帶著某個狀態，三條 read 全部錯過的機率是 0.7³ ≈ 0.34。三分之一的機率會把「有」看成「沒有」 —— 而「沒看到」正是判定分岔的依據。也就是說，這條約束有三分之一的機率是假的。

六、兩個會讓約束整個錯掉的陷阱

重要區分 #14：trans 不等於分支演化

兩個變異若分別落在同一個細胞的兩條染色體拷貝上（trans）， 它們永遠不可能出現在同一條分子上。於是計數表會呈現 00、10、01，而 11 那一格是空的 —— 跟兩群互不包含的 subclone 長得一模一樣。 在約束的脈絡下這特別致命：它會產出一條假的「不可同群」， 而那是硬約束，會直接逼混合模型拆出一個不存在的群。 現行流程有先按單倍型家族分堆，這一點是對的 —— 而且相位讓 cis／trans 在 整個 phase block 內都是已知的，不是只在一條 read 之內， 所以這個陷阱的可解範圍比 read 跨距大約一百倍。

重要區分 #13：不同 phase block 的 H1 不是同一條染色體

相位軟體在每個 block 內把 read 分成兩堆並標上 H1、H2， 但標號在每個 block 內獨立決定。 好消息：約束談的是細胞的祖先關係，不是哪一條親源染色體帶著變異。 每條約束都在單一個單位內產生，所以它與標號方向無關 —— 核心推論不受影響。 壞消息：任何把不同 block 的 H1 加總在一起的判斷都沒有意義，而且不會有錯誤訊息。 所以不能用「兩個變異都在 H1 上」當成它們同群的理由 —— 跨 block 的 H1 根本不是同一條。 由此得到一條可以寫成檢查程式的規則： 每一條約束都必須在單一個單位內部產生，不得跨單位組合。

十、估計式：把約束餵進混合模型

混合模型本體不變：每個變異的頻率來自某一群，加上量測雜訊。約束以權重項進去：

ℒ= ∑m log⁢ P(fm∣ czm, PSF) + ∑r ωr⁢ log⁢ P(Rr∣z,T)

第一項是 95% 給的：每個變異的頻率 f_m 落在它所屬群的位置 c 上， 雜訊寬度由用途二量到的點擴散函數 PSF 決定 —— 那不是自由參數。 第二項是 5% 給的：每條約束 R_r 帶著信心權重 ω_r， 限制的是變異的群歸屬 z 與樹 T。

不可同群 (i, j)      →  z_i ≠ z_j
必定同群 (i, j)      →  z_i = z_j
祖先關係 (i → j)     →  T 上 z_i 是 z_j 的祖先，且 c[z_i] > c[z_j]
巢狀比值 ϱ(i, j)     →  c[z_j] / c[z_i] = ϱ        ← 不需要純度的相對位置

關鍵是權重而不是硬條件。閘門已經擋掉大部分假約束，但擋不乾淨； 把剩下的不確定性放進 ω_r，一條錯的約束只會被稀釋， 不會像硬條件那樣直接逼出一個不存在的群。

推論方式沒有特別之處：帶約束的 EM，或直接對 (T, c, z) 取樣。 輸出必須包含每個群配對是由幾條約束決定的 —— 沒有約束支持的關係就是靠偏好補的，要標出來。

三件要注意的事

第一，0.909 是目前最強的結果。一個換了 basecaller 還守得住、 又分得開癌別的統計量，帶的是真訊號。所以閘門加上去之後要重算這個數字： 守住或變好，代表閘門濾掉的是雜訊；垮掉，代表原本的 0.909 有一部分是共用的覆蓋幾何撐出來的。

第二，「分支類」的比例還不能直接當成約束產量。 分岔要被判出來，需要兩個單突變頂點都在、而且雙突變頂點的缺席是可信的 —— 第二件事就是閘門要查的。所以那 6%–22% 是上限，不是實際可用量。

第三，有一個記帳需要對一下。 各資料集的單位數加起來是 71,955，而結論裡引用的是 85,941。 兩個數字很可能在數不同的東西，但在寫成論文之前要先釘住。

預測與結果檢視

假設閘門調得很鬆，收到 5,000 條約束；調得很嚴，只剩 300 條。 直覺上約束越多，混合模型被限制得越死，結果應該越好。 請問：鬆的那一版會不會比較好？

展開答案

不一定，而且很可能更糟 —— 因為約束的兩種錯誤代價不對稱。

一條漏掉的約束，代價是「本來可以定下來的關係，現在要靠偏好補」—— 退回沒有這條路線之前的狀態，損失有限。

但一條錯誤的「不可同群」，代價是逼混合模型拆出一個不存在的群。 而且它不會自己露餡：拆出來的那個群有頻率、有變異、看起來完全正常。 下游的樹、演化順序、臨床解讀全部跟著錯，報告上不會有任何異常。

所以取捨不是「多 vs 少」，是「漏掉 vs 造假」，而兩者代價差很多。 正確的做法是寧嚴勿鬆，並且把剩下的不確定性放進權重 ω_r， 而不是當成硬條件 —— 一條被稀釋的錯約束不會單獨改變結論。

要怎麼知道調到哪裡？用重現性當外部檢查： 在不同 basecaller／不同機構的同一個細胞株上掃過一系列閘門嚴格度， 看哪一段的群與樹最一致。這不需要金標準 —— 而那正是這個領域最缺的東西。

實作練習

十二、先把逐對跨越深度算出來

這是所有後續步驟的前提，而且從現有的狀態表就算得出來，不必碰求解器：

python3 - <<'PY'
import itertools
from collections import Counter

# 一個單位的狀態表：(S1, S2, S3, read 數)，'-' 代表沒蓋到
rows = [("-","A","-",42), ("R","-","-",31), ("A","-","-",25), ("-","-","R",25),
        ("-","R","-",22), ("-","-","A",15), ("R","A","-", 9), ("-","A","A", 6),
        ("-","A","R", 6), ("A","R","-", 5), ("-","R","R", 5), ("R","A","R", 3)]
k = 3
total = sum(r[-1] for r in rows)

for i, j in itertools.combinations(range(k), 2):
    sub = [r for r in rows if r[i] != "-" and r[j] != "-"]
    n = sum(r[-1] for r in sub)
    pat = Counter()
    for r in sub:
        pat[r[i] + r[j]] += r[-1]
    # 這一對能不能產生約束，看的是 n，不是 total
    print(f"S{i+1}xS{j+1}: n={n:3d} ({n / total * 100:4.1f}%)  {dict(pat)}")
PY

要看的是逐對的 n 之間差多少。差一個數量級是常態 —— 而那代表這個單位產出的幾條約束，可信度完全不同。

十三、四個可以馬上做的分析

分析怎麼做會回答什麼
① 約束的實際產量 對每個單位算逐對跨越深度，套一組閘門門檻，數還剩幾條約束、分別是哪一種 把「6%–22% 的分支類」變成真正可用的數字。這是最該先做的一件事
② 分類是不是幾何造成的 把單位按中位跨越深度分層，畫每一層的分類組成 分支比例若隨跨越深度上升，現在的分類有一部分是假的，約束會跟著假
③ 排序偏誤抽掉了多少「不可同群」 把候選集合用「除以配對數」的分數重排，數分支類多出幾個 直接量出第五節那個偏誤讓我們損失了多少最稀缺的約束
④ 重現性撐不撐得住閘門 掃一系列閘門嚴格度，重算同細胞株跨機構的一致性 沒有金標準時，最實際的調參依據

十四、排查順序

症狀先查什麼
混合模型多出一個很小的群先查是不是某一條「不可同群」逼出來的。追回那條約束所屬的單位，看它的逐對跨越深度
約束幾乎全是「祖先關係」第五節那個排序偏誤。分支類被系統性地判成串接了
通過閘門的約束少得離譜視窗太寬。回到第十一節，改跑一輪窄視窗
某條染色體完全沒有約束看那個區域的突變間距。距離遠 → 跨越深度低 → 全被閘門擋掉，那是對的
兩個家族的結果系統性不對稱檢查是不是分開估了。標記錯誤率把兩個家族耦合起來，必須一起估
約束彼此矛盾先看不相容單位比例。矛盾多半來自單倍型標記錯誤，不是生物學

十五、還沒解決的問題

  • 整條路線都還沒有實測。上面每一項都有結構性的理由，但沒有一項在真實資料上驗證過。 最小的驗證是模擬：合成兩群比例相同的 subclone， 確認只用 VAF 的分群必定合併，再量出要幾條約束、閘門要多嚴，才拆得開而且不拆錯。
  • 點擴散函數那一項需要同一條單倍型上有多個變異，而那正是最稀缺的區域。 低突變負荷時可能根本估不出來。
  • 約束的來源有偏。它們只來自變異密集的區域，而 kataegis 一叢會貢獻大量 彼此高度相關的約束。要先偵測並降權成一叢一個有效觀測。
  • 一個群不見得只有一群細胞。本實驗室的甲基化觀測已經看到： 單一個「單倍型 ＋ 等位」狀態底下還分得出五群甲基化模式。 所以群數的正確讀法永遠是「至少這麼多」。
  • 跨 read 跨距的關係仍然看不到。相距 100 kb 的兩個變異產不出約束，不管定序多深。

本模組術語

clone tree（克隆演化樹）
描述腫瘤內各群細胞祖先關係的樹：節點是一群帶有相同變異組合的細胞，邊代表在祖先之上又多拿到變異。要注意同一組群集常常有多棵樹同時相容。
latent node（潛在節點）
建樹時為了讓圖連得起來而補進的中間狀態，沒有被任何 read 直接觀測到。它是模型的產物，不能當成「還沒觀察到的細胞」。
mutation multiplicity
在帶有某突變的細胞中，該突變所占的拷貝數；是 VAF 與 cancer cell fraction 換算時的重要參數。
parsimony（簡約法）
在所有與資料相容的解裡，選步數（或成本）最少的那一個。它是一個偏好而不是證據 —— 當多個解並列時，簡約法決定選哪一個，但資料本身沒有排除其他解。
phase block
一段可建立連續相位關係的區域。read 長度不足、缺少 informative heterozygous 位點或證據不一致時，可能形成不同 phase blocks。
read-AF（read 層級的 ALT 比例）
在同一個分析區域、同一個單倍型家族的 read 之中，某個 somatic 位點帶 ALT 的比例。分母已限縮到同一條 haplotype 的同一段區域，所以不必經過純度與拷貝數換算；用途是在步數並列的候選樹之間排序。
somatic haplotype
在 germline haplotype 之下再細分出來的層級。某條 HP1 的 read 若帶有 somatic 突變，就屬於 HP1-1；HP2 的則是 HP2-1。無法判定來源的歸為 HP3。
