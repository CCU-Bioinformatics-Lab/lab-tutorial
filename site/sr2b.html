下篇：完整的估計式，以及它能不能建起來

把三個用途合成一條聯合估計式，說明數百個形狀相異的局部拓撲如何合併；再回頭處理約束的來源、兩道品質閘門、兩類會產生假約束的誤讀，以及約束的實際產量。

建議先修：5% 能補的三格

本模組學習目標

  • 寫出把三個用途合起來之後的完整估計式，並說明其兩項各自約束哪些變數
  • 說明數百個單位的局部拓撲形狀相異為何不構成矛盾，以及真正的矛盾有哪三種形式
  • 指出現行實作的四種分類各自對應哪一種約束，以及「必定同群」為何須給最低權重
  • 說明兩道品質閘門各自排除的失效模式，以及假約束的代價為何高於缺少約束
  • 依 Poisson 模型算出給定突變負荷下的約束產量，並說明該數量為何足夠

為什麼重要

中篇確立了三件事：僅以 VAF 頻率譜重建時， 群數 K 不可辨識、峰寬 φ 與 K 不可區辨、 成分位置 c 依賴三個外部估計值； 而多變異區域的觀測正好各補一格，且三者作用在同一組變數 z、φ、c 上。

本頁做兩件事。其一，把三者合成一條估計式 —— 中篇說明的是每個用途作用在哪裡，本頁寫出合起來長什麼樣， 並處理一個中篇尚未碰的問題：數百個單位的局部拓撲形狀各不相同，它們如何合併。

其二，處理那條估計式能不能真的建起來。 第二項所需的約束 Rr 不是憑空取得的，它們來自現行實作對每個 「區域 × 單倍型家族somatic haplotype在 germline haplotype 之下再細分出來的層級。某條 HP1 的 read 若帶有 somatic 突變，就屬於 HP1-1；HP2 的則是 HP2-1。無法判定來源的歸為 HP3。A sub-level beneath the germline haplotype: HP1-1 and HP2-1 carry somatic mutations derived from HP1 and HP2; HP3 is unassignable.完整條目 →」（以下簡稱一個單位）的分類。 而直接採用那些分類會出事：真實輸出中有相當比例的判定是在證據不足下做出的， 錯誤的約束比缺少約束更為不利 —— 一條假的「不可同群」會迫使模型分出一個不存在的群， 且不留任何跡象。

因此本頁的順序是：先寫出估計式（第一節）， 再回頭處理約束的來源（第二節）、兩道品質閘門（第三、四節）、 兩類會產生假約束的誤讀（第五節）、權重（第六節）， 最後是產量與參數取捨（第七、八節）。

概念與互動

一、完整的估計式

中篇的三個用途各動一個參數：用途一約束 z、用途二把 φ 由待估改為代入、 用途三對 c 加一條等式。把三者疊加於中篇第一節那個混合式，即得此路線的完整形式：

ℒ(K,c,π,z,T)=∑mlog[πzm·BetaBin(am;dm,ρ·czm/2,φ^)]+∑rωr·logP(Rr∣z,T)
項來源與中篇第一節的差異
第一項95% 的區域（頻率） 即中篇第一節第二步，惟有兩處相異：z 不再被邊際化（∑k 已移除），改為受約束的對象；φ^ 不再是自由參數，由用途二量測後代入
第二項5% 的區域（關係） Rr 為第 r 條約束，ωr 為其信心權重

四種約束對應的形式為：

約束 Rr對估計式的形式備註
不可同群 (i,j)zi≠zj用途一，使 K 可辨識
必定同群 (i,j)zi=zj
祖先關係 (i→j)T 上 zi 為 zj 的祖先，且 c[zi]>c[zj]
巢狀比值 ϱ(i,j)c[zj]/c[zi]=ϱ用途三，不需純度

此處採加權而非硬性條件。第八、九節的閘門雖可排除多數假約束，但無法完全排除； 將殘餘的不確定性納入 ωr，單一條錯誤約束僅被稀釋， 而不致如硬性條件般直接迫使模型產生不存在的群。

推論方法為帶約束的 EM，或直接對 (T,c,z) 取樣。 輸出須載明每一組群配對由幾條約束支持； 未獲約束支持的關係係由 pigeonhole 與偏好補足，其狀態等同中篇第一節第四步，應予標示。

數百個單位的局部拓撲形狀不同 —— 這是預期，不是矛盾

中篇的說明均以單一個單位為例。實際上通過閘門的單位有數百個， 而它們的局部拓撲形狀各不相同：有的是一條線，有的是分岔，有的只有一個節點。 此現象本身不構成衝突。

成因是每個單位只裝得下落在該視窗內的那幾個變異。 上圖的單位甲裝到的是 B 群與 C 群的變異，兩群互不包含，故其局部拓撲是分岔； 單位乙裝到的是 B 群與 D 群的變異，後者巢狀於前者，故其局部拓撲是一條線。 兩者皆為同一棵全域 clone tree 在不同變異子集上的投影 —— 形狀相異是因為子集相異，而非證據衝突。

合起來為什麼更準、解析度更高

關鍵在於認清頻率譜的輸出並不是一棵樹，而是一棵部分決定的樹。 本例中它換算出三群（1.00/0.40/0.20），而這三群在 pigeonhole 之下 有兩棵樹同時通過：線性的 A → X → D，與分支的 A → {X,D}。 取兩棵的交集，才是頻率譜真正確定下來的東西：

頻率譜確定的頻率譜未定的
A 是根D 掛在 A 之下，還是掛在 X 之下
X 在 A 之下X 是一群，還是兩群被併起來的

兩個單位補的正是右欄那兩格，而且各補一格： 甲說「X 其實是兩群，且互不包含」，乙說「D 巢狀在其中一群之內」。 候選數因此逐步收斂 —— 這就是「合起來更好」的具體內容：

手上的證據相容的候選樹備註
只有頻率譜2 棵而且 K=3 本身是錯的（少計一群）
＋ 甲3 棵K 先被修正為 4；在 4 群下若不加約束會有 7 棵，甲的「互不包含」砍到 3 棵
＋ 甲 ＋ 乙1 棵唯一解，即真實的樹

三項改變的性質並不相同，值得分開看：

改變來源性質
K 由 3 增為 4 甲的不可同群把 0.12 那根峰拆開 解析度提升：多還原一個 subclone，而這是頻率單獨永遠達不到的 —— 兩群的 θ 本就相等
樹由兩棵並列變為唯一解 乙的祖先關係把 D 釘在 B 之下 準確度提升：原本那一棵由簡約性挑選，現在由資料決定
群間距不需純度即可定出 乙的巢狀比值 ϱ=0.50 ρ 退化為整體縮放（中篇第五節）

第二項尤其值得看清楚：「D 掛在 B 之下還是 C 之下」在頻率上永遠沒有答案。 B 與 C 的期望 VAF 完全相同，所以兩種掛法產生一模一樣的直方圖 —— 這不是精度問題，是中篇第三節那個不可辨識性換一個位置再出現一次。 單位乙的共現觀測是唯一回答得了的證據。

而三項改變都不需要先把兩個單位對齊： 甲約束的是 zi≠zj，乙約束的是 T 上的一條有向邊與 c 的一個比值， 兩者作用在同一組全域變數上，求解器同時滿足即可。 形狀不同從頭到尾都不是需要處理的問題。

最後一項精確度的保留：所謂「唯一」指的是樹的形狀唯一。 拆出來的兩群頻率相同，所以它們的標號可以整組對調而不影響任何約束 —— 編號本就是任意的，這與手動 phasing 練習裡 HP1／HP2 對調也算正確是同一回事。

由此導出一條實作規則，與第五節那條互為表裡： 可以合併的是約束，不是標籤。 局部標籤（HP1-1）僅在該區域內有定義，跨區域的同名標籤並非同一條， 故不得將局部拓撲拼接成一棵大樹。所要合併者是它們對 z 與 T 的限制 —— 而 z 與 T 本就只有一份，合併因此在估計式中自動完成， 不需要任何對齊步驟。

真正的矛盾並非形狀相異，而是整個約束集合找不到任何一組 (z,T) 能同時滿足。其形式有三：

形式例成因
直接對立一個單位給不可同群 (i,j)，另一個給必定同群 (i,j)其中一條為假，多為第三節的檢定力不足
違反傳遞性必定同群 (i,j)、必定同群 (j,k)，卻又不可同群 (i,k)同上，惟須三條方能顯現
祖先關係成環za→zb→zc→za任何樹皆不可能，通常是第四節的排序偏誤將分岔判為串接

處理方式已內建於估計式：由於約束是加權項而非硬性條件， 求解器不會因矛盾而無解，它取總和最大的那組 (z,T)， 少數錯誤的約束被多數蓋過。此即本節開頭堅持採 ωr 而非硬性條件的理由。

而矛盾率本身是一個診斷量：它估計的是整條約束產線的錯誤率， 邏輯與第二節以「不相容單位」估計單倍型標記錯誤率相同，僅是提升至全域這一層。 報告應予載明。

惟此處有一個陷阱：矛盾率低不代表約束正確。 系統性偏誤（例如第四節的排序偏誤）會使錯誤的約束彼此一致 —— 它們朝同一方向偏，因而完全不互相矛盾，卻一併使結論偏移。 矛盾率只偵測得到隨機錯誤。

「必定同群」與用途一的張力

上表第二列不宜直接採用。串接表示後者衍生自前者的譜系， 故兩群為巢狀關係；比值 ≈1 僅表示後者已接近取代前者。 然而「接近取代」不等同於同一群：兩者為兩個真實存在的 clone， 僅在頻率軸上不可分辨。而「頻率相等不等同於同群」正是中篇第三節的論點。 將其強制合併，等同於在用途一所欲分離之處主動合併，方向相反。

  • 「≈1」須定為明確的容差，且該容差應由檢定力決定，而非任意設定的常數。 在跨越深度 n 之下，比值本身即帶有抽樣誤差； 唯有當「比值 <1」在該 n 下本即可分辨、而觀測仍落於 1 附近時， 「≈1」才承載資訊。n 較小時任何比值皆近似於 1， 此為解析度不足，不構成證據。
  • 其權重應為三種約束中最低者。不可同群與有向關係皆增加可辨識性； 必定同群為唯一降低可辨識性者。錯誤的不可同群將產生不存在的群； 錯誤的必定同群則使真實存在的群消失。後者更難察覺， 因為群數多出一個尚可能引起注意，少一個則不留任何異常跡象。

五、兩類會產生假約束的誤讀

兩者皆與相位有關，方向相反： 其一為相位資訊僅在 block 內有效，跨 block 即無定義； 其二為即使在 block 內相位解得正確，仍可能被解讀為錯誤的生物學。

重要區分 #13：不同 phase block 的 H1 不是同一條染色體

相位軟體在每個 block 內將 read 分為兩組並標記為 H1、H2， 但標號在各 block 內獨立決定。 可容許之處：約束所描述的是細胞的祖先關係，而非哪一條親源染色體帶有變異。 每條約束皆在單一單位內產生，故與標號方向無關，核心推論不受影響。 限制：任何將不同 block 的 H1 合併計算的判斷皆無意義，且不會產生錯誤訊息。 因此不得以「兩個變異皆位於 H1」作為兩者同群的依據 —— 跨 block 的 H1 並非同一條染色體。 由此可導出一條可實作為檢查程式的規則： 每一條約束皆須在單一單位內部產生，不得跨單位組合。

重要區分 #14：trans 不等於分支演化

若兩個變異分別位於同一細胞的兩條染色體拷貝上（trans）， 則兩者永不出現於同一條分子。計數表因而呈現 00、10、01，而 11 一格為空 —— 此形態與兩群互不包含的 subclone 完全相同。 在約束的脈絡下此點尤為關鍵：它將產出一條假的「不可同群」， 而該約束為硬性條件，將直接迫使混合模型分出一個不存在的群。 現行流程已先依單倍型家族分組，此設計正確； 且相位使 cis／trans 在整個 phase block 內為已知 （即前一項所述的 block），而非僅在單一條 read 之內， 故此項誤讀的可處理範圍約為 read 跨距的一百倍。

七、約束預算

兩個 5% 的分母不同

本頁所稱的「5%」為區域的比例：含變異的區域中， 僅 5% 含有兩個以上的變異。以下推導所用者則為變異的比例，其分母不同 —— 由於每個多變異區域至少含兩個變異，「5% 的區域」對應 9.5% 的變異。 兩個數字皆正確，但計數的對象不同；約束產量由後者決定。

三項須注意的事項

其一，0.909 為目前最強的結果。一個在更換 basecaller 後仍維持、 且能區分癌別的統計量，所承載的是真實訊號。因此加入閘門之後應重新計算此數值： 若維持或提升，表示閘門所濾除者為雜訊；若下降，則原本的 0.909 有一部分係由共同的覆蓋幾何所致。

其二，「分支類」的比例尚不可直接視為約束產量。 分岔的判定需要兩個單突變頂點皆存在，且雙突變頂點的缺席為可信 —— 後者正是閘門所檢驗的對象。故 6%–22% 為上限，而非實際可用量。

其三，有一項計數需要釐清。 各資料集的單位數總和為 71,955，而結論中引用的數值為 85,941。 兩者可能計數不同的對象，此點須在成文之前確認。

預測與結果檢視

設閘門設定寬鬆時收得 5,000 條約束，設定嚴格時僅餘 300 條。 直觀上約束越多，混合模型所受的限制越強，結果應越好。 請問：寬鬆的設定是否較佳？

展開答案

不一定，且很可能較差，因為約束的兩種錯誤代價並不對稱。

一條遺漏的約束，其代價為「原可確定的關係改由偏好補足」， 即退回第一節第四步的狀態，損失有限。

一條錯誤的「不可同群」，其代價為迫使混合模型分出一個不存在的群。 其機制為第三節的反向運作：zi≠zj 使正確的 K 不可行， 模型只能增加一個成分。 此錯誤不會自行顯現 —— 所分出的群具備頻率與變異，形態正常， 而下游的樹、演化次序與臨床解讀將一併錯誤，報告上不留任何異常跡象。

因此取捨並非「多與少」，而是「遺漏與虛構」，兩者代價相差甚大。 正確的做法為從嚴，並將殘餘的不確定性納入權重 ωr， 而非採硬性條件 —— 經稀釋的單一條錯誤約束不足以改變結論。

閘門的實際強度可藉重現性外部檢驗： 在不同 basecaller、不同機構的同一細胞株上掃描一系列閘門嚴格度， 比較何者的群與樹最為一致。此檢驗不需金標準， 而金標準正是此領域最欠缺的條件。

尚未解決的問題

  • 整條路線尚未經實測驗證。上述各項皆有結構性的理由，但均未在真實資料上檢驗。 最小的驗證即第三節的數值例：合成 ρ ＝ 0.60、CCF 分別為 1.00／0.40／0.40 的三群， 確認僅用 VAF 的分群必然給出 K=2 與線性樹， 再量測需要多少條約束、閘門需多嚴格，方能正確分離而不誤拆。
  • 用途二需要同一條單倍型上存在多個變異，而該條件對應的正是最稀缺的區域。 低突變負荷時 φ^ 可能無法估計，此時用途二失效，僅餘用途一與用途三。
  • 約束的來源具有偏性。它們僅來自變異密集的區域， 而變異密集有時並非偶然：kataegis 為一種局部超突變， 單次事件於數十 kb 內產生一連串變異。 該串變異幾乎必然同時發生且同屬一群，故將貢獻大量高度相關的約束， 在統計上卻被計為數十個獨立觀測。應先偵測並降權為每叢一個有效觀測。
  • 一個群未必對應單一細胞群體。本實驗室的甲基化觀測顯示： 單一個「單倍型 ＋ 等位」狀態之下仍可區分出五群甲基化模式。 故 K 的正確讀法恆為「至少此數」。
  • 超出 read 跨距的關係仍不可觀測。相距 100 kb 的兩個變異無法產生約束， 與定序深度無關；第八節的三層結構為此設下硬上限。

本模組術語

latent node（潛在節點）
建樹時為了讓圖連得起來而補進的中間狀態，沒有被任何 read 直接觀測到。它是模型的產物，不能當成「還沒觀察到的細胞」。
phase block
一段可建立連續相位關係的區域。read 長度不足、缺少 informative heterozygous 位點或證據不一致時，可能形成不同 phase blocks。
read-AF（read 層級的 ALT 比例）
在同一個分析區域、同一個單倍型家族的 read 之中，某個 somatic 位點帶 ALT 的比例。分母已限縮到同一條 haplotype 的同一段區域，所以不必經過純度與拷貝數換算；用途是在步數並列的候選樹之間排序。
somatic haplotype
在 germline haplotype 之下再細分出來的層級。某條 HP1 的 read 若帶有 somatic 突變，就屬於 HP1-1；HP2 的則是 HP2-1。無法判定來源的歸為 HP3。
