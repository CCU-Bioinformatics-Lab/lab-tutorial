整合篇：LiFT-CN 的生成模型與實作規格

以原始長讀分子的 germline–somatic 聯合 marks 建立 marked-fragment likelihood，將 clone tree、實體 copy lineage、allele-specific CN、mutation timing、cellular purity、tumour DNA fraction、ploidy 與 WGD modes 納入同一個 posterior，並定義可辨識條件、推論演算法、輸入輸出、ablation 與驗證標準。

建議先修：估計式與落地建議先修：聯合估計式的規格

本模組學習目標

  • 界定 LiFT-CN 的估計目標，並區分 cellular purity、tumour DNA fraction、tumour ploidy 與局部分子比例
  • 寫出由 clone tree、實體 copy lineage 與 mutation timing 到長讀分子觀測的完整生成模型
  • 說明 marked-fragment factorization 如何同時使用深度與多位點狀態而不重複計算同一條 read
  • 把 CCF 與突變多重度由自由 nuisance 改為 clone tree 與 copy history 的衍生量
  • 列出 WGD、purity、clone fraction、phase orientation 與 segmentation 的可辨識條件
  • 定義分段推論、模式保留、輸入輸出、QC 狀態與失敗停止條件
  • 以 D、E 與 E-shuffle 的對照驗證多位點 somatic haplotype 是否改善 purity 與 ploidy，而非只改善 subclone topology

為什麼重要

兩條規格之間的循環依賴

sr5 的單位點四格表可在 germline haplotype 內量測 somatic 比例， 但每個 mutation 的 CCF ci 與 multiplicity μi 仍須由外部 subclone 模型提供先驗。 sr2b 的多位點狀態表可限制 clone 數、clone tree 與相對比例， 其 VAF 位置卻又依賴 purity、allele-specific copy number 與 multiplicity。 前者需要後者的 clone 結果，後者需要前者或既有工具的 purity／CN 結果，形成直接的循環依賴。

LiFT-CN（Linked-Fragment Tumour tree and Copy-Number model） 以單一生成模型取代兩個互相提供外部參數的估計器。 somatic mutation 不再具有彼此獨立的 (ci,μi)；每個 mutation 被放置於 clone tree 的一條 edge、某一條實體 copy lineage，以及相對於 gain、loss 或 WGD 的時間位置。 clone inheritance 與 copy history 隨後決定其 CCF 與 multiplicity。

模型名稱與 novelty 的位階

LiFT-CN 為實作規格的工作名稱，不構成方法已完成或「首次」的證據。 可檢驗的新意是特定的統計閉合：以原始長讀分子的 germline–somatic 聯合 marks， 同時限制 clone tree、實體 copy lineage、clone-specific allele CN、purity、DNA fraction、ploidy 與 WGD modes。 任一個輸出本身均已有既有方法；候選 novelty 位於它們共享同一個 raw-molecule posterior 的交集。

多位點資訊的預期作用

單位點四格表只提供邊際比例。若 ci 可自由變動， purity 與 CCF 可沿同一方向縮放；若 μi 未知，mutation timing 與 CN gain 亦可交換解釋。 同一分子上的 00、10、01、11 或更高維狀態新增的是 mutation 間的共現、互斥與巢狀關係。這些關係限制共享的 clone tree 與 copy history， 再間接縮小 purity／ploidy 的可行集合。

因此，稀疏 multi-SNV haplotypes 的主要用途不是增加大量計數， 而是排除原本完全等價的參數模式。若這些單位未連到 truncal scale、post-WGD mutation 或 informative allele-specific CN，預期結果為 clone topology 改善，而非 absolute purity／ploidy 改善。

三、clone tree 與實體 copy lineage

每個 autosomal segment 的 tumour founder 具有兩條 parental copy lineages。 clone-tree edge 上的 loss 刪除一條具名 lineage，gain 複製一條具名 lineage， whole-genome doublingwhole-genome doubling 全基因體加倍腫瘤演化過程中整套基因體複製一次的事件，使各處拷貝數同時加倍。其重要後果是可辨識性：若加倍後所有等位特異拷貝數皆為偶數，則該解與未加倍的解對深度與等位比例給出完全相同的觀測；純度為 1 時兩者逐點相同。An event doubling the entire tumour genome, multiplying every copy number by two. Its consequence is identifiability: if all allele-specific copy numbers are even afterwards, the doubled solution reproduces the observed depth and allele ratios exactly, and at purity one the two models are pointwise identical.完整條目 → 複製該 edge 當時存在的全部 lineages。 事件序列決定所有 Csgh，而不只決定最後的 total CN。

固定 atomic-bin grid 後，令 B 為相鄰 bins 的 boundary indicators， S(B) 為其導出的 CN-segment partition。所有 copy-event records 均以 S(B) 中的 segment 為 target；因此 segmentation 改變時，copy-history 的 support 與 normalizer 亦隨之改變。

令 HeCN=(he1CN,…,heJeCN) 為 edge e 上的 ordered copy-event history，其中 Je=NeCN+We。每個 segmental event record 包含 segment、gain／loss type 與在該時點存在的 target lineage；若 We=1，history 中另含一個 WGD token。由 founder lineages 依序 replay HCN，唯一導出每一時點可用的 physical lineages 與最終 C。

pair order 以 deterministic edge／timing／lineage order canonicalize，不另產生兩倍 label mass。 若 Qm 為空，recurrent class probability 為 0。令 calibrated base masses 為 ρtree,ρartifact,ρrecurrent； ρrecurrent 已包含預先登錄的第二次 acquisition penalty， 每個 mutation 只在 support 非空的 classes 間重新正規化 ρ。因此 Em 為空時 P(Rm=artifact)=1；Em 非空但 Qm 為空時，只在 tree 與 artifact 間正規化。

P(Θv1∣D,Γ)∝P(D∣Θv1,Γ)PclonePcopyPplacementPphasePboundaryPerror

Γ 是固定 discovery catalogue；C 專指由 copy history 導出的 allele-specific CN states。 Pclone 含 Z0,p,K,T,π； Pcopy 為下列條件於 (T,B) 的 stage-specific factor； Pplacement(z,R,bcat∣HCN,B,T,Γ) 只含 catalogue records，並經 Em 限制； Pphase 含 normal genotype、component-gauge-fixed true carrier states H，以及 compatibility mode 才啟用的 orientation-error HMM F,σb； Pboundary 為 atomic-bin merge 的 geometric-duration／break penalty； Perror 含 χ,q,δu,μh,τh。capture factor a、E,ESV,Bu 及其 hyperparameters 在 v1 由 calibration 固定，不屬 Θv1。 完整 ascertainment stage 的 target 再乘上 mutation-count、detection 與 callable-genome factors，並把 λm 納入 Θfull；兩個 targets 不得混用。 沒有列入此 factorization 的量不得在 optimizer 或 sampler 中自由更新。

Pcopyv1=P(λCN)P(ωW)P(Ne0CN,We0∣Cfounder,T,B,λCN,ωW)P(He0CN∣Ne0CN,We0,Cfounder,T,B)1[NeCN=We=0∀e≠e0]1[C=derive(T,B,He0CN)]

Θv1 明確包含 λCN,ωW,Ne0CN,We0,He0CN,B,C， 但不含 bCN 或 off-trunk copy events。 最後的 deterministic indicator 要求 stored CN states 等於 ordered history replay 的結果； mutation timing 與 lineage eligibility 亦讀取同一個 HCN，不得使用另一套未記錄的 event order。

Pcopyfull=P(bCN)P(λCN)P(ωW)∏e[P(NeCN,We∣Cepar,T,B,λCNbeCN,ωW)P(HeCN∣NeCN,We,Cepar,T,B)]1[C=derive(T,B,HCN)]

此 factor 只屬 clone-specific-CN stage。Pcopyfull 對 T 與 B 均為 conditional； edge product 依 tree topological order 評估，因此每個 child factor 使用已 replay 的 Cepar。 Pboundary(B) 仍單獨列出，但不得把 Pcopyfull 的 normalizer 當作與 B 無關。

令 Bs=1 表示相鄰 atomic bins 之間保留 CN boundary，並形成前述 S(B)。 Bs∼Bernoulli(ωB,s)，其中 ωB,s 由 discovery fold 的 SV support 與固定 guard-grid calibration 預先決定；連續 Bs=0 的 run length 對應 geometric segment-duration prior。 inference fold 只更新 Bs，不重新選 candidate coordinates。

四、marked-fragment observation model

同一批 reads 同時產生 total depth、germline alleles、somatic states、HP tags 與 SV support。 將五種摘要似然直接相乘會重複計算。LiFT-CN 改以 marked-fragment process： 每條 read 只以唯一的 start anchor 進入 depth count 一次；其覆蓋的 germline、somatic 與 breakpoint pattern 則作為該 fragment 在已知 start／mask 下的條件 mark。

P(D∣Θ)=∏A∈{T,N}[P(NA∣Θ)∏r∈RAP(Yr∣Mr,s(r),u(r),Θ)]

A∈{T,N} 表示 tumour 與 matched normal，RA 是 sample A 的 reads， NA 為 disjoint start bins 的 counts；s(r) 是 read-start 所在 CN segment， u(r) 是其 multi-locus likelihood unit，Mr 是 read 真正覆蓋的 loci 與 alignment features， Yr 是 observed bases 與 SV marks。 此式為同一 marked process 的 factorization，因此 depth 與 composition 可同時使用而不重複計數。

read-origin mixture

origin o 為 normal parental copy，或 tumour clone g 的 physical copy lineage。 加入 region／origin-specific capture factor auso 後，molecule weight 為：

未正規化 origin weight αuso* 由細胞 mixture 直接指定： 每條 normal parental copy 各貢獻 1−p，每條 clone-copy lineage 各貢獻 pπg。 加入 capture factor 後正規化：

αuso=αuso*auso∑o'αuso'*auso'

共同的 segment coverage bias 只由 depth term 的 qs 表達； auso 僅表達 origin 間的相對 allelic mapping／capture bias，並在每個 segment 內限制其加權平均為 1。 logauso=γusoTx+uuso，其中 covariates 只含 observed mapping quality、read length、 reference allele 與 sequence context，不得含 clone、CN 或 observed ALT fraction；uuso 使用 matched normal-derived、強烈收縮至 0 的 Gaussian prior，γ 使用同一 calibration 產生的 Gaussian prior。 另對 qs 加入 callable-length-weighted ∑sLslogqs=0 的中心化約束，避免 a、q 與 CN scale 彼此任意吸收。

matched normal 以 TINC χ 取代 tumour purity：normal-origin weight 為 1−χ， tumour-origin weight 為 χπg。若污染 normal 的 clone composition 與 tumour specimen 不同， 該 composition 需有獨立先驗；單一 normal sample 不足以自由估計另一組完整 clone mixture。

multi-locus emission

P(Yr∣Mr,Θ)=(1−δu(r))∑oαu(r),s(r),o∏j∈MrbaseErj(Yrj∣Xoj)∏v∈MrSVErvSV(Brv∣Zov)+δu(r)Bu(r)(Yr)

Xoj 是 origin o 在 locus j 的 true allele； Erj 是依 base quality、context 與 mapping stratum 決定的 per-site error matrix； Zov 表示 origin 是否具有 breakpoint／rearranged adjacency，ESV 為 support、reference、uninformative 三類 alignment mark 的 calibrated categorical emission； δu(r)Bu(r) 是整條 read 的 mis-mapping、chimera 或 family-mistag background。

未覆蓋 loci 不出現在 Mr 的乘積中，等同將所有相容完整 states 邊際化， 不得補為 REF。同一 origin mixture 同時作用於所有 covered loci，因而自然產生 cross-locus dependence； 此處 k 專指 somatic loci 數：k=1 且同一 read 另覆蓋至少一個 informative germline anchor 時， 沿 parental origin × somatic REF／ALT 聚合即為四格表；沒有 germline anchor 時只有 somatic REF／ALT 兩格。 k≥2 才新增 somatic loci 間的共現與互斥資訊。

primary raw-read mode 直接使用 gauge-fixed H 構成 Xoj， 不再以 σb 重複置換 parental labels。compatibility mode 才將外部 HP1／HP2 經 (σb,F) 映射到 internal canonical labels。沒有 bridging evidence 的 components 標記為 PHASE_DISCONNECTED，但不複製成 label-switched posterior modes。

E,ESV 的 hyperparameters 與 Bu 由 matched-normal-only samples、 excluded repeats、known chimeras 與 spike-ins 預先校準並在 v1 固定。 whole-read artifact probability 則採 stratum-pooled hierarchy：

logit(δu)∼Normal(μh(u),τh(u)2),τh∼HalfNormal(sδ)

h(u) 是 platform、mapping-quality、repeat／chimera class 所定義的 calibration stratum； μh 的 informative prior 與 sδ 由 negative controls 預先校準。 所有 δu 必須透過共享 (μh,τh) partial pooling 更新，不得各自只靠 sparse unit reads 自由擬合。 Bu 仍固定，否則 δu 可吸收任何 coherent low-frequency clone state。 主要結論另做 fixed-δu 與 prior-scale sensitivity analysis。

depth marks 的條件分布

vTs∝Lsqs[2(1−p)+p∑gπg(Csg1+Csg2)]
vNs∝Lsqs[2(1−χ)+χ∑gπg(Csg1+Csg2)]

vTs,vNs 分別為 tumour 與 normal read start 落入 segment s 的相對機率。 χ 為 TINC；若 preflight 支持無 TINC，可將其固定為 0，否則採強烈偏向低值的 calibrated Beta prior。 logqs=βsTx+us，其中 xs 含 GC、mappability、replication timing 與 platform covariates， β 採 normal-derived Gaussian shrinkage prior，σq 採 half-normal prior， us∼Normal(0,σq2) 並服從前述加權中心化約束；matched normal 主要識別 β,us。 在固定 tumour total reads 下，segment counts 採 multinomial；evaluation-fold residual 若顯示額外離散，再改為 Dirichlet-multinomial。此條件 likelihood 保留深度形狀，也明確呈現 global CN scaling 的限制。

segmentation 與 SV evidence

candidate boundaries 由 discovery fold 的 depth change points、germline allele imbalance、 raw SV-support molecules 與固定寬度 guard grid 的聯集產生，形成不可再細分的 atomic bins； inference fold 才提供 boundary likelihood。此 candidate catalogue 在 production v1 中固定， 輸出的 breakpoint intervals 明確標為 conditional on catalogue，並以 guard-grid width 與 split seed 作敏感度分析。 相鄰 bins 是否合併為同一 CN segment 是 latent merge indicator， 而非預處理後固定的事實。SV-support pattern 直接包含於 Yr；同一 SV call 不再同時作 hard breakpoint 與另一個獨立 likelihood。

五、SR5 與 SR2b 式子的共同邊界

對 segment s，tumour 與 normal molecules 的期望總量為：

Ds=2(1−p)+p∑gπg(Csg1+Csg2)

mutation m 在 clone g 的 multiplicity 已由 copy history 給定，故 marginal VAF 為：

VAFm=p∑gπgμmgDs

若 mutation 位於 parental haplotype h，其 within-haplotype fraction 為：

smh=p∑gπgμmg(1−p)+p∑gπgCsgh

SR5 的 p·c·μ 結構為此式在 clonal CN 與單一 carrier group 下的 marginal； SR2b 的 local 2k state table 為同一 origin mixture 在多個 loci 上的 joint distribution。 兩者不再需要互相匯入外部 point estimates。

information audit

每個 mode 另計 depth、single-locus marks、multi-locus co-occurrence、SV marks、external evidence 與 priors 的 log-posterior contribution。移除某一 evidence class 後 mode ranking 的改變， 用以區分 data-identified、prior-resolved 與 observationally equivalent。 窄 posterior 本身不證明資料具資訊；強 clonal prior 亦可產生窄但 prior-dominated 的區間。

七、推論演算法

  1. precomputation。依固定 genome grid 建立 disjoint read-start bins； 由 discovery fold 建立 atomic CN candidate bins，再由 inference fold 建立 read coverage masks、 observed allele-pattern sufficient statistics 與 phase-connectivity graph；evaluation fold 只建立相同格式的 predictive summaries，不參與 posterior。不同 split seeds 只作獨立敏感度分析。
  2. calibration。由 matched normal、high-confidence homozygous loci、spike-ins 與 excluded repeat strata 估計並在 SMC 前固定 a,E,ESV,Bu 及其 hyperparameters；另建立 χ,q,(δu,μh,τh) 的 priors 與 TINC initial range。這些 fixed calibration objects 不列入 Θv1。ω0,ap,bp,λK,απ,asw,bsw、CN event-type probabilities、 boundary probabilities 與 artifact／recurrent class probabilities 亦在 run 前固定。
  3. component-stratified initialization。Z0=1 與 Z0=0 各配置預先登錄的最低粒子數； proposal 配額只改善數值覆蓋，不代表 component prior mass。每個 component 內的 initial weights 各自對 conditional prior P(Θz∣Z0=z) 正規化；(ω0,1−ω0) 只在最終 evidence 合併時乘入一次。各 component 分別從 prior 取樣大部分 particles；depth＋germline grid、marginal VAF clusters 與 multi-locus local trees 只提供少部分 Z0=0 proposal seeds。所有 data-derived seeds 必須來自可計算密度 qz(Θ) 的 stochastic proposal，initial importance weight 取 P(Θ∣Z0=z)/qz(Θ)；若混合 prior 與多個 proposals，分母使用完整 mixture density。 deterministic optimizer seed 必須以已知密度 jitter，否則只能作不承擔 evidence weight 的診斷起點。
  4. annealed target。production v1 固定使用 annealed sequential Monte Carlo： Pt(Θ)∝P(Θ)P(D∣Θ)βt，β0=0、βT=1。 兩個 Z0 components 各自選擇 tempering schedule 與 systematic resampling，並估計 component evidence； 最後以 P(Z0=z∣D)∝P(Z0=z)P(D∣Z0=z) 合併。下一個 βt 自適應選至 predicted ESS 為 component particle 數的 0.8；actual ESS 低於 0.5 時 resampling。
  5. analytic marginalization。read origins 在 emission 的 ∑o 中精確加總，不另抽樣 responsibilities； germline local phase states 與 atomic-bin merge indicators 在可行時用 forward-filter backward-sample 更新。
  6. continuous rejuvenation。production v1 更新 p,π,χ,bcat,λCN,ωW、 q=(β,us,σq) 與 (δu,μh,τh) 經 logit／simplex／positive transform 後 使用固定的 HMC kernel；full clone-specific-CN stage 才加入 bCN。step size 與 mass matrix 只在 βt<0.5 的 adaptation phase 更新，之後凍結。
  7. discrete rejuvenation。每個 fixed-Z0 component 內更新 GN,H,Bs； compatibility mode 另更新 F,σb。Rm 與 mutation edge／lineage／timing 以 tree message-passing Gibbs 或 enumerated Metropolis update；CN histories 以 segment dynamic programming proposal 在 v1 僅聯合更新 trunk (Ne0CN,He0CN,C)；K,T 以 subtree-prune-regraft 與 clone split／merge proposals 更新，We0 只作 trunk Bernoulli-compatible move。 full clone-specific-CN stage 才開放所有 edges 的 (NCN,HCN,C,W) 與符合 top-down WGD prior 的 reversible proposals。普通 Z0 toggle 不在 kernel contract 中；跨 component 質量由 evidence 合併。
  8. fixed versus sampled audit。每個 Θv1 variable 必須對應上列 kernel； a,E,ESV,Bu 與 calibration hyperparameters 明列為 fixed。 完整 ascertainment stage 另加入 λm,M,Sm,dm 的 conjugate／Metropolis updates，v1 不得更新這些量。
  9. mode extraction。最終 weighted particles 依 K,T,WGD 與 length-weighted major CN states 分群， phase labels 先依每個 component 的 anchor gauge canonicalize，再估計 mode mass；不得只保留最高 MAP mode 或以跨 mode posterior mean 取代。

production v1 固定 candidate atomic boundaries、使用已正規化的 K≤6 truncated prior、copy number 上限為 8、 每條 root-to-leaf path 至多一次 WGD，且先以 clonal CN 與 clonal WGD 運行；此階段只有所有 tumour clones 共同繼承的 trunk edge 可承擔 CN events 或作 WGD candidate，off-trunk event counts 與 WGD indicators 固定為 0。 開放 clone-specific CN／subclonal WGD 後才加入 bCN 並使用前述 top-down path prior。 觸及計算上限的 posterior mass 必須產生 STATE_CAP_REACHED，不得在邊界值截斷後仍回報 PASS。 full model 再開放 clone-specific CN 與 breakpoint birth／death proposals。

convergence contract

  • 至少四個 independent SMC runs 對 major mode masses 的 absolute difference 不超過 0.05， 且各 primary mode 內 p,κ,f 的 effective sample size 至少 200；
  • Z0=0 與 Z0=1 各自回報 initial quota、component ESS、evidence uncertainty 與 resampling ancestry；任一 component 的 effective particles 低於預先登錄下限時，不回報可靠的 no-tumour odds；
  • proposal kernels 的 acceptance、particle ancestry 與 terminal weight concentration 均寫入 diagnostics；
  • evaluation fold 的 fragment log predictive density 在相鄰兩次完整 run 間差異低於預先登錄閾值；
  • posterior predictive checks 同時涵蓋 depth、germline imbalance、single-site VAF、multi-locus state 與 SV support；
  • 任一 observation class 持續出現系統性 residual 時輸出 MODEL_MISFIT，即使 sampler 已收斂亦停止生物學解讀。

多位點資料的 eligibility report

模型啟動前不以固定的「至少幾個 multi-SNV units」門檻宣告可用， 而是產生 information inventory。必要欄位包括：

  • single-locus 與 multi-locus molecules 的互斥計數，以及每個 coverage mask 的數量；
  • 每個 phase-connected component 的 loci、units、independent molecules 與 Hamming-separated states；
  • 可能連到 truncal scale、互斥 branch covering set、post-gain 或 post-WGD timing 的候選 units；
  • copy-number-neutral、LOH、gain、amplification 與 excluded regions 內的單位數；
  • discovery、inference 與 evaluation folds 的 candidate retention、VAF、depth 與 context 分布；
  • base-error 與 whole-read artifact posterior，以及低頻 states 相對於 error floor 的距離。
  • E-shuffle strata 的 molecule-count distribution、singleton fraction、size 至少 2 的 strata 數、 實際可置換 molecules／somatic-locus pairs 比例、每個 seed 的實際 changed fraction 與 unique non-identity shuffles 數。

少量但連接不同 clone branches 或 WGD timing 的 units 可能排除完整 posterior mode； 大量集中於同一 mutation pair 的 molecules 則主要提高該 local state frequency 的精度。 獨立資訊量由 connected graph position 與 state contrast 決定，不由 raw read count 單獨決定。

E-shuffle以 constrained randomization 保留 E 的 depth、每站 somatic marginals、 每站 germline–somatic contingency、每條 read 的 SV marks、每站 somatic–SV contingency、segment、mask、quality bin 與 platform；只打散 somatic–somatic 同分子配對只移除 co-occurrence 的負對照

主要因果對照為 E 對 E-shuffle，而非只比較 E 與資料量較少的 D。 shuffle 不使用 derived HP tag；優先以 restricted swaps／Markov moves 精確保存每站 raw germline–somatic contingency。每條 read 的 SV marks 固定，somatic swaps 另受每站 somatic–SV contingency 約束； 因此此對照只移除 somatic–somatic pairing，而不移除 SV linkage。完整 anchor pattern 不必完全相同。 若計算限制迫使 strata 依 deterministic hierarchy 合併，必須逐層記錄被放寬的 invariant 及其最大偏差。 Neligible 明定為 inference fold 中覆蓋至少兩個 somatic loci、通過 mask／quality filters， 且位於 E-analysis units 的 molecules 數。 令 Npermutable 為至少具有一個 non-identity、constraint-valid partner 的 molecules 數， φ=Npermutable/Neligible。第 b 個 shuffle 另定義 ψb=Nchanged(b)/Neligible；Runique 為實際產生的 unique non-identity shuffled datasets 數。 只有 φ≥φmin、medianb(ψb)≥ψmin 且 Runique≥Rmin 三者同時成立，E-shuffle 才具解釋效力。任一條件未達時 輸出 SHUFFLE_UNDERPOWERED， 不得將 E 與近乎恆等的 E-shuffle 比較解讀為沒有 co-occurrence gain。 只有 E 相對 E-shuffle 改變正確 posterior mode、提高 WGD calibration、降低 purity／ploidy bias， 或修正 clone／mutation assignment，才能歸因於 joint haplotype。 若 mode 數不變而 credible interval 變窄，應報告為 precision gain； 若只改善 tree relationship metrics，應報告為 subclone gain，不可轉述為 purity/ploidy gain。

單次 E-shuffle fit 只提供 ablation effect size。若宣稱 randomization-test significance， 必須預先指定 scalar statistic TE，產生多個符合相同 constraints 的 independent shuffles， 只以 Runique 個 non-identity datasets 建立 empirical null distribution 並計算 tail probability； 不得以單一 seed 或重複的 shuffled datasets 稱為 permutation test。

尚未解決的問題

  • full clone-specific CN 的可計算性。tree、copy lineage、segmentation 與 WGD 的聯合狀態空間極大； production v1 的 clonal-CN restriction 是否保留關鍵 joint-haplotype gain，須由 simulation 確認。
  • mutation discovery split 的效率。低 purity 下將 reads 分成三 folds 會降低 recall； cross-fitting 的 bias–variance trade-off 尚無實測。
  • copy-lineage equivalence。不同 event orders 可能產生相同 final CN 與 mutation multiplicity； 輸出需合併 observationally equivalent histories，而非回報任意一條。
  • genome-graph events。chromothripsis、ecDNA、templated insertions 與複雜 rearrangements 不一定可由 segmental gain／loss tree 表達。
  • normal-cell baseline。germline CNV、mosaic normal 或非二倍體正常細胞將破壞 normal CN=2 的預設。
  • continuous subclone spectrum。離散有限 clones 對某些 tumour evolution 並不合適； posterior predictive failure 必須優先於增加 K。
  • novelty 搜尋範圍。在使用「first」之前，仍須系統性涵蓋 HATCHet／HATCHet2、PhyloWGS、 PyClone、TITAN、cloneHD、BayClone2、WEAVER、JaBbA、SAVANA、Refphase 與 genome-graph mixture models。

本模組術語

ploidy（倍性）
細胞內染色體套數。多數正常常染色體為 2（diploid）；腫瘤可呈現 3、4 或其他非整倍體狀態。
tumour DNA fraction（腫瘤 DNA 比例）
樣本 DNA 中源自腫瘤的比例。與 tumor purity（細胞比例）在 aneuploid 或 WGD 的情況下會不一樣。
tumour purity（腫瘤純度）
樣本中腫瘤細胞所佔的比例。purity 越低，somatic 訊號被正常細胞稀釋得越嚴重，偵測越困難。
whole-genome doubling（全基因體加倍）
腫瘤演化過程中整套基因體複製一次的事件，使各處拷貝數同時加倍。其重要後果是可辨識性：若加倍後所有等位特異拷貝數皆為偶數，則該解與未加倍的解對深度與等位比例給出完全相同的觀測；純度為 1 時兩者逐點相同。
