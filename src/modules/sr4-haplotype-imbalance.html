為什麼重要

上篇留下的限制

上篇的結論為：深度與等位比例所決定的是一個格點族， 族內選點須依賴錨或偏好，而同一份資料之內最強的錨是 somatic 變異的 VAF。 該錨的限制亦已指出 —— 其關係式 {{m: VAF = p/2}} 的分母含兩條單倍型的拷貝數， 故僅在二倍體區段成立。PURPLE 因此將此估計限於推得拷貝數落於 1.8 至 2.2、 且較小等位不低於 0.5 的區域。

腫瘤基因體上符合該條件的區域往往不是多數， 而不符合的區域（LOH、單一等位擴增、非整倍體）恰是腫瘤最具資訊的部分。 錨最有力之處，正是它被排除之處。

單倍型標記改變了分母

當 read 已帶有單倍型標記時，同一個 somatic 訊號可以在單一條單倍型之內計數： 分子為該單倍型上帶有 somatic 等位的分子數，分母為該單倍型的全部分子數。 另一條單倍型完全不進入這個比值，前述的限制隨之消失。

本頁的內容即為此一觀察的展開：先由原始碼寫出 LongPhase-S 現行統計量的閉式， 說明它與上篇的等位比例式為同一個形式；再據以勾勒一個可同時輸出 cellular purity 與 ploidy 的估計式，使 tumour DNA fraction 成為導出量。

本頁的位階：機制假說與原型，尚不是已完成的估計器

以下各節建立的是機制與代數關係，並指出現行流程把哪兩件事壓在同一個統計量裡。 它尚未構成一個可用的 purity／ploidy／拷貝數聯合估計器， 亦不宣稱優於現行的 DNA 比例迴歸 —— 後者在其所針對的量上已有 MAE 0.03 的實測成績。

距離一個可宣稱改善的估計器，至少還差四件事，各見其所在的節次： 位點層級的四格表尚未產生（第一、五節）； {{m: c}} 與 {{m: μ}} 為自由參數時純度只有下界（第五節）； 分段不能沿用 phase block（第六節）； 偵測與標記誤差尚未進入似然（第八節）。

{{svg:sr4-goal | [wide] 上排為現行流程：GHIR 分布經中位數與四分位距兩個特徵， 以迴歸給出 tumour DNA fraction 一個純量；純度與倍體不在輸出之中。 下排為本頁所建立者：三個觀測通道分別量在 germline 位點、視窗全體與 somatic 位點上， 聯合估計純度與每段的等位特異拷貝數，倍體與 DNA 比例由兩者導出。 右側對照上篇：ASCAT 與 PURPLE 輸出純度與倍體之後，須以換算式才進入同一個尺度。}}

現行實作已有的原料，以及還缺的一格

現行實作在每個 somatic 位點上，已將覆蓋該位點的 read 依標籤分入 H1、H2、H1-1、H2-1、H3 五個計數 （SomaticVarCaller.cpp 的 ReadHpCount）， 並已算出三個比值：germlineHaplotypeImbalanceRatio（即 [[GHIR]]）、 allelicImbalanceRatio 與 somaticHaplotypeImbalanceRatio。

但這五個計數是read 層級的標籤（見第一節的說明框）， 不是位點層級的等位計數，因此不能直接相除當作任何單一位點的等位比例。 下文所需的三個觀測通道之中，只有總深度比可由現有輸出直接取得； 單倍型深度比需在 germline heterozygous 位點上另行彙總， 而單倍型內 somatic 佔比需要一張目前尚未產生的位點層級四格表。

可容許的說法是：原料（每條 read 的單倍型歸屬與逐位點等位）已經在管線裡 （variantsHP、tumorPosReadCorrBaseHP）， 缺的是彙總方式與模型；不可說成「只要把既有的兩個數字相除」。

本頁討論範圍限於單一樣本的 cellular purity、ploidy 與等位特異拷貝數； subclonality 僅作為混淆項出現，其重建屬另一主題。

概念與互動

一、GHIR 的定義，以原始碼為準

{{eq}} GHIR(i) = \frac{\max(RC^{H1}(i), RC^{H2}(i))}{RC^{H1}(i) + RC^{H2}(i)} {{note}} {{m: i}} 為一個候選 somatic 位點；{{m: RC^{H1}}} 與 {{m: RC^{H2}}} 為該位點上標為 H1 與 H2 的 read 數。實作見 HaplotagStrategy.h 的 calculateHaplotypeImbalanceRatio。 {{/eq}}

三件必須先講清楚的事。

其一，分母只有 H1 與 H2 兩個計數。 H1-1、H2-1、H3 與未標記者皆不在分母之內。 這一點決定了後續整個閉式的形狀，且與「涵蓋該位點的總 read 數」一語不同； 以式子與原始碼為準。

其二，帶有 somatic 等位的 read 不會落入 H1 或 H2。 標記程序先判定該 read 是否帶有 somatic 等位（tumorMaxHPcount != 0）， 帶有者才進入 H1-1／H2-1／H3 的分支； 兩個 germline 計數僅收未帶 somatic 等位的 read。

這五個計數是 read 層級的標籤，不是該位點的等位計數

hpResult 每條 read 只算一次，其依據是該 read 整條上的 somatic 證據；隨後 for(auto pos : tumorSnpPosVec) ReadHpCount[hpResult]++ 把這個標籤記到該 read 覆蓋的每一個 somatic 位點上。

後果是：位點 {{m: i}} 的 ReadHpCount[H1-1] 計的是 「在 {{m: i}} 上、且在這條 read 的某處帶有 somatic 等位」的 read， 不必然在 {{m: i}} 這個位置帶有 ALT。 一條 read 若在別處帶 somatic 變異、而在 {{m: i}} 是 REF，它仍被計入 {{m: i}} 的 H1-1，且同時不被計入 {{m: i}} 的 H1。

因此這組計數可以支持「這個區域的單倍型是否失衡」， 但不足以定義任何單一位點的等位比例。第五節據此重寫。

其三，max() 使值域為 {{m: [0.5, 1]}}。 這是一個折疊統計量，與上篇所述 AMBER 取兩個等位較大者的做法同型。 邊界情形另有規定：兩個計數皆為零時回傳 0，僅其一為零時回傳 1， 前者被後續濾波當作哨兵值排除。

{{svg:sr4-ghir-buckets | [wide] 一個 somatic 位點上的 read 依標籤分入五個計數。 虛線框標出 GHIR 的分母：只有 H1 與 H2。 右側標出關鍵的一步 —— 帶有 somatic 等位的分子離開 H1 進入 H1-1， 因此 H1 被掏空，而 H2 不變。}}

二、GHIR 的無雜訊值

三個計數的分子數

設 somatic 變異位於 germline 單倍型 1。令 {{m: p}} 為 cellular purity、 {{m: n_1}} 與 {{m: n_2}} 為該處腫瘤細胞的等位特異拷貝數、 {{m: c}} 為帶有此變異的腫瘤細胞比例、{{m: μ}} 為 multiplicity。 正常細胞在兩條單倍型上各一份。各計數所對應的分子數為：

計數分子數來源
H1-1{{m: p · c · μ}}帶有 somatic 等位的腫瘤分子
H1{{m: p · (n_1 − c · μ) + (1 − p)}}單倍型 1 上未帶 somatic 等位者，含全部正常細胞的一份
H2{{m: p · n_2 + (1 − p)}}單倍型 2 的全部分子
{{eq}} GHIR^{∞} = \frac{\max(p(n_1 − cμ) + (1 − p), \quad p·n_2 + (1 − p))}{p(n_1 + n_2 − cμ) + 2(1 − p)} {{/eq}}

此式與上篇的等位比例式為同一個形式。 將上篇的 {{m: n_B}} 代換為 {{m: n_1 − cμ}}、總拷貝數代換為 {{m: n_1 + n_2 − cμ}}， 兩式逐項對應。差別僅在兩處：分子外多一層 {{m: \max}}（折疊）， 以及腫瘤側的拷貝數被 somatic 的 {{m: cμ}} 扣掉一塊。

{{svg:sr4-ghir-is-baf | [wide] 兩式逐項對齊。左為上篇的等位比例式，右為 GHIR 的無雜訊值。 分母的兩項完全對應；分子的差別只有 somatic 所扣掉的 cμ 與外層的 max。 形式相同的後果是：上篇整套機制可直接接上來 —— 反解式、格點族、以及以整數距離為目標函數的擬合方式皆然。}}

兩種歸因是同一條式子的兩項

GHIR 的偏移可歸因於 somatic read 的過度呈現， 亦可歸因於拷貝數變異、LOH 與非整倍體所造成的等位失衡。 上式顯示兩者是同一個分子裡的兩項： {{m: cμ}} 一項為 somatic 所造成的掏空，{{m: n_1 ≠ n_2}} 一項為拷貝數所造成的失衡。 二倍體時只剩前者；有拷貝數變異時兩者相加。

而單一個 GHIR 值無法分開兩者。 {{m: p = 0.50}} 時，二倍體 clonal 的位點給出 {{m: GHIR = 0.667}}； 而一個該處無 somatic 變異、但等位特異拷貝數為 {{m: 1 + 3}} 的位點， 其 GHIR 同樣為 {{m: 0.667}}。這正是 [[haplotype imbalance|單倍型失衡]] 一詞所涵蓋的兩種成因。

{{svg:sr4-two-terms | [wide] 兩欄的 GHIR 刻意設為完全相同的 0.667，純度同為 0.50。 左欄的偏移全部來自 somatic 掏空（拷貝數為 1+1）， 右欄全部來自拷貝數失衡（1+3，該處無 somatic 變異）。 只看一個 GHIR 值分不出兩者 —— 要分開，須在不同位點分別量測這兩項。}}

三、折疊效應：為何上式不是期望值

上一節的式子是把期望分子數代入比值所得， 即 {{m: \max(E[H1], E[H2]) / (E[H1] + E[H2])}}。 由於 {{m: \max}} 為非線性函數，它不等於比值的期望值 {{m: E[\max(H1,H2)/(H1+H2)]}}。兩者的差距在低深度下並不小： {{m: p = 0.20}}、跨越深度 20 時，前者為 {{m: 0.556}}，後者為 {{m: 0.599}}。 故上式應稱為無雜訊值或漸近值，不可稱為期望值 —— 任何以它反解純度的做法，在有限深度下都帶有系統性偏誤。

{{m: \max}} 使 GHIR 恆不小於 0.5，因此即使真實情形完全平衡 （{{m: n_1 = n_2}} 且無 somatic 變異），有限深度下的樣本 GHIR 期望值仍高於 0.5。 其偏移量隨跨越深度下降而增大：

平衡位點的實際期望值0.6230.5880.5630.5510.540
與真值 0.5 的偏移0.1230.0880.0630.0510.040

取兩個計數的較大者，使 GHIR 的值域為 {{m: [0.5, 1]}}。 其後果是真實平衡的位點在有限深度下不會給出 0.5，而是給出一個偏高的值， 且該偏移隨深度下降而增大。

可容許之處：折疊使「哪一條單倍型較多」這件無關的資訊被消去， 因此不需要跨位點的相位一致性 —— 這正是上篇所述 ASCAT 隨機化 A／B 標號的同一個理由。

限制：分布的中位數與四分位距兩者皆同時受純度與深度影響， 故不是兩個獨立的訊號。以此二者為特徵的迴歸，其所學到的一部分是資料集的深度分布； 更換深度設定即須重新訓練。上篇所述 PURPLE 對同一問題設有明確處置： 以二項分布算出平衡區段的期望值，並在觀測值低於 0.535 時比較 「視為平衡」與「視為觀測值」兩種解釋，取偏離較小者。 GHIR 目前沒有對應的處置。

五、單倍型內的 somatic 佔比

先把計數定義清楚

承第一節的警告：現行的五個計數是 read 層級的標籤，不能直接相除。 此處所需的是位點 {{m: i}} 的四格表 —— 每條覆蓋 {{m: i}} 的 read 同時給出兩件事：它來自哪一條單倍型，以及它在 {{m: i}} 這個位置是 REF 還是 ALT。

read 的單倍型來源在 {{m: i}} 為 REF在 {{m: i}} 為 ALT
單倍型 1{{m: R_{1,ref}}}{{m: R_{1,alt}}}
單倍型 2{{m: R_{2,ref}}}{{m: R_{2,alt}}}

此表在現行實作中尚未被彙總，但其原料已經存在： variantsHP 記錄了每條 read 在每個位點的等位類別， 且 tumorPosReadCorrBaseHP[pos][readID] 已將其逐位點、逐 read 保留下來。 分子側另有一個確為逐位點的計數 somaticReadHpCount —— 它只在該 read 於該位點帶有 somatic 等位時才累加，故可直接充當 {{m: R_{1,alt}}}。 缺的是分母側：ReadHpCount[H1] 會漏掉「在別處帶 somatic 變異、在此處為 REF」的 read。

{{eq}} s(i) = \frac{R_{1,alt}}{R_{1,alt} + R_{1,ref}} = \frac{p · c · μ}{p · n_1 + (1 − p)} {{note}} 分母為單倍型 1 在該位點的全部分子數，與該 read 在其他位置的 somatic 狀態無關。 {{/eq}}

{{m: n_1 = μ = 1}} 且 {{m: c = 1}} 時 {{m: s = p}}

代入即得 {{m: s = p·1/(p + 1 − p) = p}}。 與上篇 PURPLE 所用的 {{m: VAF = p/2}} 相比，此處沒有那個 2。 成因在分母：{{m: VAF}} 的分母涵蓋兩條單倍型，故正常細胞貢獻 2 份； {{m: s}} 的分母只涵蓋一條，正常細胞只貢獻 1 份。

式中不含 {{m: n_2}}

這是此路線的主要論據，但其範圍須精確界定。 {{m: s}} 消去的只有 {{m: n_2}}；它仍直接依賴帶有變異的那一條單倍型的拷貝數 {{m: n_1}}， 以及 {{m: c}} 與 {{m: μ}}。

因此正確的說法是「侷限於另一條單倍型的變化不影響它」， 而非「LOH、擴增與非整倍體皆不影響它」。落在帶有變異那一條上的事件全部有影響： copy-neutral LOH、該條的擴增、變異發生於擴增之前或之後（決定 {{m: μ}}）， 以及該條本身被刪除（此時 {{m: s}} 無定義）。 以 {{m: p = 0.50}}、{{m: n_1 = 1}} 固定、僅改變 {{m: n_2}} 為例：

該區段的狀態{{m: 2 × VAF}}（PURPLE 的錨）{{m: s}}（本路線）
{{m: 1 + 1}}（二倍體）0.5000.500
{{m: 1 + 0}}（LOH）0.6670.500
{{m: 1 + 3}}（單一等位擴增）0.3330.500

PURPLE 之所以將 somatic 擬合限於推得拷貝數 1.8 至 2.2 的區域，理由即在第二、三列： 在該範圍之外，{{m: 2 × VAF}} 的偏誤達三成。{{m: s}} 不需要這道限制。

六、聯合估計式

分段不可直接取 [[phase block]]。 兩者的 N50 尺度相近並不蘊含斷點對應：拷貝數斷點可以落在一個 block 之內， 而同一個拷貝數狀態也可以橫跨許多 block。 一個 block 若跨越兩個拷貝數狀態，該段的 {{m: (n_1, n_2)}} 就不是一組整數， 三個通道會同時被扭曲。

正確的做法與上篇所述的 PURPLE 相同： 以深度與 germline 等位計數獨立分段，並納入結構變異的斷點； phase block 只負責在每個拷貝數區段之內提供 H1／H2 的定向。 兩者是不同的工作 —— 一個決定邊界在哪，一個決定邊界內的兩條怎麼配對。

參數為：全樣本單一的 {{m: p}}，以及每段兩個整數 {{m: (n_1, n_2)_s}}。 倍體與 DNA 比例不是自由參數，而是導出量：

{{eq}} κ = \frac{\sum_{s} ℓ_s · (n_{1,s} + n_{2,s})}{\sum_{s} ℓ_s}, \qquad f = \frac{p · κ}{p · κ + 2(1 − p)} {{note}} {{m: ℓ_s}} 須為該段的可呼叫常染色體長度，不可用 heterozygous 位點數代替 —— 後者的密度受族群來源、可對應性、LOH 與過濾條件影響， 而 LOH 區段的 het 密度趨近於零，正好會把本路線最有訊號的區段權重壓掉。 性染色體與 germline 拷貝數變異區另行處理。 {{m: f}} 由上篇的換算式導出，故其誤差可追溯至 {{m: p}} 與 {{m: κ}} 兩者。 {{/eq}}

目標函數不可寫成「上篇的兩項懲罰乘積再加一個對數似然」。 兩者的尺度無關：懲罰項隨區段數與權重增長，似然項隨變異數與深度增長， 兩者之間沒有任何係數校準相對影響力。在高突變負荷的腫瘤上， 整個目標函數會被似然項主導；在拷貝數變異密集而突變稀少的腫瘤上則相反。 把懲罰與似然混在同一個和裡，等於讓「解的可信度」隨資料量的組成而漂移。

應改寫為單一個對數似然（或後驗），三個通道各為其中一項， 簡約性偏好進入先驗而非進入分數：

{{eq}} \log L = \log L_{depth} + \log L_{germline} + \log L_{somatic} + \log P(CN, WGD, clones) {{note}} 深度項宜取負二項而非卜瓦松（過離散），等位項宜取 beta-binomial 而非二項； 兩者皆須考慮同一條 read 上多個位點並非獨立，否則有效樣本數被高估。 上篇 PURPLE 的事件懲罰在此對應 {{m: \log P(CN, WGD)}} 一項。 {{/eq}}
項資料來源作用
{{m: E_s}}各段的等位特異拷貝數事件懲罰，即上篇的連續簡約先驗
{{m: D_s}}通道一與通道二偏離懲罰，容忍度隨 {{m: p}} 調整
第三項通道三錨：對每個 somatic 位點取二項似然 {{m: Binomial(RC^{H1-1} + RC^{H1}, s)}}

第三項與 PURPLE 的 somatic 懲罰在性質上不同，此點須明確區分。 PURPLE 的懲罰為單邊：僅當變異拷貝數超出主要等位所能容納的上界時扣分， 未超出者一律不扣。第三項為雙邊的似然：{{m: s}} 偏高或偏低皆改變分數， 因此它直接約束 {{m: p}}，而非僅排除不合理的候選。

{{svg:sr4-flow | [wide] 完整流程。淺色的四步為現行實作已具備者： 單倍型標記、五個計數、低信心變異濾除，以及分段所依據的 phase block。 深色的四步為新增者：由 germline heterozygous 位點取單倍型深度比、 依 n₁ 分層、聯合最佳化，以及輸出四個量與其區間。 現行的「兩個矩加迴歸」被整段取代。}}

七、此錨解決與未解決的不可辨識性

解決：無等位失衡時純度不可辨識

上篇第八節列出的第一項不可辨識為「全基因體皆為 1+1 時 {{m: ρ}} 不可辨識」。 此時兩條軌道皆為常數：深度比處處相同、等位比例處處為 0.5，對純度零資訊。 ASCAT 將此類樣本標記為非異常並拒絕輸出，PURPLE 則轉用二倍體區段的 VAF 峰。

而在此情形下 {{m: n_1 = 1}} 處處成立，故 {{m: s = p · c}}， 其上包絡直接給出 {{m: p}}。此項不可辨識因而被解除。 其代價僅為需要存在 truncal 的 somatic 變異 —— 而 subclone 重建的整個前提即為此。

未解決：全基因體加倍

此處須明確劃線。將上篇的格點變換施於本頁的錨： {{m: (k, m) = (2, 0)}} 時 {{m: n_1 → 2n_1}}， 而一個發生於加倍之前的變異，其 {{m: μ}} 亦隨之加倍。代入 {{m: s}}：

{{eq}} s′ = \frac{ρ′ · c · 2μ}{ρ′ · 2n_1 + (1 − ρ′)} {{note}} 以 {{m: ρ = 0.40}}、{{m: n_1 = μ = 1}} 為例：原式 {{m: s = 0.400}}； 加倍後 {{m: ρ′ = 0.25}}、{{m: n_1′ = 2}}、{{m: μ′ = 2}}，代入仍得 {{m: s′ = 0.400}}。 {{/eq}}

錨在加倍變換下不變，因此它不能單獨破解加倍簡併。 上篇的結論在此仍然成立：加倍與否須由簡約先驗、奇數拷貝數的存在， 或樣本外的量測決定。

此一劃線並非本路線的缺陷，而是其適用範圍的準確界定。 可宣稱的是「純度的估計不再需要該區段為二倍體， 且無等位失衡的樣本亦可估計」，不可宣稱「解決了純度與倍體的簡併」。

其對輸出格式的要求是明確的：加倍與否未定時，估計器須同時保留並回報兩個模式， 而非挑一個回報。可用以定下模式的證據有三類 —— 任一區段出現奇數的等位特異拷貝數、 加倍之後才發生的變異（其 {{m: μ}} 不隨拷貝數加倍）、以及樣本外的量測。 三者皆不成立時，回報單一組 {{m: (p, κ)}} 會把一個雙峰的後驗壓成一個看似確定的數字。

{{svg:sr4-what-it-fixes | [wide] 三種不可辨識的處置對照。 左欄「全基因體無等位失衡」：兩條軌道皆為常數，但 n₁ = 1 處處成立，故錨仍給出純度 —— 解除。 中欄「錨的區域限制」：{{m: s}} 的分母不含另一條單倍型，故 LOH 與擴增區段皆可用 —— 解除。 右欄「全基因體加倍」：拷貝數與 multiplicity 一同加倍時 {{m: s}} 不變 —— 仍未解除， 須另以簡約先驗或樣本外量測處理。}} {{svg:sr4-loh-strength | [wide] LOH 區段（n₂ = 0）上，H2 只剩正常細胞的一份， 故單倍型深度比 D₁/D₂ 為 (p·n₁ + 1 − p) ÷ (1 − p)， 隨純度急遽上升，是全基因體上訊號最強的一類區段。 而錨在此處同樣成立。兩者相合的後果是：對 ASCAT 與 PURPLE 而言最不利的區域， 在此路線上反而是資訊最密的區域。}}

以 read 抽樣後合併所合成的樣本，其已知的比例是分子的比例 {{m: f}}。 M8 已建立 {{m: f}} 與 cellular purity {{m: p}} 在非二倍體之下並不相等（重要區分 #2）； 此處是該項在實驗設計上的後果。

可容許之處：以此資料評比一個輸出 {{m: f}} 的方法完全恰當， 真值精確且無須換算。現行的評比即屬此類。

限制：以同一批資料評比一個輸出 {{m: p}} 的方法時， 須先將標示值換算為 {{m: p}}，而該換算需要來源細胞株的倍體。 若逕以標示的 0.2 當作 {{m: p}} 的真值，則所有估計器看起來都會低估， 因為真實的 {{m: p}} 在非整倍體細胞株上低於 0.2。 而且此一偏誤會改變方法之間的排名：誤差是到參考值的距離， 換掉參考值不是對所有估計值施加同一個平移， 故估得偏高、恰好接近 {{m: f}} 的方法會被系統性地評為較佳。 此偏誤不會在任何內部一致性檢查中顯現。

預測與結果檢視

{{ask}}

一份合成混合樣本標示為「purity 0.2」， 其來源細胞株的倍體為 3.2。某方法在此樣本上估得 cellular purity 為 0.14。 請問：此結果的誤差為多少？

{{reveal}}

約 0.005，而非 0.06。

該樣本以 read 比例合成，故標示的 0.2 是分子比例 {{m: f}}。 對應的 cellular purity 為

{{eq}} p = \frac{2f}{κ(1 − f) + 2f} = \frac{2 × 0.20}{3.2 × 0.80 + 0.40} = 0.135 {{/eq}}

故 0.14 的估計值誤差約為 0.005。 若逕以標示的 0.2 為真值，同一個結果會被記為低估 0.06 —— 相差一個數量級。

此一混淆會改變方法之間的排名，不只是讓所有方法一起看起來低估。 誤差是到參考值的距離，換掉參考值並非對所有估計值施加同一個平移。 承上例（真值 {{m: p = 0.135}}、標示值 {{m: 0.20}}）：

估計值對真值 {{m: p = 0.135}} 的誤差對標示值 {{m: 0.20}} 的誤差
0.140.005（較佳）0.060
0.180.0450.020（較佳）

排名反轉。用錯參考值的評比，會系統性地偏好那些估得偏高、 恰好接近 {{m: f}} 的方法 —— 也就是偏好把 DNA 比例當純度回報的方法。 此偏誤不會在任何內部一致性檢查中顯現。

可行的做法有二：其一，在此類資料上只評比 {{m: f}}， 並將 {{m: p}} 與 {{m: κ}} 列為未經真值驗證的輸出； 其二，另行取得來源細胞株的倍體，並在報告中載明該倍體的來源與不確定性。 兩者皆可接受，但必須擇一言明，而不是把標示值直接當作 {{m: p}}。

{{/ask}}

可行的開發順序

前述四項缺口彼此有依賴關係，故順序不是任意的。 在四格表建起來之前擬合整個模型，得到的殘差無法歸因； 在無雜訊式子未經模擬驗證之前談效能，量到的是實作錯誤而非方法極限。

  1. 先建計數。位點層級的四格表，以及以深度與 germline 等位獨立分段的兩條軌道。 此步不涉及任何模型選擇，可單獨驗證。
  2. 以模擬驗證無雜訊式子。由已知的 {{m: (p, n_1, n_2, c, μ)}} 生成計數， 確認第二節與第五節的式子可被反解回原值。此步失敗即為實作錯誤，與方法無關。
  3. 再寫階層式似然。深度、germline 等位、somatic 等位三項， 加上 {{m: c_i}}、{{m: μ_i}}、標記錯誤率與偵測機率的先驗。
  4. 加倍未定時回報多個模式，而非挑一個。
  5. 掃過參數空間做模擬：純度、倍體、加倍時序、subclonal 拷貝數變異、 突變負荷、phase switch 錯誤率、深度、讀長、[[TINC]]，以及兩個定序平台。
  6. 分開評比，不要混為一談： {{m: f}} 用 held-out 的混合樣本與現行迴歸直接比； {{m: (p, κ)}} 只能在另有流式細胞術、DNA 指數或核型等佐證的樣本上比； 而校準度（區間涵蓋率、失敗率、加倍模式的正確率）須單獨報告 —— MAE 與 {{m: R^2}} 不涵蓋這一項。

尚未解決的問題

  • 整條路線尚未經實測。上述各項皆有代數上的依據，但均未在真實資料上檢驗。 最小的驗證為第二節的閉式：取二倍體且拷貝數正常的區段， 比對 {{m: 1/(2 − p)}} 與實測的 GHIR 分布，確認閉式與資料相符， 再據以檢查現行迴歸的殘差是否確為折疊與拷貝數兩項所致。
  • 分層與估計互為前提。{{m: s}} 的分層需要可靠的每段 {{m: (n_1, n_2)}}， 而後者正是要一併估計的量。此為典型的交替最佳化問題， 其收斂性與初始值的敏感度未知，須以模擬檢驗。
  • 低 DNA 比例時的偏誤未量化。somatic 標籤的 recall 在該區間下降， 而該區間恰為本主題最關切者。recall 曲線須先量測，否則錨在低純度時系統性低估。
  • 跨 block 的等位特異拷貝數軌道。單倍型標號逐 block 獨立， 故沿染色體連續的拷貝數輪廓需要另一層連結。 {{m: κ}} 與 {{m: p}} 不受此限，但「這一段是 2+0 還是 0+2」在跨 block 之後無定義。
  • {{m: p}} 與 {{m: κ}} 沒有乾淨的真值。前一節所述的三項驗證皆為間接。 此為本主題最缺乏的條件，且不因方法改良而改善。
  • 與 subclone 重建共用 {{m: c}}。本頁的 {{m: c}} 與該主題的細胞比例為同一個量， 兩處的估計理應一致。目前兩者各自獨立，未曾互相檢驗 —— 而互相檢驗本身即為一項不需金標準的驗證。
