為什麼重要

本模組比較兩種分析設計：有配對正常樣本的 tumor–normal（TN）模式， 以及只有腫瘤樣本的 tumor-only（TO）模式。是否有 matched normal 會改變可用的對照證據與不確定性。

差異不只是少一個輸入檔案；它會改變可辨識的變異類型與後續判讀方式。

概念與互動

配對正常樣本在做什麼

在 paired tumor–normal calling 中，[[somatic variant]] 候選通常指腫瘤中有支持、 而 matching normal 未觀察到足夠支持的變異。判讀仍需考慮污染、coverage、copy number 與 caller uncertainty：

  • 兩邊都有支持 → 優先考慮 [[germline variant]] 或其他 non-somatic，依品質與模型條件判斷
  • 只有腫瘤有支持 → 列為 somatic candidate，仍不是最終答案

caller 產生的是 [[candidate|候選變異]]，還不是最終答案；這是 [[tumour-normal]]（TN）模式的基本框架。 本教材以 [[ClairS]]、[[DeepSomatic]] 作為 tumor–normal calling 範例，實際輸入與過濾流程請依版本文件確認。

沒有正常樣本的時候

在部分臨床或研究情境，matched normal 可能因成本、檢體量或取得條件而缺失。 此時可採用 [[tumour-only]]（TO）分析，但可用的 germline 對照較少。

沒有正常組織時，改用什麼當對照

替代方案可使用公開的族群資料庫，利用 allele frequency 與已知變異紀錄提供 germline 線索。 符合指定頻率、品質與 annotation 條件的候選可作為排除依據，但不能無條件排除資料庫中的所有項目。

本教材在 LongPhase-TO／ClairS-TO 情境中將這組資料庫集合稱為 [[PON]]（population database set）。 它包含 1000 Genomes、gnomAD、dbSNP 等來源；在 GATK Mutect2 語境，PoN 通常指由多個正常樣本建立的 recurrent-artifact panel，兩者需明確區分。

問題出在「族群常見」與「這個人有」不是同一件事。下圖把兩種做法並排比較：

兩類資料都無法完整涵蓋以下情況：

  • 無法保證辨識某個病人私有的 germline 變異（族群中罕見，資料庫可能未收錄）
  • 無法保證辨識尚未觀察過的技術性 artifact

上述候選可能被誤判為 somatic，進而降低 [[precision]]。 後續方法會加入 phasing 與 read-level 結構訊號，作為資料庫之外的補充證據。

TN calling 的實務限制

前述 TN 流程是簡化描述；實務上不能只以兩個 VCF 的差集判定 somatic。

{{guard:6 | matched-normal calling 不是把兩個 VCF 相減}}

以下因素都可能使直接差集判定失準：

  • [[TINC]]（tumour-in-normal contamination）—— matched normal 中存在腫瘤來源訊號。 真正的 somatic 變異可能在 normal 中呈現低頻支持；若採用「normal 有訊號即排除」的規則，可能誤刪候選。
  • coverage 不對等 —— 若 normal coverage 較低（例如約 25×），somatic 變異在 normal 中未被觀察到， 可能只是深度不足，不代表它不存在。
  • [[copy number]] 造成的 allelic imbalance —— 讓 VAF 偏離預期，判斷門檻要跟著調。
  • caller 本身的不確定性 —— 兩邊的 caller 都可能漏掉或多報。

第一項可用下圖示意，提醒 paired normal 仍可能因污染而誤判：

{{svg:m07-tinc | [wide] 左：示意 matched normal 未觀察到腫瘤來源訊號；右：normal 中含有少量腫瘤來源 DNA，使同一位置出現低頻支持。若採用「normal 有訊號即排除」的簡化規則，可能誤刪 genuine somatic candidate；實際 VAF 取決於 depth、污染比例、copy number 與 variant multiplicity。}}

VAF 可作為輔助訊息：簡單 diploid heterozygous germline 變異常接近 0.5，污染訊號可能較低； 但實際值取決於 purity、copy number、zygosity、multiplicity、clonality 與 depth。 因此不能只用「有沒有訊號」或固定門檻判定。

即使有配對正常樣本，仍需要結合多項品質與模型過濾條件。

{{/guard}}

一句話總結

tumor-only 的核心困難

配對正常樣本提供病人的 germline 對照；population database set 主要提供族群層級的 germline 證據。未涵蓋的 private germline 或尚未觀察到的 artifact 可能保留為額外候選，其中部分會成為 false positive，需結合其他證據判讀。

資料庫無法涵蓋所有個體特異變異，因此可加入 read-level phase／連結結構、 copy number、LOH 與品質等補充證據。在理想化的 [[triplet graph]] 示例中，這些資訊可能呈現 不同 pattern；但系統性 artifact 或 phasing error 仍可能造成例外，因此此結構只能作為補充證據，不能單獨定案。

{{reveal}}

VAF 約 0.5 且未被族群資料庫涵蓋時，可優先考慮 private germline， 但不能排除 somatic 或其他來源。

在簡化的 diploid、單拷貝模型下，somatic VAF 可近似為 purity／2； 較一般的模型還受 purity、multiplicity 與 total copy number 影響，並會受到 normal DNA、 clonality、mapping bias 與 depth 影響，因此不能單獨依 VAF 分類。

應再檢查 read-level phase／連結結構、copy number、LOH、品質與獨立證據。 [[triplet graph]] 中的三種 pattern 是理想化示例，實務資料未必能完全區分， 系統性 artifact 或 phasing error 也可能造成例外。

比較兩種 calling 設計的結果

此練習比較 paired 與 tumor-only 的輸出差異。若有配對資料，可在相同參考序列與 相近過濾設定下執行兩種模式，再比較結果：

{{cli}} # 配對模式找到、而僅腫瘤模式未找到的候選（數量依資料與設定而異） bcftools isec -C paired.vcf.gz tumoronly.vcf.gz | wc -l # 僅腫瘤模式多出的候選（可能包含 private germline、artifact 或 paired caller 漏報） bcftools isec -C tumoronly.vcf.gz paired.vcf.gz | wc -l # 查詢多出候選在 normal 中的 VAF # VAF 接近 0.5 時，可優先檢查 private germline 的可能性 {{/cli}}

最後一步是檢查多出的候選在正常樣本中的 VAF，並同時查看 depth、copy number、 purity、mapping／base quality 與 caller evidence。VAF 接近 0.5 可提示 private germline， 但仍需排除污染、比對偏差與其他模型不確定性，不能僅依此一項證據定案。
