為什麼重要

中篇確立了三件事：僅以 VAF 頻率譜重建時， 群數 K 不可辨識、峰寬 φ 與 K 不可區辨、 成分位置 c 依賴三個外部估計值； 而多變異區域的觀測正好各補一格，且三者作用在同一組變數 {{m: z}}、{{m: φ}}、{{m: c}} 上。

本頁做兩件事。其一，把三者合成一條估計式 —— 中篇說明的是每個用途作用在哪裡，本頁寫出合起來長什麼樣， 並處理一個中篇尚未碰的問題：數百個單位的局部拓撲形狀各不相同，它們如何合併。

其二，處理那條估計式能不能真的建起來。 第二項所需的約束 {{m: R_r}} 不是憑空取得的，它們來自現行實作對每個 「區域 × [[somatic haplotype|單倍型家族]]」（以下簡稱一個單位）的分類。 而直接採用那些分類會出事：真實輸出中有相當比例的判定是在證據不足下做出的， 錯誤的約束比缺少約束更為不利 —— 一條假的「不可同群」會迫使模型分出一個不存在的群， 且不留任何跡象。

因此本頁的順序是：先寫出估計式（第一節）， 再回頭處理約束的來源（第二節）、兩道品質閘門（第三、四節）、 兩類會產生假約束的誤讀（第五節）、權重（第六節）， 最後是產量與參數取捨（第七、八節）。

概念與互動

一、完整的估計式

中篇的三個用途各動一個參數：用途一約束 {{m: z}}、用途二把 {{m: φ}} 由待估改為代入、 用途三對 {{m: c}} 加一條等式。把三者疊加於中篇第一節那個混合式，即得此路線的完整形式。 先把兩個容易被省略的定義寫清楚：第一，峰的位置必須使用每個變異自己的拷貝數與 multiplicity；第二，Beta-binomial 的第三個參數不是含糊的「峰寬」，而是可換算為 Beta 分布 concentration 的 overdispersion。

{{eq}} θ_{mk} = E[VAF_m \mid z_m=k] = \frac{ρ · c_k · μ_m}{ρ · CN_m + 2(1 − ρ)} {{/eq}}

其中 {{m: ρ}} 是樣本純度、{{m: c_k}} 是第 {{m: k}} 群的 CCF、 {{m: CN_m}} 是變異所在腫瘤區段的總拷貝數、{{m: μ_m}} 是帶原細胞中該變異的 multiplicity。若該區段二倍體且 {{m: μ_m=1}}，才化簡為 {{m: θ_{mk}=ρc_k/2}}；這個化簡只適用於 copy-number-normal、單拷貝變異， 不能放回有 CN 或 LOH 的變異。

{{eq}} a_m \mid (d_m,z_m=k) \sim BetaBinomial(d_m;α_{mk},β_{mk}), \qquad α_{mk}=θ_{mk}κ_m,\quad β_{mk}=(1−θ_{mk})κ_m {{/eq}} {{eq}} \hat{φ}_m=\hat{φ}(d_m,CN_m),\qquad κ_m=\frac{1−\hat{φ}_m}{\hat{φ}_m},\qquad Var(a_m\mid d_m,z_m=k)=d_mθ_{mk}(1−θ_{mk})[1+(d_m−1)\hat{φ}_m] {{/eq}}

這裡以 {{m: φ=1/(κ+1)}} 定義 overdispersion，故 {{m: φ=0}} 是 binomial 極限，{{m: φ}} 越大代表同一深度下的額外抽樣變異越大。 {{m: \hat{φ}(d,CN)}} 不是一個全域常數：應在「read depth 分層 × 腫瘤 CN 分層」內， 以已知共享真實頻率的同單倍型變異估計，再以平滑或 shrinkage 借力處理稀疏 strata。 沒有足夠校準資料的 {{m: (d,CN)}} 格不得悄悄套用一個寬峰；應標為未知並做敏感度分析。

{{eq}} ℓ_comp(K,c,π,z,T) = \sum_{m} \log [ π_{z_m} · BBpmf(a_m \mid d_m,α_{m,z_m},β_{m,z_m}) ] + \sum_{r} ω_r · \log P(R_r \mid z,T) {{/eq}}

符號 {{m: ℓ_comp}} 刻意標成合成（composite）目標： {{m: a_m}} 與 {{m: R_r}} 往往由同一批 read 計算，兩項不是獨立資料集， 因此不能直接把這個和當成已證明的完整 joint likelihood。只有改為逐 read 建模、 再由同一個生成模型同時推出 VAF 與關係時，才可稱為完整 likelihood；目前規格應稱為 經校準的 composite/pseudo-likelihood，並以有效樣本數或留出單位校準 {{m: ω_r}}。

此處寫的是可實作的統計規格，不是已完成或已驗證的 estimator 程式。 以下各項定義的目的，是讓後續實作能逐項測試；在合成資料與真實重複資料通過末節所列驗證之前， 不得把 {{m: Score}} 的最大值當成已證實的生物學結論。

若 {{m: I_r(z,T)=1}} 表示候選解滿足第 {{m: r}} 條觀測關係， {{m: q_r=P(R_r\mid I_r=1)}}、{{m: ε_r=P(R_r\mid I_r=0)}} 且 {{m: q_r>ε_r}}，則軟關係模型明確為：

{{eq}} \log P(R_r\mid z,T)=I_r(z,T)\log q_r+[1−I_r(z,T)]\log ε_r {{/eq}}

所以 {{m: ω_r}} 不是把關係變成硬條件，而是把這條觀測的對數證據乘上可靠度： 違反相對於滿足少掉 {{m: ω_r\log(q_r/ε_r)}}。可將 {{m: ω_r}} 設為 {{m: 0≤ω_r≤1}} 的可信度（此時是 tempered pseudo-likelihood），或在 {{m: ω_r}} 為獨立重複觀測數時用整數權重；兩者都應在報告中區分。只有在 {{m: ε_r=0}} 且 {{m: ω_r>0}} 時才是數學上的硬約束；本提案不採此設定， 而是讓高信心關係近似硬、低信心關係可被其他證據推翻。

{{eq}} Score(K,Θ)=ℓ_comp(K,Θ)−\frac{1}{2}p_K\log M_eff+\log p(K), \qquad \hat{K}=\arg\max_K Score(K,\hat{Θ}_K) {{/eq}}

{{m: Θ=(c,π,z,T)}}；{{m: ρ}} 若已有外部純度估計則固定，否則須列為 一個全域 nuisance scalar 與 {{m: Θ}} 一併 profile。巢狀比值只能定出 {{m: c}} 的相對尺度， 不能憑空決定最後的絕對尺度。{{m: p_K}} 是在第 {{m: K}} 群下的自由參數數目， {{m: M_eff}} 是扣除同一 read／同一突變叢相關性後的有效觀測數， {{m: p(K)}} 是對群數的先驗（若不用先驗，可設為常數）。這個 BIC/先驗項不可省略： 關係限制只會砍掉不相容的候選解，並不會自己決定要不要多開一群；沒有此項，增加 {{m: K}} 可能只是在吸收錯誤關係或過度擬合。此處 {{m: BBpmf}} 是上一組 {{m: (α,β)}} 定義所對應的 beta-binomial PMF；{{m: \hat{Θ}_K}} 則是固定 {{m: K}} 後使 {{m: ℓ_comp}} 最大的解。上式是預先指定的選模規則； 若使用 composite likelihood，{{m: p_K}} 與 {{m: M_eff}} 必須以模擬或重抽樣校準， 不可直接照搬普通 likelihood 的 BIC 並宣稱具有同一套理論保證。

項來源與中篇第一節的差異
第一項95% 的區域（頻率） 即中篇第一節第二步，惟有兩處相異：{{m: z}} 不再被邊際化（{{m: \sum_{k}}} 已移除），改為受約束的對象；{{m: \hat{φ}_m=\hat{φ}(d_m,CN_m)}} 不再是自由參數，由用途二分層量測後代入
第二項5% 的區域（關係） {{m: R_r}} 為第 {{m: r}} 條觀測關係；{{m: ω_r}} 是經校準的可靠度／重複觀測權重，不是硬編碼開關

四種約束對應的形式為：

約束 {{m: R_r}}對估計式的形式備註
不可同群 {{m: (i, j)}}{{m: z_i ≠ z_j}}用途一，使 K 可辨識

此處採軟關係模型而非硬性條件。第三、四節的閘門雖可排除多數假約束，但無法完全排除； 將殘餘的不確定性納入 {{m: (q_r,ε_r,ω_r)}}，單一條錯誤觀測只增加有限的違反代價， 而不會像 {{m: ε_r=0}} 的硬性條件般直接迫使模型產生不存在的群。

推論方法為帶約束的 EM，或直接對 {{m: (T, c, z)}} 取樣。 輸出須載明每一組群配對由幾條約束支持； 未獲約束支持的關係係由 pigeonhole 與偏好補足，其狀態等同中篇第一節第四步，應予標示。

數百個單位的局部拓撲形狀不同 —— 這是預期，不是矛盾

中篇的說明均以單一個單位為例。實際上通過閘門的單位有數百個， 而它們的局部拓撲形狀各不相同：有的是一條線，有的是分岔，有的只有一個節點。 此現象本身不構成衝突。

{{svg:sr2-two-topologies | [wide] 延續中篇第三節那個例子（ρ、A、B、C 都不變），只加上第四群 D 與兩個單位。 上排是三份證據各自說了什麼 —— 注意頻率譜給的是一棵部分決定的樹，不是一棵完整的樹。 中排說明目標函數的兩項各自回答什麼、又各自不回答什麼。 下排是三者合起來時，相容的候選樹如何被砍到只剩一棵。}}

成因是每個單位只裝得下落在該視窗內的那幾個變異。 上圖的單位甲裝到的是 B 群與 C 群的變異，兩群互不包含，故其局部拓撲是分岔； 單位乙裝到的是 B 群與 D 群的變異，後者巢狀於前者，故其局部拓撲是一條線。 兩者皆為同一棵全域 clone tree 在不同變異子集上的投影 —— 形狀相異是因為子集相異，而非證據衝突。

合起來為什麼更準、解析度更高

關鍵在於認清頻率譜的輸出並不是一棵樹，而是一棵部分決定的樹。 本例中它換算出三群（{{m: 1.00 / 0.40 / 0.20}}），而這三群在 pigeonhole 之下 有兩棵樹同時通過：線性的 A → X → D，與分支的 A → {{m: \{X, D\}}}。 取兩棵的交集，才是頻率譜真正確定下來的東西：

頻率譜確定的頻率譜未定的
A 是根D 掛在 A 之下，還是掛在 X 之下
X 在 A 之下X 是一群，還是兩群被併起來的

兩個單位補的正是右欄那兩格，而且各補一格： 甲說「X 其實是兩群，且互不包含」，乙說「D 巢狀在其中一群之內」。 候選數因此逐步收斂 —— 這就是「合起來更好」的具體內容：

手上的證據相容的候選樹備註
只有頻率譜2 棵而且 {{m: K = 3}} 本身是錯的（少計一群）
＋ 甲3 棵{{m: K}} 先被修正為 4；在 4 群下若不加約束會有 7 棵，甲的「互不包含」砍到 3 棵
＋ 甲 ＋ 乙1 棵唯一解，即真實的樹

三項改變的性質並不相同，值得分開看：

改變來源性質
{{m: K}} 由 3 增為 4 甲的不可同群把 {{m: 0.12}} 那根峰拆開 解析度提升：多還原一個 subclone，而這是頻率單獨永遠達不到的 —— 兩群的 {{m: θ}} 本就相等
樹由兩棵並列變為唯一解 乙的祖先關係把 D 釘在 B 之下 準確度提升：原本那一棵由簡約性挑選，現在由資料決定
群間距不需純度即可定出 乙的巢狀比值 {{m: ϱ = 0.50}} {{m: ρ}} 退化為整體縮放（中篇第五節）

第二項尤其值得看清楚：「D 掛在 B 之下還是 C 之下」在頻率上永遠沒有答案。 B 與 C 的期望 VAF 完全相同，所以兩種掛法產生一模一樣的直方圖 —— 這不是精度問題，是中篇第三節那個不可辨識性換一個位置再出現一次。 單位乙的共現觀測是唯一回答得了的證據。

而三項改變都不需要先把兩個單位對齊： 甲約束的是 {{m: z_i ≠ z_j}}，乙約束的是 {{m: T}} 上的一條有向邊與 {{m: c}} 的一個比值， 兩者作用在同一組全域變數上，求解器同時滿足即可。 形狀不同從頭到尾都不是需要處理的問題。

最後一項精確度的保留：所謂「唯一」指的是樹的形狀唯一。 拆出來的兩群頻率相同，所以它們的標號可以整組對調而不影響任何約束 —— 編號本就是任意的，這與手動 phasing 練習裡 HP1／HP2 對調也算正確是同一回事。

由此導出一條實作規則，與第五節那條互為表裡： 可以合併的是約束，不是標籤。 局部標籤（HP1-1）僅在該區域內有定義，跨區域的同名標籤並非同一條， 故不得將局部拓撲拼接成一棵大樹。所要合併者是它們對 {{m: z}} 與 {{m: T}} 的限制 —— 而 {{m: z}} 與 {{m: T}} 本就只有一份，合併因此在估計式中自動完成， 不需要任何對齊步驟。

真正的矛盾並非形狀相異，而是整個約束集合找不到任何一組 {{m: (z, T)}} 能同時滿足。其形式有三：

形式例成因
直接對立一個單位給不可同群 {{m: (i, j)}}，另一個給必定同群 {{m: (i, j)}}其中一條為假，多為第三節的檢定力不足
違反傳遞性必定同群 {{m: (i, j)}}、必定同群 {{m: (j, k)}}，卻又不可同群 {{m: (i, k)}}同上，惟須三條方能顯現
祖先關係成環{{m: z_a → z_b → z_c → z_a}}任何樹皆不可能，通常是第四節的排序偏誤將分岔判為串接

處理方式已內建於估計式：由於約束是加權的軟證據項而非硬性條件， 求解器不會因矛盾而無解，它取總和最大的那組 {{m: (z, T)}}， 少數錯誤的約束被多數蓋過。此即本節開頭堅持採 {{m: (q_r,ε_r,ω_r)}} 而非硬性條件的理由。

而矛盾率本身是一個診斷量：它估計的是整條約束產線的錯誤率， 邏輯與第二節以「不相容單位」估計單倍型標記錯誤率相同，僅是提升至全域這一層。 報告應予載明。

惟此處有一個陷阱：矛盾率低不代表約束正確。 系統性偏誤（例如第四節的排序偏誤）會使錯誤的約束彼此一致 —— 它們朝同一方向偏，因而完全不互相矛盾，卻一併使結論偏移。 矛盾率只偵測得到隨機錯誤。

{{svg:sr2-flow | [wide] 完整流程共八步，其中四步沿用現行實作。 須新增者為兩道閘門、約束的信心值，以及最末的接合。 第五步為關鍵：錯誤的約束將迫使模型產生不存在的群。}}

二、約束的來源：現行實作的分類輸出

前六節建立機制，以下各節處理其可行性。首要問題是 {{m: R_r}} 的來源。 現行流程對每個單位所做的分類，已直接對應上述四種約束：

{{svg:rg-unit-classes | [wide] 三欄的邊際計數刻意設為相同，用以顯示僅憑邊際無法區分三者。 左欄為串接，給出有向的祖先關係；中欄為分岔，給出「不可同群」； 右欄四格皆非空為不相容，其性質為品質訊號而非生物學結果。}}
現行輸出對應的約束在全基因體尺度所決定的量
分岔（無分子同時帶有兩者）不可同群（軟；高信心時近似硬）強制拆峰，為用途一唯一的原料。惟 trans 會偽造此一格，見第五節
串接，且比值 {{m: ≈ 1}}必定同群（軟；高信心時近似硬）合併分散於不同區域的同一群。權重應為最低，理由見下
串接，且比值 {{m: < 1}}有向（軟）：A 群為 B 群的祖先群間先後次序，取代中篇第一節第四步的簡約性偏好
不相容（四格皆非空）不產生約束反向用於估計單倍型標記的錯誤率

「必定同群」與用途一的張力

上表第二列不宜直接採用。串接表示後者衍生自前者的譜系， 故兩群為巢狀關係；比值 {{m: ≈ 1}} 僅表示後者已接近取代前者。 然而「接近取代」不等同於同一群：兩者為兩個真實存在的 clone， 僅在頻率軸上不可分辨。而「頻率相等不等同於同群」正是中篇第三節的論點。 將其強制合併，等同於在用途一所欲分離之處主動合併，方向相反。

  • 「{{m: ≈ 1}}」須定為明確的容差，且該容差應由檢定力決定，而非任意設定的常數。 在跨越深度 {{m: n}} 之下，比值本身即帶有抽樣誤差； 唯有當「比值 {{m: < 1}}」在該 {{m: n}} 下本即可分辨、而觀測仍落於 1 附近時， 「{{m: ≈ 1}}」才承載資訊。{{m: n}} 較小時任何比值皆近似於 1， 此為解析度不足，不構成證據。
  • 其權重應為三種約束中最低者。不可同群與有向關係皆增加可辨識性； 必定同群為唯一降低可辨識性者。錯誤的不可同群將產生不存在的群； 錯誤的必定同群則使真實存在的群消失。後者更難察覺， 因為群數多出一個尚可能引起注意，少一個則不留任何異常跡象。

三、閘門一：單位的有效樣本數

四、閘門二：候選排序偏誤對「不可同群」的系統性損耗

第二道閘門較第一道隱蔽，且偏誤方向不利。 最小成本候選常不只一個，現行流程以 [[read-AF]] 的差值總和排序； 問題在於相加的項數由拓撲形狀決定：

{{svg:rg-score-bias | [wide] 三種形狀的祖先後代配對數分別為 3、1、0。 串接得到正分，星狀恆為 0 —— 故最小成本候選中同時存在此二形狀時，分支形狀恆不獲選。}}

其後果為：本應產出「不可同群」的單位，將改為產出「祖先關係」。 而「不可同群」為用途一唯一的原料， 因此該偏誤系統性地移除拆峰的能力，使中篇第三節所述的 K ＝ 2 得以維持。

修正方式為將差值總和改為似然：在該拓撲所施加的約束下擬合各節點的分子比例， 再比較最大化後的似然值。如此不同形狀所比較的是對同一組數字的解釋能力， 形狀本身不再決定勝負。

五、兩類會產生假約束的誤讀

兩者皆與相位有關，方向相反： 其一為相位資訊僅在 block 內有效，跨 block 即無定義； 其二為即使在 block 內相位解得正確，仍可能被解讀為錯誤的生物學。

{{svg:rg-block-spin | [wide] 上排為物理事實：兩條染色體拷貝各自連續。 中排為軟體輸出：block A 的 H1 對應拷貝 ①，block B 的 H1 對應拷貝 ② —— 兩個 H1 並非同一條。}} {{guard:13 | 不同 phase block 的 H1 不是同一條染色體}} 相位軟體在每個 block 內將 read 分為兩組並標記為 H1、H2， 但標號在各 block 內獨立決定。 可容許之處：約束所描述的是細胞的祖先關係，而非哪一條親源染色體帶有變異。 每條約束皆在單一單位內產生，故與標號方向無關，核心推論不受影響。 限制：任何將不同 block 的 H1 合併計算的判斷皆無意義，且不會產生錯誤訊息。 因此不得以「兩個變異皆位於 H1」作為兩者同群的依據 —— 跨 block 的 H1 並非同一條染色體。 由此可導出一條可實作為檢查程式的規則： 每一條約束皆須在單一單位內部產生，不得跨單位組合。 {{/guard}} {{guard:14 | trans 不等於分支演化}} 若兩個變異分別位於同一細胞的兩條染色體拷貝上（trans）， 則兩者永不出現於同一條分子。計數表因而呈現 00、10、01，而 11 一格為空 —— 此形態與兩群互不包含的 subclone 完全相同。 在約束的脈絡下此點尤為關鍵：它可能產出一條假的「不可同群」； 若把它錯誤地設成 {{m: ε_r=0}} 的硬性條件，才會直接迫使混合模型分出一個不存在的群。 本提案的 {{m: ε_r>0}} 軟模型允許頻率項與其他關係把它推翻。 現行流程已先依單倍型家族分組，此設計正確； 且相位使 cis／trans 在整個 phase block 內為已知 （即前一項所述的 block），而非僅在單一條 read 之內， 故此項誤讀的可處理範圍約為 read 跨距的一百倍。 {{/guard}}

三項須注意的事項

其一，0.909 為目前最強的結果。一個在更換 basecaller 後仍維持、 且能區分癌別的統計量，所承載的是真實訊號。因此加入閘門之後應重新計算此數值： 若維持或提升，表示閘門所濾除者為雜訊；若下降，則原本的 0.909 有一部分係由共同的覆蓋幾何所致。

其二，「分支類」的比例尚不可直接視為約束產量。 分岔的判定需要兩個單突變頂點皆存在，且雙突變頂點的缺席為可信 —— 後者正是閘門所檢驗的對象。故 6%–22% 為上限，而非實際可用量。

其三，有一項計數需要釐清。 各資料集的單位數總和為 71,955，而結論中引用的數值為 85,941。 兩者可能計數不同的對象，此點須在成文之前確認。

預測與結果檢視

{{ask}}

設閘門設定寬鬆時收得 5,000 條約束，設定嚴格時僅餘 300 條。 直觀上約束越多，混合模型所受的限制越強，結果應越好。 請問：寬鬆的設定是否較佳？

{{reveal}}

不一定，且很可能較差，因為約束的兩種錯誤代價並不對稱。

一條遺漏的約束，其代價為「原可確定的關係改由偏好補足」， 即退回第一節第四步的狀態，損失有限。

一條錯誤的「不可同群」，其代價為迫使混合模型分出一個不存在的群。 其機制為第三節的反向運作：{{m: z_i ≠ z_j}} 使正確的 {{m: K}} 不可行， 模型只能增加一個成分。 此錯誤不會自行顯現 —— 所分出的群具備頻率與變異，形態正常， 而下游的樹、演化次序與臨床解讀將一併錯誤，報告上不留任何異常跡象。

因此取捨並非「多與少」，而是「遺漏與虛構」，兩者代價相差甚大。 正確的做法為從嚴，並將殘餘的不確定性納入權重 {{m: ω_r}}， 而非採硬性條件 —— 經稀釋的單一條錯誤約束不足以改變結論。

閘門的實際強度可藉重現性外部檢驗： 在不同 basecaller、不同機構的同一細胞株上掃描一系列閘門嚴格度， 比較何者的群與樹最為一致。此檢驗不需金標準， 而金標準正是此領域最欠缺的條件。

{{/ask}}

尚未解決的問題

  • 整條路線尚未經實測驗證。上述各項皆有結構性的理由，但均未在真實資料上檢驗。 最小的驗證即第三節的數值例：合成 ρ ＝ 0.60、CCF 分別為 1.00／0.40／0.40 的三群， 確認僅用 VAF 的分群必然給出 {{m: K = 2}} 與線性樹， 再量測需要多少條約束、閘門需多嚴格，方能正確分離而不誤拆。
  • 用途二需要同一條單倍型上存在多個變異，而該條件對應的正是最稀缺的區域。 低突變負荷時 {{m: \hat{φ}(d,CN)}} 可能無法估計，此時用途二失效，僅餘用途一與用途三。
  • 約束的來源具有偏性。它們僅來自變異密集的區域， 而變異密集有時並非偶然：kataegis 為一種局部超突變， 單次事件於數十 kb 內產生一連串變異。 該串變異幾乎必然同時發生且同屬一群，故將貢獻大量高度相關的約束， 在統計上卻被計為數十個獨立觀測。應先偵測並降權為每叢一個有效觀測。
  • 一個群未必對應單一細胞群體。本實驗室的甲基化觀測顯示： 單一個「單倍型 ＋ 等位」狀態之下仍可區分出五群甲基化模式。 故 {{m: K}} 的正確讀法恆為「至少此數」。
  • 超出 read 跨距的關係仍不可觀測。相距 100 kb 的兩個變異無法產生約束， 與定序深度無關；第八節的三層結構為此設下硬上限。
