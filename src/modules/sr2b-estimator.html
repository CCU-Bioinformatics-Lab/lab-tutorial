為什麼重要

中篇確立了三件事：僅以 VAF 頻率譜重建時， 群數 K 不可辨識、峰寬 φ 與 K 不可區辨、 成分位置 c 依賴三個外部估計值； 而多變異連鎖視窗的觀測正好各補一格，且三者作用在同一組待估量上： 突變屬於哪一群的指派 {{m: z}}、額外離散度 {{m: φ}}，以及各群的 CCF {{m: c}}。

把三者合起來的最直接寫法，是把頻率的對數似然與一串「關係約束」的對數證據 相加，再給每條關係一個權重。這個寫法有一個結構缺陷，而且它不是細節： 多變異連鎖視窗的 read 會被計兩次 —— 一次是它們各自的 VAF 進了頻率項， 一次是同一批分子被換算成關係又進了第二項。 兩項因此不是獨立的資料集，那個和也就不是一個 likelihood； 權重之所以必須存在，正是為了事後稀釋這個重複。

本頁採取另一條路，而它其實更簡單：不要把 read 換算成關係，直接對 read 建模。 把觀測依連鎖視窗切成互不重疊的兩類 —— 只有一個變異的連鎖視窗，與兩個以上變異的連鎖區段 —— 兩類各寫一個因子，相乘即得完整的 likelihood。 單變異連鎖視窗那個因子正是原本的 beta-binomial； 多變異連鎖區段那個因子是同一個模型在多個位點上的一般形式。 兩者不是兩個模型；當連鎖區段只含一個變異時，這個 read 模型的邊界情形就是 beta-binomial。

這個改動的代價與收益都很集中。收益是：權重、關係的可信度、以及為了保護硬約束而設的門檻 全部不需要了，因為證據強弱本來就是似然自己會算的東西。 代價是：觀測通道必須寫完整 —— 逐位點的定序錯誤與整條分子的家族誤標形狀不同， 少寫一種，錯誤造出來的少數幾條 read 就會被讀成一個新的 clone。

因此本頁的順序是：先寫出估計式（第一節），再逐層寫出多變異連鎖區段的生成過程 （第二節）與它的預設抽樣分布（第三節）；接著處理三種不同的「沒有」（第四節）、 分類為何是輸出而不是輸入（第五節）、數百個連鎖區段如何合併（第六節）； 最後是現行實作要改的兩處（第七節）、兩類與相位有關的誤讀（第八節）、 產量與參數取捨（第九、十節）與實作分期（第十一節）。

概念與互動

一、從一個變異走到完整的目標函數

先不要從最後一條長公式讀起。這個 estimator 只是在反覆回答一個問題： 若假設有 {{m: K}} 個突變群，哪一組群比例、clone tree 與突變指派，最能產生實際看到的 read，同時又沒有為了追逐雜訊而多開群？讀法可拆成四層：

層次輸入或問題這一層的輸出
1. 一個變異的資料總共 {{m: d_m}} 條 read，其中 {{m: a_m}} 條支持 alt觀測 VAF：{{m: \hat{VAF}_m=a_m/d_m}}
2. 生物狀態假設變異 {{m: m}} 屬於群 {{m: k}}該狀態預期的 VAF：{{m: θ_{mk}}}
3. 觀測機率預期 VAF 與校準過的離散度看到 {{m: a_m}} 的 beta-binomial 機率
4. 全資料比較把互不重疊的 read 證據各算一次資料配適度 − 複雜度代價 + 群數先驗

第一層：先分清楚觀測值、未知狀態與校準量

符號意思在 estimator 中的角色
{{m: m}}第 {{m: m}} 個 somatic variant資料索引
{{m: a_m}}在變異 {{m: m}} 支持 alt 的 read 數可觀測
{{m: d_m}}在變異 {{m: m}} 通過品質篩選的總 read depth可觀測，且 {{m: 0\le a_m\le d_m}}
{{m: K}}候選突變群的總數；{{m: k\in\{1,\ldots,K\}}} 是其中一群要比較的模型大小
{{m: z_m}}變異 {{m: m}} 被指派到哪一群未知的離散變數；{{m: z_m=k}} 表示指派到群 {{m: k}}
{{m: c_k}}第 {{m: k}} 群的 [[cancer cell fraction|CCF]]：帶有該群突變的腫瘤細胞比例由 clone 比例、tree 與指派共同決定

第二層：生物狀態先決定預期 VAF

{{eq}} θ_{mk}=E[VAF_m\mid z_m=k] =\frac{ρ·c_k·μ_m}{ρ·CN_m+2(1−ρ)} {{/eq}}

分子問的是「樣本中預期有多少份帶突變的 DNA」；分母問的是 「這個位置總共有多少份 DNA」。因此 {{m: θ_{mk}}} 不是新的觀測值，而是 在候選指派 {{m: z_m=k}} 成立時，模型預測的 VAF 中心。

例如變異 {{m: m}} 有 {{m: a_m=20}}、{{m: d_m=100}}，所以觀測 VAF 是 0.20。 若候選群的 {{m: c_k=0.50}}、純度 {{m: ρ=0.80}}、{{m: CN_m=2}}、{{m: μ_m=1}}， 模型預測 {{m: θ_{mk}=(0.8×0.5×1)/(0.8×2+0.2×2)=0.20}}，與資料吻合。 只把 {{m: CN_m}} 改成 4，預期 VAF 就降為約 0.11；所以同一群的變異也不必落在同一個原始 VAF。 只有二倍體且 {{m: μ_m=1}} 時，才可化簡成 {{m: θ_{mk}=ρc_k/2}}； 有 copy-number alteration 或 LOH 時不可使用這個捷徑。

第三層：beta-binomial 把「相差多少」換成機率

{{eq}} π_m\mid z_m=k\sim Beta(α_{mk},β_{mk}), \qquad a_m\mid(d_m,π_m)\sim Binomial(d_m,π_m) {{/eq}}

白話是先允許這一批分子的真實 alt 比例 {{m: π_m}} 在 {{m: θ_{mk}}} 周圍小幅變動，再由 {{m: d_m}} 條 read 抽出 alt count {{m: a_m}}。 把看不見的 {{m: π_m}} 積分掉，就得到：

{{eq}} a_m\mid(d_m,z_m=k)\sim BetaBinomial(d_m;α_{mk},β_{mk}), \qquad α_{mk}=θ_{mk}κ_m,\quad β_{mk}=(1−θ_{mk})κ_m {{/eq}}

這條式子的隨機結果是 alt count {{m: a_m}}；{{m: d_m}} 是已知的試驗次數。 {{m: θ_{mk}}} 控制中心，{{m: κ_m}} 是 Beta 分布的 concentration：越大表示 {{m: π_m}} 越集中在中心。為了讓「越大越寬」較直觀，本頁改用

{{eq}} φ_m=\frac{1}{κ_m+1}, \qquad Var(a_m\mid d_m,z_m=k)=d_mθ_{mk}(1−θ_{mk})[1+(d_m−1)φ_m] {{/eq}}

因此 {{m: φ_m=0}} 是普通 binomial 的極限；{{m: φ_m}} 越大，同一中心周圍可接受的 read-count 波動越大。它不是可任意調寬的「峰寬旋鈕」。實作使用 {{m: φ_m=\hat{φ}(d_m,CN_m)}}：在「read depth 分層 × 腫瘤 CN 分層」內用獨立校準資料估計， 再以平滑或 shrinkage 幫助稀疏 strata。沒有足夠資料的 {{m: (d,CN)}} 格要標為未知並做敏感度分析， 不可悄悄套用一個寬峰。

不要把這裡的 {{m: φ_m}} 與第三節的 {{m: τ_u}} 混在一起。 {{m: φ_m}} 描述跨獨立變異時單位點 alt count 的額外變異；{{m: τ_u}} 則是多變異連鎖區段內 整個狀態比例向量的 concentration，而且本頁稍後主張 PCR-free 長讀資料預設不需要額外的 {{m: τ_u}}。

第四層之一：全資料的 likelihood，讓每批 read 只出現一次

{{svg:sr2b-two-factors | [wide] 上半是相加的寫法：多變異連鎖視窗的 read 同時進了兩項， 所以那個和不是 likelihood，權重是為了修補重複計數才存在的。 下半把觀測切成互不重疊的兩類，兩個因子相乘即為完整的 likelihood，權重隨之消失。}} {{eq}} P(D\mid Θ_K)=∏_{m∈ S_1}P_{BB}(a_m\mid d_m,Θ_K) ·∏_{u∈ S_2}P_u(D_u\midΘ_K) {{/eq}}
符號這裡的精確意思
{{m: D}}送入 estimator 的全部 read 觀測
{{m: S_1}}只含一個變異、而且其 read 未進入任何多變異連鎖區段的變異集合
{{m: S_2}}含兩個以上變異的連鎖區段集合；{{m: u}} 是其中一個區段，{{m: k_u}} 是該區段的變異數
{{m: D_u}}連鎖區段 {{m: u}} 的逐條 read 觀測：覆蓋遮罩、ref／alt 狀態與家族標記
{{m: P_{BB}}}{{m: S_1}} 中一個單變異觀測的 beta-binomial 機率；中心與離散度已包含在參數中
{{m: P_u}}第二節才會展開的多變異聯合 read 模型；它也包含各位點的邊際 VAF
{{m: Θ_K}}固定群數 {{m: K}} 時所有待估狀態的縮寫

更完整地說，{{m: Θ_K}} 包含 clone 細胞比例 {{m: w}}、[[clone tree]] {{m: T}}、 突變指派 {{m: z}}、逐拷貝基因型 {{m: G}}、觀測錯誤參數 {{m: e}}，以及未被外部固定時的純度 {{m: ρ}}。 {{m: c_k}} 由 {{m: w}}、{{m: T}} 與 {{m: z}} 決定，{{m: μ_m}} 由 {{m: G}} 決定。 {{m: e}} 不是一個錯誤率，而是一組觀測通道參數的縮寫，包括稍後的逐位點錯誤 {{m: ε}} 與 連鎖區段家族誤標率 {{m: ξ_u}}。 外部提供的 copy number 與校準後的 {{m: \hat{φ}}} 是條件輸入，為了避免式子過長沒有逐項寫在條件線右側。

本式把 {{m: z}} 當作與其他參數共同最佳化的離散狀態，也就是輸出一組明確的突變指派。 若實作選擇把 {{m: z}} 邊際化，likelihood 必須改為對所有指派加總，模型選擇的校準也要跟著重做； 兩種推論方式不可在同一個 {{m: Score}} 裡混用。

成立的關鍵不是「{{m: S_1}} 與 {{m: S_2}} 兩個名字不同」，而是給定 {{m: Θ_K}} 後，兩者背後的 read 觀測可視為條件獨立且沒有交集。 若一批 read 已進入 {{m: D_u}}，它就不能再透過該位點的 {{m: a_m/d_m}} 進入第一個乘積。

要點在於 {{m: S_2}} 的因子已經包含那些變異的邊際 VAF： 若區段 {{m: u}} 含 {{m: k_u}} 個變異，一張 {{m: 2^{k_u}}} 格的聯合表沿任一個位點加總， 得到的就是該位點的 alt／ref 計數。 所以把多變異連鎖區段的變異再放回第一個乘積，就是把同一批 read 算第二次。

第四層之二：目標函數 = 配適資料 − 複雜度代價 + 先驗偏好

{{eq}} L_{data}(K,Θ_K) =\sum_{m∈ S_1}\log P_{BB}(a_m\mid d_m,Θ_K) +\sum_{u∈ S_2}\log P_u(D_u\midΘ_K) {{/eq}} {{eq}} Score(K,Θ_K)=L_{data}(K,Θ_K)−\frac{1}{2}p_K\log M_{eff}+\log p(K), \qquad \hat{Θ}_K=\arg\max_{Θ_K}L_{data}(K,Θ_K), \quad \hat K=\arg\max_{K\in\{1,\ldots,K_{max}\}} Score(K,\hat{Θ}_K) {{/eq}}
目標函數中的項白話問題數值變大時代表什麼
{{m: L_{data}(K,Θ_K)}}這個候選模型產生目前 read 資料的能力有多好？資料越支持這組群、tree 與指派
{{m: -\frac{1}{2}p_K\log M_{eff}}}為這個模型用了多少自由度？此項永遠是代價；{{m: K}} 或自由參數越多，扣分通常越大
{{m: \log p(K)}}分析前對群數 {{m: K}} 有何先驗偏好？先驗上較可信的群數得到較少懲罰

其中 {{m: K_{max}}} 是分析前指定的最大候選群數；{{m: p_K}} 是群數固定為 {{m: K}} 時真正被估計的自由參數數目； {{m: M_{eff}}} 是考慮同一突變叢與同一連鎖區段內相關性後的有效獨立資訊量， 不是把 read 或變異數直接代入；{{m: p(K)}} 是群數先驗。 先對每個候選 {{m: K}} 找到最佳的 {{m: \hat{Θ}_K}}，再比較其分數。 複雜度項不可省略，因為多開一群幾乎總能改善資料配適，卻可能只是在吸收錯誤。 {{m: M_{eff}}} 的定義必須在實作前固定並以模擬或 bootstrap 校準；若做不到，應改用預先指定的 held-out predictive score，而不是把未校準的 BIC 當成精確答案。

{{m: ρ}} 若已有外部純度估計就固定；否則把它列為全域 nuisance scalar， 對每個 {{m: K}} 與其他 {{m: Θ_K}} 一起 profile。局部的比值只能定出 {{m: c}} 的相對尺度， 不能憑空補出純度的絕對尺度。

此處寫的是可實作的統計規格，不是已完成或已驗證的 estimator 程式。 以下各項定義的目的，是讓後續實作能逐項測試；在合成資料與真實重複資料通過末節所列驗證之前， 不得把 {{m: Score}} 的最大值當成已證實的生物學結論。

二、一個多變異連鎖區段的生成模型

上式的 {{m: P_u(D_u \mid Θ_K)}} 是整份規格的核心。它必須從全域參數一路長到一條 read 上看到的字母，中間不能有任何自由參數 —— 一旦局部比例可以自己亂動， 這個連鎖區段就不再對全域參數施加任何限制，整條路線也就白做了。

{{svg:sr2b-emission | [wide] 五層各做一件事，中間沒有自由參數。 注意第二層：一個連鎖區段只看得到一條染色體拷貝，另一條在另一個連鎖區段裡 —— 這決定了第三層的分母該怎麼寫。第五層的部分覆蓋是邊際化，不是填成參考型。}}

連鎖區段、局部基因型與分子權重

一個連鎖區段 {{m: u}} 是一個單倍型連鎖區段：一個連鎖視窗 × 一條 [[somatic haplotype|單倍型家族]]。 這個切法很重要：它表示一個連鎖區段裡的 read 全部來自同一條染色體拷貝， 另一條拷貝屬於另一個連鎖區段。因此 不可以在連鎖區段內部再把兩條拷貝混起來寫成各佔一半 —— 那是尚未依家族分組時的寫法，用在已分組的資料上會把細胞比例整體算錯將近一倍。

設 clone {{m: g}} 在拷貝 {{m: b}} 上的全域基因型為 {{m: G_{g,b,m} ∈ \{0,1\}}}， 投影到連鎖區段 {{m: u}} 的那幾個位點，即得局部基因型 {{m: H_{ugb} ∈ \{0,1\}^{k_u}}}。基因型寫在拷貝這一層而不是 clone 這一層， 是為了讓 cis／trans 與 LOH 有地方表達。分子權重則為：

{{eq}} η_{ugb} = \frac{w_g · A_{ugb}}{\sum_{g'} w_{g'} · CN_{ug'}}, \qquad q_{u,h} = \sum_{g,b} η_{ugb} · 1(H_{ugb}=h) {{/eq}}

{{m: A_{ugb}}} 是該拷貝在此處的份數，{{m: CN_{ug}}} 是 clone {{m: g}} 在此處的總拷貝數。 分母是全部分子數，所以 {{m: \sum_{g,b} η_{ugb}=1}}。 拷貝數在這裡進入，不是事後乘上去的；LOH 時兩條同源染色體不再各佔一半， 這條式子自動處理。正常細胞是 {{m: w_0}} 那一項，{{m: CN=2}}， 其局部基因型恆為全參考；若所有細胞比例總和為 1，則純度是 {{m: ρ=1−w_0}}。 因此純度已經包含在細胞組成裡，不是事後再乘一次的換算因子。

要注意 {{m: q_{u,h}}} 是分子比例而非細胞比例，兩者差一個拷貝數因子。 中篇第五節那條「兩個非參考型的組相除、共同分母消去」的式子， 就是這裡任取兩格相除的結果 —— 用途三因此不是一條額外的等式約束，它是這個模型的一個推論。

覆蓋遮罩：沒覆蓋到的位點要邊際化

一條 read 只覆蓋連鎖區段裡的一部分位點。設其覆蓋遮罩為 {{m: M ⊆ J_u}}、觀測到的字母為 {{m: y ∈ \{0,1\}^{|M|}}}，則

{{eq}} q_{u,M}(y) = \sum_{h : h_M = y} q_{u,h} {{/eq}}

也就是把所有「在 {{m: M}} 上與 {{m: y}} 相符」的完整狀態加起來。 一條只看到第一與第三個位點、讀到 {{m: 1\text{–}1}} 的 read，同時支持 {{m: 101}} 與 {{m: 111}}。沒覆蓋到的位點不可以填成參考型 —— 那會把一條中立的 read 變成一條反對 {{m: 111}} 的證據。

一個連鎖區段一個 p，不是一個遮罩一個

同一個連鎖區段裡不同遮罩的 read 取樣的是同一池分子， 所以它們的比例是相關的。正確的寫法是讓整個連鎖區段共用一個潛在比例向量， 每條 read 各自從它自己的遮罩投影出來：

{{eq}} p_u \sim Dirichlet(τ_u · q_u), \qquad y_i \mid M_i, p_u \sim Categorical(Proj_{M_i}(p_u)) {{/eq}}

若改成「每個遮罩各自一個 Dirichlet-multinomial」， 等於宣稱不同遮罩的 read 來自互相獨立的分子池。那是一個 composite likelihood 近似，可以用，但必須如此稱呼， 而且它會低估同一連鎖區段內部的相關性。

觀測通道：兩種形狀不同的錯誤

{{m: q_u}} 是「還沒經過任何錯誤」的比例。實際觀測到的比例要再過一層：

{{svg:sr2b-mistag | [wide] 左右兩種錯誤的形狀不同：一種一次改一個字母，一種一次搬走整條分子。 位點差得越多，逐位點錯誤的機率掉得越快，而誤標完全不受位點數影響 —— 所以差三個位點時，能造出假狀態的幾乎只剩誤標這一條路。}} {{guard:19 | 逐位點錯誤與整條分子誤標不是同一件事}} 逐位點錯誤（basecalling、mapping／參考偏誤）一次只改一個字母，各位點獨立， 所以要造出一個差 {{m: r}} 個位點的狀態，機率約為 {{m: ε^r}}，隨差異位點數 {{m: r}} 急速下降。 整條分子的家族誤標（[[haplotagging]] 標錯家族）則是把另一個家族的一條分子整條搬過來， 它的所有位點一起改變，機率是單一個 {{m: ξ_u}}，與位點數無關。 後果：若模型只寫了逐位點錯誤，在全 {{m: 0}} 的背景上出現的 {{m: 111}} 在模型眼中是「錯誤造不出來的」（{{m: ε^3 ≈ 10^{−7}}}）， 於是只剩一個解釋 —— 一個新的 clone。而它真正的來源是隔壁那個家族。 {{m: k_u ≥ 2}} 時誤標就是主要的假狀態來源，這條寫漏會直接產生假的 subclone。 兩者都要就地估計、不得採用全域常數；家族誤標尤其要成對估計，因為它連結兩條通道。 {{/guard}} {{svg:rg-error-gates | [wide] 每個位點一道錯誤閘門；最末一道為家族交換閘門， 少部分分子被標至另一條通道。交換閘門連結兩條通道，故兩個家族必須一併估計。}}

HP1／HP2 的方向是 nuisance

連鎖區段的家族標號在每個 phase set 內獨立決定， 所以「這個連鎖區段的家族一」對應到全域基因型的哪一條拷貝 {{m: b}} 並不確定。 處理方式是引入一個局部方向變數 {{m: σ_u ∈ \{原樣, 對調\}}} 並把它邊際化：

{{eq}} P(D_u \mid Θ_K) = \sum_{σ_u} P(D_u \mid Θ_K, σ_u) · P(σ_u) {{/eq}}
作用域補充：{{m: σ}} 如何跨 phase set 定義

{{m: σ}} 是每個連鎖視窗一個， 不是每個連鎖區段一個 —— 同一個連鎖視窗的兩個家族互為補集，共用同一個方向。 若兩個 phase set 之間沒有共享的變異，也沒有其他錨點，而且相關 clone 的比例又相同， 則它們的對應關係真的不可辨識。此時正確的輸出是保留數個等價的對應， 而不是挑一個印出來。

三、預設是 multinomial：一條 read 是一個分子

上式寫了一個 {{m: τ_u}}，但它的預設值應該是無窮大，也就是退化成 multinomial。理由是 guardrail 第 7 條的直接後果：

beta-binomial 的 overdispersion 來自「分子池的真實比例偏離期望值」—— 那是一個兩段抽樣的結構：先從細胞抽出分子，再從分子抽出 read。 而 PCR-free 的長讀定序沒有第二段：一條 read 就是一條分子， 不存在同一條分子被讀到兩次的情形。細胞數又以百萬計， 第一段抽樣的變異小到可以忽略。所以在一個連鎖區段內部， read 的計數本來就是 multinomial，額外的離散度沒有來源。

這給出一條明確的實作規則：先用 multinomial，只有在殘差真的顯示額外離散時才加 {{m: τ_u}}，而且要說得出它來自哪裡（連鎖視窗內部的 mapping 或覆蓋不均， 而非分子抽樣）。{{m: τ_u}} 若要估，也必須跨可比較的連鎖區段分層借力 —— 一張稀疏的計數表沒有能力同時定出 {{m: q_u}} 與它自己的離散度。

順帶一提，這也讓中篇用途二的估計方式需要重新檢查。 用途二以「同一連鎖區段、同一條單倍型上數個變異之間的離散度」量測 {{m: φ}}。 但若這些變異位於同一批分子上，分子池的偏離是它們共有的， 在兩者相減時會消去 —— 剩下的只有各自的 read 抽樣與 base error。 這樣估出來的 {{m: \hat{φ}}} 會偏低，而偏低的 {{m: \hat{φ}}} 正好把 {{m: K}} 往上推，方向與這條路線想要的結論相同。 {{m: φ}} 應改由相距夠遠、分子池獨立的同群變異估計。

四、三種不同的「沒有」

{{svg:sr2b-zero-kinds | [wide] 三欄的觀測一模一樣，都是「這一格計數為 0」。 分得開它們的不是那個 0，而是跨越深度、其他連鎖區段的證據，與就地估到的錯誤率。 中間那條警告是這一節的關鍵：Dirichlet 的參數不可以是零。}} {{guard:20 | 一格是空的，有三種不同的成因}} 抽樣零：該狀態存在（{{m: q_h > 0}}），只是跨越這幾個位點的分子太少沒抽到。 沒抽到的機率是 {{m: (1−q_h)^n}}；{{m: n=3}}、{{m: q_h=0.3}} 時約為 {{m: 0.34}}， 所以「沒看到」幾乎沒有排除任何東西。 結構零：沒有任何 clone 帶這個基因型，{{m: q_h = 0}}。 這是要推論出來的結論，不是輸入。以門檻把它判定下來，等於把結論當成前提。 錯誤地板：基因型確實不存在，但定序錯誤與家族誤標仍會產生看起來像它的 read， 所以觀測比例有一個不為零的下界。 三者的觀測完全相同。混為一談的後果是：錯誤造出來的少數幾條 read 被讀成一個新的 clone。 {{/guard}}

第二種與第三種必須分開寫，還有一個純技術但無法迴避的理由： Dirichlet 的參數不可以是零。結構零給出 {{m: q_h=0}}， 而 {{m: τ q_h = 0}} 不是一個合法的 Dirichlet 分量。 所以結構零一定要先經過錯誤通道抬到地板之上：

{{eq}} q_{u,h}^{obs} = (1−ε_u) · q_{u,h} + ε_u · r_h {{/eq}}

這不是為了數值穩定而加的小常數。 它就是「零不代表不可能」這句話的數學形式 —— {{m: ε_u r_h}} 的大小正是這個連鎖區段能分辨的最小比例， 也就是第十節那個偵測下界的來源。若 {{m: r_h}} 由第二節的兩個錯誤通道算出來， 這個地板是可以就地估計的量，不需要另設參數。

六、數百個連鎖區段的局部形狀不同 —— 這是預期，不是矛盾

通過品質檢查的連鎖區段有數百個，而它們的局部拓撲形狀各不相同： 有的是一條線，有的是分岔，有的只有一個節點。此現象本身不構成衝突。

{{svg:sr2-two-topologies | [wide] 延續中篇第三節那個例子（ρ、A、B、C 都不變），只加上第四群 D 與兩個連鎖區段。 上排是三份證據各自說了什麼 —— 注意頻率譜給的是一棵部分決定的樹，不是一棵完整的樹。 中排說明目標函數的兩項各自回答什麼、又各自不回答什麼。 下排是三者合起來時，相容的候選樹如何被砍到只剩一棵。}}

成因是每個連鎖區段只裝得下落在該連鎖視窗內的那幾個變異。 上圖的連鎖區段甲裝到的是 B 群與 C 群的變異，兩群互不包含，故其局部形狀是分岔； 連鎖區段乙裝到的是 B 群與 D 群的變異，後者巢狀於前者，故其局部形狀是一條線。 兩者皆為同一棵全域 clone tree 在不同變異子集上的投影 —— 形狀相異是因為子集相異，而非證據衝突。

合起來為什麼更準、解析度更高

關鍵在於認清頻率譜的輸出並不是一棵樹，而是一棵部分決定的樹。 本例中它換算出三群（{{m: 1.00 / 0.40 / 0.20}}），而這三群在 [[pigeonhole]] 之下 有兩棵樹同時通過：線性的 A → X → D，與分支的 A → {{m: \{X, D\}}}。 取兩棵的交集，才是頻率譜真正確定下來的東西：

頻率譜確定的頻率譜未定的
A 是根D 掛在 A 之下，還是掛在 X 之下
X 在 A 之下X 是一群，還是兩群被併起來的

兩個連鎖區段補的正是右欄那兩格，而且各補一格： 甲的狀態表在「兩個突變同時出現」那一格只有錯誤地板的量，乙則相反。 候選數因此逐步收斂 —— 這就是「合起來更好」的具體內容：

手上的證據相容的候選樹備註
只有頻率譜2 棵而且 {{m: K = 3}} 本身是錯的（少計一群）
＋ 甲3 棵{{m: K}} 先被修正為 4；在 4 群下若無局部觀測會有 7 棵，甲砍到 3 棵
＋ 甲 ＋ 乙1 棵唯一解，即真實的樹

三項改變的性質並不相同，值得分開看：

改變來源性質
{{m: K}} 由 3 增為 4 甲那一格的空缺把 {{m: 0.12}} 那根峰拆開 解析度提升：多還原一個 subclone，而這是頻率單獨永遠達不到的 —— 兩群的 {{m: θ}} 本就相等
樹由兩棵並列變為唯一解 乙的巢狀狀態表把 D 釘在 B 之下 準確度提升：原本那一棵由簡約性挑選，現在由資料決定
群間距不需純度即可定出 乙的兩格相除，共同分母消去 {{m: ρ}} 退化為整體縮放（中篇第五節）

第二項尤其值得看清楚：「D 掛在 B 之下還是 C 之下」在頻率上永遠沒有答案。 B 與 C 的期望 VAF 完全相同，所以兩種掛法產生一模一樣的直方圖 —— 這不是精度問題，是中篇第三節那個不可辨識性換一個位置再出現一次。 連鎖區段乙的共現觀測是唯一回答得了的證據。

而三項改變都不需要先把兩個連鎖區段對齊： 兩個連鎖區段各自算出自己那張表的機率，而兩張表都由同一組 {{m: (w,T,z)}} 產生，相乘即完成合併。 形狀不同從頭到尾都不是需要處理的問題，而合併也不需要任何對齊步驟。

最後一項精確度的保留：所謂「唯一」指的是樹的形狀唯一。 拆出來的兩群頻率相同，所以它們的標號可以整組對調而不影響任何機率 —— 編號本就是任意的，這與手動 phasing 練習裡 HP1／HP2 對調也算正確是同一回事。

由此導出一條實作規則，與第八節那條互為表裡： 可以合併的是機率，不是標籤。 局部標籤（HP1-1）僅在該連鎖視窗內有定義，跨連鎖視窗的同名標籤並非同一條， 故不得將局部拓撲拼接成一棵大樹。所要合併者是它們對 {{m: (w,T,z)}} 的支持度 —— 而這組參數本就只有一份。

真正的矛盾長什麼樣

真正的矛盾並非形狀相異，而是整組連鎖區段找不到任何一組 {{m: (w,T,z)}} 能同時給出夠高的機率。在舊的硬約束寫法下，它會表現為三種無解形式； 在似然寫法下它不再讓求解器卡住，但仍然是必須報告的診斷量：

形式例成因
直接對立一個連鎖區段的表說兩者不共存，另一個說共存其中一個是抽樣零或錯誤地板被讀成結構零
違反傳遞性三個連鎖區段兩兩相容，合起來卻無解同上，惟須三個連鎖區段方能顯現
祖先關係成環{{m: z_a → z_b → z_c → z_a}}任何樹皆不可能，通常是第七節的排序偏誤將分岔判為串接

處理方式已內建：由於沒有任何一格的機率是 0， 求解器不會因矛盾而無解，它取總機率最大的那組參數，少數異常的連鎖區段被多數蓋過。 此即第四節堅持要有錯誤地板的理由 —— 那個地板同時是「零不代表不可能」與 「矛盾不會炸掉求解器」這兩件事的來源。

而殘差本身是一個診斷量：擬合後各連鎖區段的狀態表與模型預測的差距， 估計的是整條產線的錯誤率，邏輯與以「不相容連鎖區段」估計單倍型標記錯誤率相同， 僅是提升至全域這一層。報告應予載明。

惟此處有一個陷阱：殘差小不代表模型正確。 系統性偏誤（例如第七節的排序偏誤）會使錯誤彼此一致 —— 它們朝同一方向偏，因而完全不互相矛盾，卻一併使結論偏移。 殘差只偵測得到隨機錯誤。

對一半。門檻確實不需要了，但有一件事變得更重要，不是更不重要。

舊寫法必須設門檻，是因為一條由 {{m: n=3}} 產生的假「不可同群」 會迫使混合模型分出一個不存在的群，而且不留任何跡象。 新寫法沒有這個失效模式：沒有任何一格的機率是 0， 一個 {{m: n=3}} 的連鎖區段算出來的似然差異本來就很小。這一半是對的。

但代價轉移到了錯誤地板身上。地板由第二節的兩個錯誤通道決定， 而地板訂錯的後果與舊寫法的假約束一樣嚴重、一樣安靜：

  • 地板訂得太低（例如只寫了逐位點錯誤、漏了家族誤標）： 誤標造出來的少數幾條 read 在模型眼中變成「錯誤不可能產生」， 於是被解釋成一個新的 clone。這正是舊寫法那個失效模式換一個位置再出現一次。
  • 地板訂得太高：真實的低頻 subclone 被吸進地板，{{m: K}} 少算。 這一種更難察覺，因為群數少一個不會引起任何注意。

所以取捨並沒有消失，只是從「要不要相信這條約束」變成「錯誤率估得準不準」。 好消息是後者是一個可以就地量測的量（不相容連鎖區段的比例、 同一連鎖區段內互斥狀態的共現率），而前者從來都不是。 這正是改寫的實際收益：把一個靠判斷的旋鈕，換成一個可以估計的參數。

實際強度仍應藉重現性外部檢驗： 在不同 basecaller、不同機構的同一細胞株上掃描一系列錯誤率設定， 比較何者的群與樹最為一致。此檢驗不需金標準， 而金標準正是此領域最欠缺的條件。

  • 整條路線尚未經實測驗證。上述各項皆有結構性的理由，但均未在真實資料上檢驗。 最小的驗證即中篇第三節的數值例：合成 ρ ＝ 0.60、CCF 分別為 1.00／0.40／0.40 的三群， 確認僅用 VAF 的分群必然給出 {{m: K = 2}} 與線性樹， 再量測需要多少個多變異連鎖區段、錯誤率要估得多準，方能正確分離而不誤拆。

  • 連鎖區段的來源具有偏性。它們僅來自變異密集的連鎖視窗， 而變異密集有時並非偶然：kataegis 為一種局部超突變， 單次事件於數十 kb 內產生一連串變異。 該串變異幾乎必然同時發生且同屬一群，故將貢獻大量高度相關的證據， 在統計上卻被計為數十個獨立觀測。應先偵測並降權為每叢一個有效觀測。
  • 一個群未必對應單一細胞群體。本實驗室的甲基化觀測顯示： 單一個「單倍型 ＋ 等位」狀態之下仍可區分出五群甲基化模式。 故 {{m: K}} 的正確讀法恆為「至少此數」。
  • 超出 read 跨距的關係仍不可觀測。相距 100 kb 的兩個變異無法落入同一個連鎖區段， 與定序深度無關；第七節的三層結構為此設下硬上限。
