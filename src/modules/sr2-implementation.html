為什麼重要

上篇的結論是一個沒有解決的僵局。VAF 與甲基化 β 值都是 [[marginal distribution|邊際分布]]，而 [[clone tree]] 需要的是 [[joint distribution|聯合分布]]；長讀把聯合分布變成直接觀測，但那只在一條 read 的跨距內成立。

本實驗室已經有一套實作在跑這條路線：以「區域 × [[somatic haplotype|單倍型家族]]」為單位， 把每條 read 在該區域各 somatic 位點上的 R／A 讀出來建成狀態表， 再找最少步數、能走到所有觀測狀態的樹。這一頁不是要換掉它， 而是把它已經量到的東西看清楚，然後指出三個要改的地方。

起點是一件從真實資料才看得出來的事。

{{svg:rg-partial-reads | [wide] 這是一個真實單位的覆蓋統計。 八成的 read 只看得到三個位點裡的一個 —— 它對「兩個位點的共現」完全沒有意見。 把同一批 read 按位點對拆開之後才看得出來：這個單位的樹靠的是 17 與 20 兩個數字，不是 194， 而其中一對根本沒有資料，卻一樣被決定了關係。}}

這件事推翻了一個很自然的假設。一個單位的資料不是一份跨 k 個位點的聯合樣本， 而是一組各自獨立、大小差很多的「位點對」子樣本。整頁其餘部分都是這句話的後果：

  1. 缺席要有證據撐著。「沒看到某個狀態」有兩種原因 —— 真的沒有那種細胞， 或根本沒有 read 跨得到。目前的做法把兩者當成同一件事。 這是唯一會系統性製造假結論的地方，所以是第一優先。
  2. 類別比例還混著幾何。串接與分岔被偵測到的機率本來就不一樣， 而且都隨兩個變異的距離變化。所以現在量到的拓撲類別分布，有一部分是讀長造成的，不是腫瘤造成的。
  3. 頻率放錯位置了。它不該是被分箱的對象 —— 那需要每個單位都有夠密的聯合觀測，而事實上沒有。它該是在單位內部排序候選拓撲的似然。

這一頁不是教材。它假設你讀完上篇，處理的是「這個模型哪裡會壞、怎麼修」， 所以給的是式子、參數與失敗模式。範圍限定在單倍型；甲基化只在最後出現一次， 而且是當成「一個拓撲節點不見得只有一群細胞」的限制，不是一條資料通道。

概念與互動

一、三層資訊：範圍愈小，資訊愈完整

{{svg:rg-three-tiers | [wide] read 跨距限制的是「數不數得到共現分子」， [[phase block]] 限制的是「知不知道兩個位點在不在同一條染色體上」。 後者的範圍比前者大約一百倍 —— 相位是靠 germline 雜合位點串起來的， 所以兩個相距 800 kb 的 somatic 位點即使沒有任何一條 read 同時蓋到，它們是 cis 還是 trans 仍然是已知的。}}

二、H1 與 H2 的標號只在同一個 block 內有意義

相位軟體在每個 block 內把 read 分成兩堆並標上 H1、H2， 但標號在每個 block 內獨立決定。把每個 block 的標號方向寫成一個正負號 σ， 可觀測的資料在所有 σ 的翻轉下完全不變。

{{svg:rg-block-spin | [wide] 上排是實體事實：兩條染色體拷貝各自連續。 中排是軟體輸出：block A 的 H1 對應拷貝 ①，block B 的 H1 對應拷貝 ② —— 兩個 H1 不是同一條。 下排分開列出不受影響的與會出錯的。}} {{guard:13 | 不同 phase block 的 H1 不是同一條染色體}} 這件事有一半是好消息、一半是壞消息，兩半都要記住。 好消息：clone tree 談的是細胞的祖先關係，不是哪一條親源染色體帶著變異。 每個單位內部算出來的量都與 σ 無關，所以核心推論可以直接對 σ 邊際化 —— 成本是零。 現行流程的鍵值已經含 phase set，這一點是對的。 壞消息：任何把不同 block 的 H1 加總在一起的統計都沒有意義，而且不會有任何錯誤訊息。 跨 block 的單倍型特異拷貝數、跨 block 比較甲基化偏向，都要先定出 σ 才能講。 由此得到一條可以寫成檢查程式的設計規則： 所有全基因體統計都必須只由「單位內部的量」組成。 本頁第九節那四個頻譜全部滿足這一條。 {{/guard}}

三、觀測模型：部分觀測是常態，不是例外

分析單位的鍵值是 (染色體, PS, 視窗, 家族)。 單位裡每條 read 給的不是一個完整的 k 維向量，而是一個覆蓋集合，加上該集合上的等位：

Or⊆ {1,…,k} ， x∈ {0,1} |Or|

所以一個單位的資料是「一堆不同階數的邊際表」，不是一張聯合表。 上面那個真實例子裡，一階表裝了 82.5% 的 read，三階表只有 3 條。

關鍵的衍生量是逐對跨越深度 —— 有幾條 read 同時蓋到位點 i 與 j：

E[nij] ≈ D⁢ E[ (L−dij) + ] E[L]

D 是該家族深度，L 是 read 跨距分布，d_ij 是兩個位點的距離。 跨越深度隨距離衰減 —— 前面例子裡的 20、17、3 不是雜訊，是幾何。

還有一件事要先講清楚：部分觀測支撐的是超立方體的一個「面」，不是一個頂點。 一條在位點 1 讀到 A、位點 2 沒蓋到的 read，同時相容於 10 與 11 —— 它分不出串接與分岔。把好幾條部分 read 的面交集起來得到的頂點是推論出來的， 不該和「有一條完整 read 直接看到」的頂點放在同一個信心層級。

錯誤模型本身不變，仍然是每個位點一道閘門，加上兩個家族之間的交換：

{{svg:rg-error-gates | [wide] 兩條並排的通道是同一個視窗的兩個家族。 每個位點一道錯誤閘門；最後一道是家族交換閘門，一小部分分子被標到另一條通道去（交叉的虛線）。 交換閘門把兩條通道接在一起，所以兩個家族必須一起估。}}

四、缺席要有證據撐著：逐對檢定力閘門

這是本頁最重要、也最該先做的一項修正。

{{svg:rg-pairwise-gate | [wide] 左邊是跨越深度隨距離衰減，圖上標出真實例子的三個位點對。 右邊是問題本身：「這個狀態沒出現」有兩種完全不同的原因，而目前的解法把兩者當成同一件事。 下方是修正 —— 每一對先用自己的跨越深度算檢定力，不足的標成「未定」，不允許它的缺席去約束樹。}}

用真實數字看它有多嚴重。前面那個例子裡 n₁₃ = 3， 而演算法照樣對 S1 與 S3 的關係下了結論。假設那條譜系裡有三成的分子帶著該狀態， 三條 read 全部錯過的機率是 0.7³ ≈ 0.34 —— 三分之一的機率會把「有」看成「沒有」，而輸出看起來跟一個可靠的結論沒有兩樣。

預期效果要先講出來，這樣才驗證得了： 目前被歸進單層無分支的單位（各資料集 19.5%–46.8%）應該有一部分正確地移到未解析 —— 因為那一類正是「觀測到的狀態很少」的單位，而狀態少的原因可能只是沒有 read 跨得到。

五、一個 k＝2 單位只會落入三類

{{svg:rg-unit-classes | [wide] 三欄的邊際計數刻意做成一樣 —— 重點正是「光看邊際分不出來」。 但要注意：這三類能不能分出來，前提是那一對有足夠的跨越深度。第四節那道閘門就是在守這件事。}} {{guard:14 | trans 不等於分支演化}} 兩個變異若分別落在同一個細胞的兩條染色體拷貝上（trans）， 它們永遠不可能出現在同一條分子上。於是計數表會呈現 00、10、01，而 11 那一格是空的 —— 跟兩群互不包含的 subclone 長得一模一樣。 所以「直接從 read 的組成建樹」如果沒有先按單倍型家族分堆， 會系統性地把同一個細胞裡的兩個變異判成分支演化。現行流程有先分家族，這一點是對的。 而且相位讓 cis／trans 在整個 phase block 內都是已知的，不是只在一條 read 之內 —— 這個陷阱的可解範圍比 read 跨距大約一百倍。 {{/guard}}

六、狀態集合 → 候選拓撲：最小成本就是最少潛在節點

現行流程用 Camin–Sokal 簡約假設：單點突變、單一固定根（全參考型）、 只允許 0→1、每個非根節點恰有一個父節點、邊成本都是 1。在這組假設下：

cost(T)= |E|= |V|−1= C+|H|−1

C 是固定節點數（根 ＋ 保留的觀測狀態），|H| 是為了連通而補進去的潛在節點數。 C 固定時，最小成本等價於最少潛在節點，搜尋問題就是超立方體上的最小成本 Steiner 樹形圖。

{{svg:rg-steiner-latent | [wide] 只觀測到 00 與 11 時，中間一定要補一個狀態， 但補 10 還是補 01 資料沒有意見 —— 於是得到兩個並列的最小成本候選，兩個都要留著。 潛在節點數本身就是一個值得統計的量：它數的是「這棵樹需要、但沒有任何觀測支持」的狀態。}}

這正是上篇重要區分 #9 講的 [[latent node]]，只是現在它有了數字。 把全基因體的 |H| 分布畫出來，就是「這份重建有多少比例來自推論」的直接量度 —— 而求解器本來就算出來了，它就是成本。

七、排序：差值總和有形狀偏誤

最小成本候選常常不只一個。現行流程用 [[read-AF]] 的差值總和排序： 把樹上每一組「祖先 → 後代」的 read-AF 相減再全部加起來，取最高分。 方向是對的 —— 先發生的變異應該出現在更多分子上。問題出在相加的項數由形狀決定。

{{svg:rg-score-bias | [wide] 三個形狀的祖先後代配對數分別是 3、1、0。 串接得到正分，星狀恆等於 0 —— 所以最小成本候選裡同時有這兩種形狀時，分支永遠贏不了。 而觀測到最多的類別正好是「多層無分支」，這個偏誤剛好往那個方向推。}}

範圍要說清楚：這不代表 38%–53% 的「多層無分支」都是假的。 最小成本候選集合裡常常只有同一種形狀，那時排序怎麼做都不影響結果。 但只要集合裡同時有串接與分支，串接就自動勝出， 而這件事的影響量是可以量出來的（見第十二節的分析②）。

八、頻率該放在哪裡：排序的似然，不是分箱的對象

把差值總和換成一個真正的似然：問「這個拓撲有多能解釋觀測到的這組 read-AF」。 拓撲對各節點的分子比例施加兩條約束，兩條都是純算術：

串接⁢v→w: f(w)≤f(v) 分岔⁢v→ w1,w2: f(w1)+ f(w2)≤ f(v)

f(v) 是以 v 為根的子樹所佔的分子比例。 給定拓撲，在這些約束下擬合 f，用各位點自己的覆蓋深度當二項式權重，再比最大化後的似然。

這樣做買到三件事。第一，不同形狀變得可以互相比較， 因為它們是在比「解釋同一組數字的能力」，形狀不再自己決定勝負。 第二，各位點自己的覆蓋深度進得去 —— 前面例子裡三個位點的覆蓋是 73、98、60， 在差值總和裡權重完全一樣，在似然裡不會。

第三件事最重要：純度、拷貝數與 multiplicity 在這裡精確消掉。 同一個單位裡的 read-AF 共用同一個分母（同一段區域、同一條家族），而上面兩條約束寫的都是比值。

{{svg:rg-composition-count | [wide] 公式在數什麼：一堆分子除以全部分子。 正常細胞的分子只落在「全 0」那一堆，所以任兩個非參考型的堆相除時，共同的分母整個消掉。 注意這張圖畫的是窄視窗的理想情況 —— 每條 read 都蓋到所有位點。寬視窗下要換成逐對的版本。}} {{svg:rg-cancellation | [wide] 相除之後只剩下兩個 clone 的細胞比例與家族拷貝數之比。 右欄是傳統路線的對照：VAF 換算細胞比例要三個估計值，同一個 VAF＝0.30 可以落在 0.38 到 1.80。}}
p(c) p(c′) = wj⁢κj wj′⁢κj′

ρ 就住在那個共同分母裡，所以它消掉。 這是舊版模型唯一原封不動保留下來的結果 —— 而它現在有了正確的用途：排序，而不是分箱。

九、四個全基因體頻譜

被分箱的對象不再是譜系內比例，而是下面四個量。 它們都只由單位內部的量組成（所以與 σ 無關），都不需要純度，而且對每個單位都算得出來。

頻譜量什麼現況
S1　拓撲類別局部演化的形狀已經量到，而且可重現
S2　最少潛在節點數 |H|有多少「必要但沒被觀測到」的狀態從現有輸出就導得出來
S3　候選集合大小可辨識性 —— 資料到底縮到剩幾個答案部分已量（87.53% 可完整列舉）
S4　最佳與次佳的似然差頻率訊號實際上決定了多少要先做第八節

S1 一定要報兩次：閘門前與閘門後。兩者的差就是幾何修正量本身， 兩個都報出來，比只報一個有資訊得多。

十、窄視窗第二輪：頻率仍然有用，只是要換個尺度

視窗寬度是一個 trade-off 旋鈕，而且是舊版模型完全沒有模型化的那一個：

項目寬視窗（現行約 39 kb）窄視窗（≤ read 跨距）
單位數多（八萬多個）少
每單位位點數k 可以到 3 以上多半只有 k＝2
聯合觀測非常稀疏多數 read 蓋到所有位點
適合算S1、S2、S3S4，以及頻率譜

建議兩輪都跑。同一支程式改一個參數，回答的是不同的問題。 窄視窗那一輪才有辦法把譜系內比例估準 —— 而估得準的時候，它的偵測下界其實相當低：

{{svg:rg-detection-window | [wide] 窄視窗下每個家族 60 條分子、錯誤率千分之五時，下界約 0.05。 但下界要逐單位算，不能用固定常數。上界 0.5 是類推來的，必須由模擬重新推定。}} {{svg:rg-rho-spectrum | [wide] 窄視窗那一輪才做得到的事：一個 clone 本身也是從單一細胞指數擴張的族群， 所以同一條 1/f 定律必須在每一個 clone 內部成立、常數相同。 這是第二輪的目標，不是寬視窗輸出可以直接拿來做的事。}}

舊版模型還提過一個「串接比例對親代比例」的預測。 在幾何修正（第四節）與排序偏誤（第七節）都排除之前，那個預測沒有辦法檢驗 —— 目前量到的串接比例遠高於它的預期值，而那兩項剛好都往同一個方向推。 所以現在應該把它當成流程的診斷訊號，而不是生物學結論。這是對舊版一項主張的撤回。

三件要注意的事

第一，0.909 是目前最強的結果。一個換了 basecaller 還守得住、 卻又分得開癌別的統計量，帶的是真的訊號。任何重新設計如果把它弄丟了，那是退步不是進步。 所以第四節那道閘門加上去之後，要重算這個 0.909： 守住或變好，代表閘門濾掉的是雜訊；垮掉，代表原本的 0.909 有一部分是共用的覆蓋幾何撐出來的 —— 那也是很重要的資訊。

第二，類別比例目前還不能當成演化結論。 串接要被看見，需要觀測到雙突變的那個頂點； 分岔要被看見，需要兩個單突變頂點都在、而且雙突變頂點的缺席是可信的。 兩者的偵測機率都隨跨越深度變化，也就是隨兩個變異的距離變化。 在把這件事量出來之前，6%–22% 的分支比例混著幾何。

第三，有一個記帳需要對一下。 各資料集的單位數加起來是 71,955，而結論裡引用的是 85,941。 兩個數字很可能在數不同的東西（全部含突變的單位，與通過某個篩選的單位）， 但在寫成論文之前要先把它釘住。

預測與結果檢視

{{ask}}

現行流程在七個資料集上，「多層無分支」都是最大的一類（38%–53%）， 而分支類只有 6%–22%。有人主張這代表「腫瘤的局部演化以線性為主」。 請問：這個推論成立嗎？

{{reveal}}

還不成立，而且有兩個獨立的理由指向同一個方向。

理由一：偵測機率不對稱。要判為串接，需要看到雙突變的那個頂點； 要判為分岔，需要兩個單突變頂點都在，而且雙突變頂點的缺席是可信的。 第二件事要求足夠的跨越深度，而跨越深度隨兩個變異的距離掉得很快。 換句話說，距離遠的位點對比較容易被判成串接或單層 —— 不是因為生物學，是因為看不到。

理由二：排序有形狀偏誤。差值總和的項數由形狀決定 —— 串接有 3 組祖先後代配對，星狀有 0 組，所以星狀恆得 0 分。 最小成本候選裡只要同時有這兩種形狀，串接就自動勝出。

兩個理由都往「高估串接」推，而觀測到的正是串接佔多數。 這不代表結論是錯的 —— 它可能是對的 —— 而是代表目前的證據還分不出來。

要怎麼分？兩件事都可以在現有輸出上做，不需要重新定序，也不需要重寫求解器： 把單位按跨越深度分層，看類別組成會不會跟著變； 以及把候選集合用「除以配對數」的分數與第八節的似然各重排一次，看類別分布移動多少。 這兩件事做完之前，這個推論就只是一個待檢驗的假說。

順帶一提，這正是上篇重要區分 #11 的同一件事換了個位置： 那裡說的是「頻率群集不等於 clone tree」，這裡說的是「拓撲類別分布不等於演化模式分布」—— 中間都隔著一層方法本身造成的偏差。

十一、先把逐對跨越深度算出來

這是所有修正的前提，而且從現有的狀態表就算得出來，不必碰求解器：

{{cli}} python3 - <<'PY' import itertools from collections import Counter # 一個單位的狀態表：(S1, S2, S3, read 數)，'-' 代表沒蓋到 rows = [("-","A","-",42), ("R","-","-",31), ("A","-","-",25), ("-","-","R",25), ("-","R","-",22), ("-","-","A",15), ("R","A","-", 9), ("-","A","A", 6), ("-","A","R", 6), ("A","R","-", 5), ("-","R","R", 5), ("R","A","R", 3)] k = 3 total = sum(r[-1] for r in rows) cov = Counter() for r in rows: cov[sum(1 for x in r[:k] if x != "-")] += r[-1] for c in sorted(cov, reverse=True): print(f"蓋到 {c} 個位點: {cov[c]:4d} 條 ({cov[c] / total * 100:5.1f}%)") print() for i, j in itertools.combinations(range(k), 2): sub = [r for r in rows if r[i] != "-" and r[j] != "-"] n = sum(r[-1] for r in sub) pat = Counter() for r in sub: pat[r[i] + r[j]] += r[-1] print(f"S{i+1}xS{j+1}: n={n:3d} ({n / total * 100:4.1f}%) {dict(pat)}") print() for i in range(k): sub = [r for r in rows if r[i] != "-"] n = sum(r[-1] for r in sub) a = sum(r[-1] for r in sub if r[i] == "A") print(f"read-AF(S{i+1}) = {a}/{n} = {a / n:.2f}") PY {{/cli}}

要看的東西：逐對的 n 之間差多少。差一個數量級是常態， 而那代表這個單位的不同祖先關係，是用完全不同的證據量決定的。 n 特別小的那幾對，就是第四節那道閘門要擋下來的。 最後三行印出的 read-AF 也要注意各自的分母 —— 它們不一樣，而差值總和沒有考慮這件事。

十二、三個可以馬上做的分析

按價值排序，全部只需要既有的輸出。

分析怎麼做會回答什麼
① 類別分布是不是幾何造成的 把單位按「突變位置的分散程度」或「中位跨越深度」分層，畫每一層的拓撲類別組成 分支比例若隨跨越深度上升，第二節那個擔憂就是真的，現在的 S1 有一部分是假的。這是目前最值得畫的一張圖
② 排序偏誤有多大 把現有候選集合用「除以祖先後代配對數」的分數重排一次，再用第八節的似然排一次，比較類別分布 若 S1 幾乎不動，這個疑慮就結案，而且結論因為被檢查過而更強
③ 重現性撐不撐得住閘門 加上第四節的閘門後，重算同細胞株跨機構的組成相似度 守住或變好 → 閘門濾掉的是雜訊；垮掉 → 原本的 0.909 有一部分是共用的覆蓋幾何

十四、還沒解決的問題

  • 一個拓撲節點不見得只有一群細胞。本實驗室的甲基化觀測已經看到這件事： 在某個位置，單一個「單倍型 ＋ 等位」狀態底下還分得出五群甲基化模式。 所以節點數的正確讀法是「至少這麼多群」，永遠不是「剛好這麼多群」。 這是單倍型路線的解讀上限，不是調參數能解決的事。
  • 跨 read 跨距的聯合仍然看不到。相距 100 kb 的兩個變異，聯合計數對長讀一樣是未知的 （雖然第一節救回了它們的 cis／trans 狀態）。
  • 潛在節點的意義仍然含糊。它可能對應真的中間世代，也可能只是模型為了連通而記的帳。 S2 量得出它有多少，量不出它是哪一種。
  • 窄視窗那一輪還沒跑過，所以頻率譜那一半目前全都是設計，不是結果。
  • 本頁對排序偏誤的推論還沒有實測撐著 —— 第十二節的分析②做完之前， 它是一個有結構理由的假說，不是已知事實。
