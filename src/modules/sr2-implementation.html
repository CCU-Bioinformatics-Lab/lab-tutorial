為什麼重要

這一頁的目標只有一個：把全基因體的 subclone 系統發生重建做得更好 —— 不是再多產出幾萬筆局部陳述。

上篇的結論給了一個不太舒服的起點。20 kb 視窗、每 Mb 5 個變異時， 含變異的區域有 95% 只有一個變異；那種區域裡「一條單倍型」就等於「一個變異」， 所以把標籤丟掉之後，單倍型頻率譜幾乎就塌回 VAF 頻率譜。 換句話說，頻率值本身不是這條路線的賣點。

但反過來看，剩下那 5% 給的東西性質完全不同：它給的不是更多資料點， 而是資料點之間的關係 —— 哪兩個變異不可能屬於同一群、哪一群是哪一群的祖先。 而關係不需要多：一棵 [[clone tree]] 要定的是群與群之間那幾個關係， 不是一萬五千個變異各自的歸屬。

{{svg:sr2-goal | [wide] 兩種區域各出一半的力：95% 的區域給頻率，決定峰落在哪裡； 5% 的區域給關係，決定哪些峰真的是分開的、峰該多寬、峰之間的比例，以及誰是誰的祖先。 兩者餵進同一個混合模型，輸出才是全基因體的群與樹。}}

而這一頁真正的出發點是下面這件事： 本實驗室現行的實作，其實已經在算右邊那一欄了。 它對每一個「區域 × [[somatic haplotype|單倍型家族]]」（以下簡稱一個「單位」） 都判過是串接還是分岔 —— 那些判定就是約束，只是它們停在區域層級，從來沒有被送到全基因體那一層。

所以要做的事有兩件，順序不能顛倒：

  1. 把那些判定變得可信。直接拿現行輸出當約束會出事 —— 真實資料裡有相當比例的判定是在證據不足的情況下做出來的，而錯的約束比沒有約束更糟。
  2. 把它們接到全基因體的混合模型上。頻率定位置，約束定個數、寬度、比例與先後。

這一頁不是教材。它假設你讀完上篇，給的是式子、參數與失敗模式。 範圍限定在單倍型；甲基化只在最後出現一次，而且是當成解讀上限，不是一條資料通道。

概念與互動

一、5% 能做的三件事

{{svg:sr2-five-percent | [wide] 兩群細胞若佔的比例剛好一樣，在一維頻率軸上就是同一個點， 再深的定序也分不開。而一個「沒有分子同時帶兩者」的觀測，就足以把那根峰拆開。 下方是約束預算與它成立的前提。}}

用途一：打破一維上的簡併

VAF 頻率譜有一個結構性的盲點：兩群細胞如果佔的比例一樣， 它們在頻率軸上就是同一個點。這不是精度問題 —— 加深定序、增加變異數、 換更好的 caller 都沒有用，因為那個方向上的似然本來就是平的。

但只要有一對變異落在同一個區域、分屬那兩群，而且觀測到沒有分子同時帶兩者， 就得到一條硬約束：這兩個變異不可能屬於同一群。混合模型被迫把那根峰拆成兩個成分。 這是可辨識性的改變，不是精度的改變 —— 可辨識性講的是「資料原則上分不分得出這兩種情況」， 精度講的是「分得出來，但量得準不準」。前者加再多資料也不會變，後者會。 這也是這條路線最強的一個論點。

用途二：直接量出「峰應該多寬」

這一項不需要任何假設，值得優先做。

在 VAF 頻率譜裡，一群的寬度 ＝ 生物學上的離散 ＋ 技術雜訊，兩者混在一起分不開。 但是同一條單倍型上的幾個變異，真實頻率完全相同 —— 它們就在同一批分子上，生物學離散恰好是零。 所以那幾個變異之間觀測到的離散度，就是純粹的技術雜訊，是量出來的，不是假設的。

按深度與拷貝數分層估出來，就得到一條經驗性的「點擴散函數」—— 這個名字借自光學：真值是一個點（同一條單倍型上那幾個變異的共同真實頻率）， 量出來卻是一團有寬度的散布，而這條函數就是那團散布的形狀。 拿它去對全基因體的頻率譜做解卷積（把已知的模糊從觀測裡除掉），峰會變窄 —— 峰變窄，本來被埋掉的小群就浮得出來。

用途三：不需要純度的相對位置

同一個單位裡兩條單倍型的比值不需要純度： 純度只影響「正常細胞的分子有多少」，而那些分子在兩個比例的分母裡是同一項， 相除的時候整個消掉（第八節把式子寫出來）。

拷貝數則不是無條件消掉的，它要一個前提： 兩個 clone 在這個位置的家族拷貝數相同 —— 也就是此處沒有 subclonal 拷貝數變異。 好消息是這個前提可以就地檢查（用家族深度比），不必額外估計， 所以它跟「需要一個全域拷貝數估計值」是兩回事。

於是每一個巢狀對（其中一個變異所在的細胞群，整群包含在另一群裡面 —— 也就是分類為「串接」的那種對）都直接給出「兩群的細胞比例之比」。 把這些比值匯總起來，群與群的相對位置就定下來了， 純度只剩下一個整體縮放因子的角色。

這把上篇說的第一層不確定性（換算需要純度、拷貝數與 [[mutation multiplicity|multiplicity]] 三個估計值）降級成一個純量： 換算錯了，整排群一起平移，相對關係不變。

二、約束從哪裡來：現行實作已經算出來了

好消息是不必從頭寫。現行流程對每個單位做的分類，直接就對應三種約束：

{{svg:rg-unit-classes | [wide] 三欄的邊際計數刻意做成一樣 —— 重點正是「光看邊際分不出來」。 左邊是串接，給出有向的祖先關係；中間是分岔，給出「不可同群」； 右邊四格全滿是不相容，那不是生物學結果而是品質訊號。}}
現行輸出對應的約束它在全基因體那一層決定什麼
分岔（沒有分子同時帶兩者）不可同群（硬）強迫拆峰 —— 打破一維上的簡併。但 trans 會偽造這一格，見第六節
串接，且比值 ≈ 1必定同群（硬）把散在不同區域的同一群併起來。權重要最低，理由見下
串接，且比值 < 1有向：A 群是 B 群的祖先群與群的先後 —— 取代[[parsimony|簡約性]]
不相容（四格全滿）不產生約束反過來估計單倍型標記的錯誤率

「必定同群」這一條要小心，因為它跟用途一互相拉扯

上面那張表最容易被照單全收的是第二列。串接代表後者長在前者的譜系上， 所以兩群是巢狀；比值 ≈ 1 只是說後者幾乎接管了前者。 但「幾乎接管」不等於同一群 —— 那是兩個真實存在的 clone， 只是在頻率軸上分不開。而頻率相同不等於同一群，正是用途一整段在論證的事。 把它們硬性合併，等於在用途一想拆開的地方主動把兩群黏起來，方向剛好相反。

所以這一條要加兩個限制：

  • 「≈ 1」要寫成一個明確的容差，而且容差由檢定力決定，不是拍板的常數。 在跨越深度 n 之下，比值本來就有抽樣誤差； 只有當「比值 < 1」在這個 n 下本來就分辨得出來而觀測仍然落在 1 附近， 「≈ 1」才帶資訊。n 小的時候，任何比值都 ≈ 1 —— 那不是證據，是沒有解析度。
  • 權重要是三種約束裡最低的。不可同群與有向關係都在增加可辨識性； 必定同群是唯一一條在減少它的。錯的不可同群會逼出一個不存在的群， 錯的必定同群則會讓一個真的群整個消失 —— 後者更難發現， 因為多出一個群還會讓人起疑，少一個群不會有任何異常。

三、但約束不能照單全收

{{svg:rg-partial-reads | [wide] 八成的 read 只看得到三個位點裡的一個。 把同一批 read 按位點對拆開之後才看得出來：這個單位的判定靠的是 17 與 20 兩個數字，不是 194， 而其中一對只有 3 條 read，卻一樣被判了關係。}}

一個單位的有效樣本數不是它的總 read 數， 而是每一個位點對各自有幾條 read 同時蓋到。 上圖那個單位的三個位點對，跨越深度分別是 20、17 與 3 —— 而那個 n = 3 的位點對，照樣產出了一條約束。

假設那條譜系裡有三成的分子帶著某個狀態，三條 read 全部錯過的機率是 0.7³ ≈ 0.34。三分之一的機率會把「有」看成「沒有」 —— 而「沒看到」正是判定分岔的依據。也就是說，這條約束有三分之一的機率是假的。

為什麼可跨越的範圍這麼小，要回到下面這個結構：

{{svg:rg-three-tiers | [wide] read 跨距限制的是「數不數得到共現」， [[phase block]] 限制的是「知不知道兩個位點在不在同一條染色體上」。 約束只能從最上層那一格產生 —— 那也是三層裡範圍最小的一層。}}

四、閘門一：逐對檢定力

{{svg:rg-pairwise-gate | [wide] 「這個狀態沒出現」有兩種完全不同的原因：真的沒有那種細胞， 或根本沒有 read 跨得到。目前的解法把兩者當成同一件事 —— 而在約束的脈絡下，第二種會直接變成一條假的硬約束。}} {{cli}} for each pair (i, j) in the unit: n_ij = 同時蓋到 i 與 j 的 read 數 π_ij = 在 n_ij 與錯誤率 ε 下，偵測到「佔該譜系 ϱ_min」的狀態的檢定力 if π_ij < π*: 這一對不產生約束（標成 UNDETERMINED） report: 收到幾條約束、丟掉幾條、丟掉的是哪些 {{/cli}}

ε 與 η 要就地估，不要用全域常數。錯誤模型本身不變 —— 每個位點一道閘門，加上兩個家族之間的交換：

{{svg:rg-error-gates | [wide] 每個位點一道錯誤閘門；最後一道是家族交換閘門， 一小部分分子被標到另一條通道去。交換閘門把兩條通道接在一起，所以兩個家族必須一起估。}}

五、閘門二：排序偏誤會系統性地把分岔判成串接

第二道閘門比第一道隱蔽，而且方向很不利。 最小成本候選常常不只一個，現行流程用 [[read-AF]] 的差值總和排序 —— 問題出在相加的項數由形狀決定：

{{svg:rg-score-bias | [wide] 三個形狀的祖先後代配對數分別是 3、1、0。 串接得到正分，星狀恆等於 0 —— 所以最小成本候選裡同時有這兩種形狀時，分支永遠贏不了。}}

放進約束的脈絡，後果很具體： 該產出「不可同群」的單位，會改成產出「祖先關係」。 而「不可同群」正是用途一唯一的來源 —— 所以這個偏誤會系統性地抽掉拆峰的能力，讓該分開的群留在一起。

修法是把差值總和換成似然：在拓撲施加的約束下擬合各節點的分子比例， 再比最大化後的似然。這樣不同形狀才是在比「解釋同一組數字的能力」，形狀不再自己決定勝負。

六、兩個會產出假約束的陷阱

兩個都跟相位有關，而且方向相反： 第一個講的是相位資訊只在 block 內有效，跨出去就沒有意義； 第二個講的是即使在 block 內，相位解得對也可能被讀成錯的生物學。

{{svg:rg-block-spin | [wide] 上排是實體事實：兩條染色體拷貝各自連續。 中排是軟體輸出：block A 的 H1 對應拷貝 ①，block B 的 H1 對應拷貝 ② —— 兩個 H1 不是同一條。}} {{guard:13 | 不同 phase block 的 H1 不是同一條染色體}} 相位軟體在每個 block 內把 read 分成兩堆並標上 H1、H2， 但標號在每個 block 內獨立決定。 好消息：約束談的是細胞的祖先關係，不是哪一條親源染色體帶著變異。 每條約束都在單一個單位內產生，所以它與標號方向無關 —— 核心推論不受影響。 壞消息：任何把不同 block 的 H1 加總在一起的判斷都沒有意義，而且不會有錯誤訊息。 所以不能用「兩個變異都在 H1 上」當成它們同群的理由 —— 跨 block 的 H1 根本不是同一條。 由此得到一條可以寫成檢查程式的規則： 每一條約束都必須在單一個單位內部產生，不得跨單位組合。 {{/guard}} {{guard:14 | trans 不等於分支演化}} 兩個變異若分別落在同一個細胞的兩條染色體拷貝上（trans）， 它們永遠不可能出現在同一條分子上。於是計數表會呈現 00、10、01，而 11 那一格是空的 —— 跟兩群互不包含的 subclone 長得一模一樣。 在約束的脈絡下這特別致命：它會產出一條假的「不可同群」， 而那是硬約束，會直接逼混合模型拆出一個不存在的群。 現行流程有先按單倍型家族分堆，這一點是對的 —— 而且相位讓 cis／trans 在 整個 phase block 內都是已知的（就是上一個陷阱講的那個 block）， 不是只在一條 read 之內，所以這個陷阱的可解範圍比 read 跨距大約一百倍。 {{/guard}}

九、約束預算：夠不夠用

先把兩個 5% 分開

這一頁從頭到尾講的「5%」是區域的比例：含變異的區域裡， 只有 5% 有兩個以上的變異。但下面要算的是變異的比例，那是另一個分母 —— 因為每個多變異區域至少裝兩個變異，所以「5% 的區域」裝的是 9.5% 的變異。 兩個數字都對，只是在數不同的東西：約束的產量由後者決定。

數字是怎麼來的

假設變異在基因體上是 Poisson 散布。令 λ ＝ 每個視窗的期望變異數： 每 Mb 5 個、視窗 20 kb 時 λ ＝ 0.1；基因體 3.1 Gb 切成 155,000 個視窗。 於是三個關鍵比例都是 λ 的閉式函數：

{{cli}} 含變異的視窗 155,000 × (1 − e^−λ) = 14,750 其中只有一個變異的比例 λe^−λ / (1 − e^−λ) = 95.1% ← 上篇那個 95% 落在多變異視窗的「變異」比例 1 − e^−λ = 9.5% ← 這一節要用的 15,500 × 0.095 = 1,475 個變異 相鄰位點對（每個含 k 個變異的視窗貢獻 k−1 對） 155,000 × (λ − (1 − e^−λ)) = 750 兩個變異落在同一個單倍型家族 × 1/2 = 375 ≈ 表上的 369 {{/cli}}

配對慣例要釘住。上面數的是相鄰位點對； 若改成視窗內全配對（每個視窗 C(k,2) 對），低負荷時兩者幾乎一樣 （5／Mb：388 vs 375），但高負荷時會分開 —— 50／Mb 時全配對給約 38,750， 相鄰配對給約 28,500。表上的 24,500 是相鄰配對這一支。 寫成論文之前，這個慣例要跟第四節的閘門講同一種語言， 否則「收到幾條約束」在兩處會是兩個定義。

按上面的模型，若腫瘤有三群、質量分別是 0.60／0.25／0.15， 跨第 i 群與第 j 群的對數就是總對數 × 2wiwj：

夠用的理由是：要定的是群與群之間那幾個關係，不是 15,500 個點各自的歸屬。 最稀疏的那一對也有 28 個獨立觀測。 但這是通過閘門「之前」的數字 —— 閘門會砍掉一部分， 所以報告一定要把「收到幾條、丟掉幾條」列出來。

十、估計式：把約束餵進混合模型

混合模型本體不變：每個變異的頻率來自某一群，加上量測雜訊。約束以權重項進去：

ℒ= ∑m log⁢ P(fm∣ czm, PSF) + ∑r ωr⁢ log⁢ P(Rr∣z,T)

第一項是 95% 給的：每個變異的頻率 f_m 落在它所屬群的位置 c 上， 雜訊寬度由用途二量到的點擴散函數 PSF 決定 —— 那不是自由參數。 第二項是 5% 給的：每條約束 R_r 帶著信心權重 ω_r， 限制的是變異的群歸屬 z 與樹 T。

{{cli}} 不可同群 (i, j) → z_i ≠ z_j 必定同群 (i, j) → z_i = z_j 祖先關係 (i → j) → T 上 z_i 是 z_j 的祖先，且 c[z_i] > c[z_j] 巢狀比值 ϱ(i, j) → c[z_j] / c[z_i] = ϱ ← 不需要純度的相對位置 {{/cli}}

關鍵是權重而不是硬條件。閘門已經擋掉大部分假約束，但擋不乾淨； 把剩下的不確定性放進 ω_r，一條錯的約束只會被稀釋， 不會像硬條件那樣直接逼出一個不存在的群。

推論方式沒有特別之處：帶約束的 EM，或直接對 (T, c, z) 取樣。 輸出必須包含每個群配對是由幾條約束決定的 —— 沒有約束支持的關係就是靠偏好補的，要標出來。

三件要注意的事

第一，0.909 是目前最強的結果。一個換了 basecaller 還守得住、 又分得開癌別的統計量，帶的是真訊號。所以閘門加上去之後要重算這個數字： 守住或變好，代表閘門濾掉的是雜訊；垮掉，代表原本的 0.909 有一部分是共用的覆蓋幾何撐出來的。

第二，「分支類」的比例還不能直接當成約束產量。 分岔要被判出來，需要兩個單突變頂點都在、而且雙突變頂點的缺席是可信的 —— 第二件事就是閘門要查的。所以那 6%–22% 是上限，不是實際可用量。

第三，有一個記帳需要對一下。 各資料集的單位數加起來是 71,955，而結論裡引用的是 85,941。 兩個數字很可能在數不同的東西，但在寫成論文之前要先釘住。

預測與結果檢視

{{ask}}

假設閘門調得很鬆，收到 5,000 條約束；調得很嚴，只剩 300 條。 直覺上約束越多，混合模型被限制得越死，結果應該越好。 請問：鬆的那一版會不會比較好？

{{reveal}}

不一定，而且很可能更糟 —— 因為約束的兩種錯誤代價不對稱。

一條漏掉的約束，代價是「本來可以定下來的關係，現在要靠偏好補」—— 退回沒有這條路線之前的狀態，損失有限。

但一條錯誤的「不可同群」，代價是逼混合模型拆出一個不存在的群。 而且它不會自己露餡：拆出來的那個群有頻率、有變異、看起來完全正常。 下游的樹、演化順序、臨床解讀全部跟著錯，報告上不會有任何異常。

所以取捨不是「多 vs 少」，是「漏掉 vs 造假」，而兩者代價差很多。 正確的做法是寧嚴勿鬆，並且把剩下的不確定性放進權重 ω_r， 而不是當成硬條件 —— 一條被稀釋的錯約束不會單獨改變結論。

要怎麼知道調到哪裡？用重現性當外部檢查： 在不同 basecaller／不同機構的同一個細胞株上掃過一系列閘門嚴格度， 看哪一段的群與樹最一致。這不需要金標準 —— 而那正是這個領域最缺的東西。

十二、先把逐對跨越深度算出來

這是所有後續步驟的前提，而且從現有的狀態表就算得出來，不必碰求解器。

那張狀態表從哪裡來

不必等求解器輸出，也不必知道它的內部格式 —— 狀態表就是「哪些 read 在哪些位點讀到什麼」， 從 somatic_haplotag 的 BAM 加上 somatic VCF 就湊得出來。先取位點：

{{cli}} # 這個區域裡有哪些 somatic 位點（位置、REF、ALT） bcftools query -r chr1:1000000-1020000 -f '%POS\t%REF\t%ALT\n' somatic.vcf {{/cli}}

再把這些位點上的 read 逐條攤開。單位是「區域 × 單倍型家族」， 所以家族篩選不能省 —— 混進另一個家族的 read，計數表就不是這個單位的了：

{{cli}} python3 - <<'PY' import collections, pysam BAM = "tumor.somatic_haplotag.bam" CHROM = "chr1" FAMILY = "1" # 家族 1 ＝ HP:Z:1 與它的 somatic 後代 1-1、1-2… SITES = [(1_003_412, "C", "T"), # 上一步 bcftools 撈出來的 (位置, REF, ALT) (1_009_887, "G", "A"), (1_016_204, "A", "G")] bam = pysam.AlignmentFile(BAM) state = collections.defaultdict(lambda: ["-"] * len(SITES)) for k, (pos, ref, alt) in enumerate(SITES): for col in bam.pileup(CHROM, pos - 1, pos, truncate=True, min_base_quality=0, stepper="nofilter"): for p in col.pileups: if p.is_del or p.is_refskip or not p.alignment.has_tag("HP"): continue aln = p.alignment # ★ somatic_haplotag 寫的是字串 HP:Z:1-1，haplotag 寫的是整數 HP:i:1。 # str() 讓兩種都跑得動，但只有前者分得出家族內的 somatic 分支。 if str(aln.get_tag("HP")).split("-")[0] != FAMILY: continue b = aln.query_sequence[p.query_position] state[aln.query_name][k] = "A" if b == alt else "R" if b == ref else "-" # 同一個狀態組合的 read 併成一列 —— 這就是下一段要用的 rows rows = [(*pat, n) for pat, n in collections.Counter(tuple(v) for v in state.values()).most_common()] for r in rows: print(r) PY {{/cli}}

然後看逐對的 n

{{cli}} python3 - <<'PY' import itertools from collections import Counter # 換成上一段印出來的 rows 就是跑自己的資料。 # 這裡填的是「真實資料與證據」那個 194 條 read 的單位，'-' 代表沒蓋到 rows = [("-","A","-",42), ("R","-","-",31), ("A","-","-",25), ("-","-","R",25), ("-","R","-",22), ("-","-","A",15), ("R","A","-", 9), ("-","A","A", 6), ("-","A","R", 6), ("A","R","-", 5), ("-","R","R", 5), ("R","A","R", 3)] k = 3 total = sum(r[-1] for r in rows) for i, j in itertools.combinations(range(k), 2): sub = [r for r in rows if r[i] != "-" and r[j] != "-"] n = sum(r[-1] for r in sub) pat = Counter() for r in sub: pat[r[i] + r[j]] += r[-1] # 這一對能不能產生約束，看的是 n，不是 total print(f"S{i+1}xS{j+1}: n={n:3d} ({n / total * 100:4.1f}%) {dict(pat)}") PY {{/cli}}

要看的是逐對的 n 之間差多少。差一個數量級是常態 —— 而那代表這個單位產出的幾條約束，可信度完全不同。

十三、四個可以馬上做的分析

分析怎麼做會回答什麼
① 約束的實際產量 對每個單位算逐對跨越深度，套一組閘門門檻，數還剩幾條約束、分別是哪一種 把「6%–22% 的分支類」變成真正可用的數字。這是最該先做的一件事
② 分類是不是幾何造成的 把單位按中位跨越深度分層，畫每一層的分類組成 分支比例若隨跨越深度上升，現在的分類有一部分是假的，約束會跟著假
③ 排序偏誤抽掉了多少「不可同群」 把候選集合用「除以配對數」的分數重排，數分支類多出幾個 直接量出第五節那個偏誤讓我們損失了多少最稀缺的約束
④ 重現性撐不撐得住閘門 掃一系列閘門嚴格度，重算同細胞株跨機構的一致性 沒有金標準時，最實際的調參依據

①：把上一段的腳本再往前推十行

①被列成最該先做的一件事，而它其實就是第十二節那支腳本加上「套門檻、按類型數」：

{{cli}} python3 - <<'PY' import itertools, math from collections import Counter RHO_MIN, PI_STAR = 0.05, 0.95 # 要偵測到「佔該譜系 5%」的狀態，檢定力要 95% n_min = math.ceil(math.log(1 - PI_STAR) / math.log(1 - RHO_MIN)) # 門檻對參數有多敏感 —— 先看這張表，再決定 RHO_MIN 與 PI_STAR print("每一對最少需要的跨越 read 數 n") print(" ϱ_min ＼ π* 0.80 0.90 0.95") for rho in (0.05, 0.10, 0.20): ns = [math.ceil(math.log(1 - p) / math.log(1 - rho)) for p in (0.80, 0.90, 0.95)] print(f" {rho:.2f} " + "".join(f"{n:7d}" for n in ns)) print(f"\n目前設定 → n_min = {n_min}\n") # 換成全部單位就是真的產量。key 是單位名，value 是第十二節那個 rows units = {"unit_A": [("-","A","-",42), ("R","-","-",31), ("A","-","-",25), ("-","-","R",25), ("-","R","-",22), ("-","-","A",15), ("R","A","-", 9), ("-","A","A", 6), ("-","A","R", 6), ("A","R","-", 5), ("-","R","R", 5), ("R","A","R", 3)]} def classify(seen): if len(seen) == 4: return "不相容（不產生約束）" if "AA" not in seen and {"AR", "RA"} <= seen: return "不可同群" if "AA" in seen: return "祖先關係／必定同群" return "資訊不足" kept, dropped = Counter(), Counter() for name, rows in units.items(): k = len(rows[0]) - 1 for i, j in itertools.combinations(range(k), 2): sub = [r for r in rows if r[i] != "-" and r[j] != "-"] n = sum(r[-1] for r in sub) if n < n_min: dropped[f"檢定力不足 (n={n})"] += 1 continue pat = Counter() for r in sub: pat[r[i] + r[j]] += r[-1] kept[classify({s for s, v in pat.items() if v > 0})] += 1 print("通過閘門：", dict(kept) or "（一條都沒有）") print("丟掉： ", dict(dropped)) PY {{/cli}}

拿這個單位跑出來的結果是三對全滅 —— n ＝ 20、17、3，而 ϱ_min ＝ 0.05、π* ＝ 0.95 要求 n ≥ 59。 （這跟第十一節那張圖是同一件事的兩種說法：每個家族 60 條分子時，可偵測下界約 0.05。）

所以①的輸出不會是「6%–22% 的分支類」那個數字， 會小得多，而且小多少完全由 RHO_MIN 與 PI_STAR 決定 —— 這正是為什麼要先印那張敏感度表再選門檻。 如果全基因體掃完真的一條都不剩，那不是腳本壞了， 是視窗太寬：回到第十一節改跑一輪窄視窗，讓多數 read 蓋得到兩端。

十四、排查順序

症狀先查什麼
混合模型多出一個很小的群先查是不是某一條「不可同群」逼出來的。追回那條約束所屬的單位，看它的逐對跨越深度
加了約束之後群數反而變少反方向的同一件事：查「必定同群」。跨越深度不足時比值一律 ≈ 1，會把兩個真的群黏成一個。見第二節那個容差
約束幾乎全是「祖先關係」第五節那個排序偏誤。分支類被系統性地判成串接了
通過閘門的約束少得離譜視窗太寬。回到第十一節，改跑一輪窄視窗
某條染色體完全沒有約束看那個區域的突變間距。距離遠 → 跨越深度低 → 全被閘門擋掉，那是對的
兩個家族的結果系統性不對稱檢查是不是分開估了。標記錯誤率把兩個家族耦合起來，必須一起估
約束彼此矛盾先看不相容單位比例。矛盾多半來自單倍型標記錯誤，不是生物學

十五、還沒解決的問題

  • 整條路線都還沒有實測。上面每一項都有結構性的理由，但沒有一項在真實資料上驗證過。 最小的驗證是模擬：合成兩群比例相同的 subclone， 確認只用 VAF 的分群必定合併，再量出要幾條約束、閘門要多嚴，才拆得開而且不拆錯。
  • 點擴散函數那一項需要同一條單倍型上有多個變異，而那正是最稀缺的區域。 低突變負荷時可能根本估不出來。
  • 約束的來源有偏。它們只來自變異密集的區域 —— 而變異密集有時候不是巧合：kataegis 是一種局部超突變， 同一次事件在幾十 kb 內一口氣打出一串變異。 那一串幾乎必然同時發生、同屬一群，所以它會貢獻大量彼此高度相關的約束， 在統計上卻被當成幾十個獨立觀測。要先偵測並降權成一叢一個有效觀測。
  • 一個群不見得只有一群細胞。本實驗室的甲基化觀測已經看到： 單一個「單倍型 ＋ 等位」狀態底下還分得出五群甲基化模式。 所以群數的正確讀法永遠是「至少這麼多」。
  • 跨 read 跨距的關係仍然看不到。相距 100 kb 的兩個變異產不出約束，不管定序多深。
