為什麼重要

這是 [[LongPhase-S]] 的完整流程，也是 tumor–normal 分析支線的基礎。 後續的 somatic indel CNN 方法與 subclone 重建都會使用它的輸出。

前面模組介紹的相關概念，會在本節整合使用。

概念與互動

五個階段

階段做什麼
①[[ClairS]] 產生 tumor variants、[[Clair3]] 產生 normal variants
②把 normal variants [[phasing|phase]] 起來，建立 HP1／HP2 骨架

為何 purity 估計先於過濾

回到 M8 的合成示例：purity 0.2（此處與 tumor DNA fraction 相等）、50× coverage，一個 clonal somatic 變異 只有約 5 條 read 支持。

若套用適合 purity 1.0 的嚴格門檻，真變異可能被當成雜訊而漏掉，[[recall]] 下降。 若一律放寬，高 purity 樣本的偽陽性則可能增加。

因此此流程先估計 purity，再依估計值調整過濾門檻。

GHIR：用失衡程度估計模型定義的 purity

[[GHIR]]（Germline Haplotype Imbalance Ratio）的基本原理如下：

  • 在理想且無系統性偏差的正常細胞裡，某個 germline 位點的 HP1 與 HP2 read 預期接近 50:50，GHIR ≈ 0.5
  • 若腫瘤細胞在 HP2 上發生 somatic 突變，部分 read 會被分到 HP2-1， 因此不再計入原本 HP2 分支的比例
  • 在其他條件相近時，tumor DNA fraction（此模型中的 purity）越高，失衡訊號通常越明顯
{{svg:m12-ghir | [wide] 上排：在此比值定義下，突變 read 被分到新的分支後不再計入原 haplotype，因此比值偏離 0.5；在其他條件相近時，tumor DNA fraction 越高，偏移通常可能越明顯。下排：將全基因體位點的比值畫成直方圖；在此資料與定義下，分布可能向較高比值移動。}}

可量化這個分布的位置（例如取中位數與四分位距）， 再以驗證資料建立「分布特徵 → 模型定義的 purity」的迴歸關係，估計樣本的 purity。

實際分布與 LCVF

真實資料的 GHIR 分布可能受到低信心位點干擾。因此 LongPhase-S 設計了 LCVF（Low-Confidence Variant Filtering），以四個條件過濾：

Filter排除什麼
Germline Haplotype Imbalance在 normal 樣本裡就已經失衡的位點（多半是 [[copy number|CNV]] 造成）
Germline Haplotype Read Ratio大量 read 沒被分配到任何 haplotype 的位點（例如大片段 deletion）
Read Count（static）read 數太少的位點 —— 分母太小，GHIR 會亂跳
Read Count（dynamic）用 bimodal valley thresholding 自動找雙峰之間的谷點當門檻

最後一項不是固定單一數字，而是依資料分布形狀決定門檻 —— 先高斯平滑、找兩個主峰，再取中間的谷點。此作法可降低對固定門檻的依賴；穩健性仍需由驗證資料評估。

四個 somatic variant filter

purity 估好之後，用它動態調整門檻，跑四個過濾器：

Filter偽陽性訊號判斷依據
TINC可能是 germline，或 normal 含有腫瘤污染檢查該位點在 normal 樣本的 [[VAF]]；較高時增加 germline/TINC 疑慮
Read-level比對或 read 證據混亂造成的可疑訊號帶變異的 read 若同時帶有 HP1 與 HP2 的 germline allele → 提高疑慮
Haplotype origin同一問題的整體統計支持 read 若多來自同一條 germline haplotype，則增加來源一致性的支持
Variant cluster密集 read pattern 造成的可疑訊號檢查變異是否集中於同一群 read；以 z-score 識別異常模式，仍需配合其他證據

這四個 filter 都檢查haplotype 來源的一致性或 read pattern 的異常， 但各自的指標與閾值不同，應合併判讀。

HP3 的後續指派

重建 somatic haplotype 時，未涵蓋 germline 錨點的 read 會先標為 HP3。之後再依其攜帶的 somatic 變異證據，嘗試指派到對應的 somatic haplotype （見 M6 的下半部示意）。

並非所有 HP3 都能完成指派。如果某個 somatic 變異的支持 read 同時來自兩條 germline haplotype，來源證據互相衝突，則保留為不可指派。

三項常見注意事項

  • purity 不會印到 stdout。請讀取 _purity.out，尋找 Tumor purity: 0.169599 這一行。
  • 是 --tumor-bam-file，不是 --tumor-bam。 同理是 --tumor-snv-file。
  • --tumor-purity 的合法範圍是 0.1–1.0（不是 0–1）。 給了這個參數就會關閉自動估計。

判讀練習

{{ask}}

執行 estimate_purity 後得到 0.95，但外部資料估計這個檢體只有大約 40% 的腫瘤細胞。

可能出了什麼問題？

{{reveal}}

依可能性排序：

  1. 大範圍的 [[LOH]] 或 [[copy number|CNV]]。GHIR 量的是 haplotype 失衡， LOH 與 somatic 突變可能造成相似的失衡訊號。若未被 LCVF 充分過濾，模型可能高估 purity。
  2. 輸入的 normal VCF 沒有正確 phase。GHIR 依賴 HP1／HP2 的分群； 若 phasing 錯誤，比例便失去解釋力。先檢查 phased VCF 裡的 PS 是否合理。
  3. [[TINC]]。如果 normal 樣本含有腫瘤 DNA 污染，germline 基準線可能發生偏移。
  4. 模型外推。迴歸是在六個細胞株的合成樣本上訓練的。 如果你的樣本在某個維度上不像那批訓練資料（不同癌別、不同 [[basecalling|basecaller]]、不同 coverage）， 預測可能不可靠。

建議的排查順序是：先以 IGV 檢視多個區域的 phasing 品質， 再查看 _purity.out 的 filter 統計，確認 LCVF 濾掉的位點比例。 若濾除比例異常低，第 1 項的可能性較高。

執行完整流程

{{cli}} # 前置：normal 的 germline VCF 要先 phase 好 longphase-s phase \ -s normal_snp.vcf -b normal.bam -r reference.fasta \ -t 8 -o phased_normal --ont # 主流程：估純度 + 過濾 + somatic haplotagging longphase-s somatic_haplotag \ -s phased_normal.vcf \ -b normal.bam \ --tumor-snv-file tumor_snv.vcf \ --tumor-bam-file tumor.bam \ -r reference.fasta \ -t 8 \ -o tagged \ --output-somatic-vcf \ --somatic-calling-log {{/cli}}

逐項檢視輸出

{{cli}} # purity 估計（不會印到 stdout，請讀取輸出檔案） grep -A2 'Estimation result' tagged_purity.out # 每條 read 被分到哪個 somatic haplotype samtools view tagged.bam | grep -o 'HP:Z:[0-9-]*' | sort | uniq -c # 過濾後的 somatic 變異（PASS 與 LowQual） awk '!/^#/ {print $7}' tagged_sc.vcf | sort | uniq -c {{/cli}}

細節正確做法

使用 IGV 驗證輸出

載入 tagged.bam，依 HP tag 分組，檢視一個 somatic 變異。 可檢查帶有 somatic 變異的 read 是否集中於某一條 haplotype， 以及兩側的 germline allele 是否一致。

若帶變異的 read 兩側 germline allele 混合， 該位點的偽陽性疑慮會增加；仍需結合四個過濾器與其他品質指標判斷。
