為什麼重要

兩條規格之間的循環依賴

sr5 的單位點四格表可在 germline haplotype 內量測 somatic 比例， 但每個 mutation 的 CCF {{m: c_i}} 與 multiplicity {{m: μ_i}} 仍須由外部 subclone 模型提供先驗。 sr2b 的多位點狀態表可限制 clone 數、clone tree 與相對比例， 其 VAF 位置卻又依賴 purity、allele-specific copy number 與 multiplicity。 前者需要後者的 clone 結果，後者需要前者或既有工具的 purity／CN 結果，形成直接的循環依賴。

LiFT-CN（Linked-Fragment Tumour tree and Copy-Number model） 以單一生成模型取代兩個互相提供外部參數的估計器。 somatic mutation 不再具有彼此獨立的 {{m: (c_i,μ_i)}}；每個 mutation 被放置於 clone tree 的一條 edge、某一條實體 copy lineage，以及相對於 gain、loss 或 WGD 的時間位置。 clone inheritance 與 copy history 隨後決定其 CCF 與 multiplicity。

{{svg:sr6-generative-chain | [wide] LiFT-CN 的生成鏈由 clone tree 與 branch exposure 開始， 先產生 ordered CN／WGD history 與各 timing slot 可用的 physical lineages，再將 mutation 放到 edge／timing／extant lineage，最後投影至 raw molecules； read-start depth 與 conditional marks 最後共同限制 {{m: p,κ,f}}、clone fractions 與 copy histories。}}

模型名稱與 novelty 的位階

LiFT-CN 為實作規格的工作名稱，不構成方法已完成或「首次」的證據。 可檢驗的新意是特定的統計閉合：以原始長讀分子的 germline–somatic 聯合 marks， 同時限制 clone tree、實體 copy lineage、clone-specific allele CN、purity、DNA fraction、ploidy 與 WGD modes。 任一個輸出本身均已有既有方法；候選 novelty 位於它們共享同一個 raw-molecule posterior 的交集。

多位點資訊的預期作用

單位點四格表只提供邊際比例。若 {{m: c_i}} 可自由變動， purity 與 CCF 可沿同一方向縮放；若 {{m: μ_i}} 未知，mutation timing 與 CN gain 亦可交換解釋。 同一分子上的 {{m: 00}}、{{m: 10}}、{{m: 01}}、{{m: 11}} 或更高維狀態新增的是 mutation 間的共現、互斥與巢狀關係。這些關係限制共享的 clone tree 與 copy history， 再間接縮小 purity／ploidy 的可行集合。

{{svg:rg-cancellation | [wide] 多位點非參考狀態的比例可消去共同的 purity 與 copy-number 分母， 直接限制 clone 間的相對比例。絕對 purity 仍須由 truncal mutation、涵蓋全部腫瘤細胞的 branch 聯集、 allelic imbalance 或外部 DNA-content evidence 確立尺度。}}

因此，稀疏 multi-SNV haplotypes 的主要用途不是增加大量計數， 而是排除原本完全等價的參數模式。若這些單位未連到 truncal scale、post-WGD mutation 或 informative allele-specific CN，預期結果為 clone topology 改善，而非 absolute purity／ploidy 改善。

概念與互動

一、估計目標與模型邊界

核心分析單位為一份 tumour–matched-normal long-read WGS。 全模型允許 clone-specific CN、tree edge 上的 segmental gain／loss、每條 root-to-leaf path 至多一次 WGD、 局部 phase orientation 不確定性與 tumour-in-normal contamination。 第一版實作限於 autosomes、單一 tumour sample、matched normal、SNV／short indel、 clonal CNA 與 clonal WGD；clone-specific CNA、subclonal WGD、sex chromosomes 與 tumour-only mode 依序於後續階段解除。此限制避免單一 bulk sample 一開始即承擔任意多個 CN mixtures。

somatic catalogue 的 selection 必須顯式界定

caller sensitivity 隨 VAF、depth、context、platform 與 purity 改變， 故 called mutations 並非隨機抽樣。第一版以 pre-registered read identity hash 將 molecules 固定分成 discovery、inference 與 evaluation 三 folds：前者只建立候選 catalogue 與 candidate boundaries， 中者只估計 posterior，後者只計算 predictive diagnostics。三 folds 不交換，evaluation fold 不進 posterior， 也不相乘或平均不同 folds 的 posterior；不同 split seeds 只作敏感度分析。各 likelihood 另含已知 sampling-fraction exposure offset。 如此可避免同一條 read 同時決定「位點被納入」與「位點支持哪個參數」。 此版本估計的是catalogue-visible clone tree；完整版本再以 thinned mutation process 整合未偵測事件。

三、clone tree 與實體 copy lineage

每個 autosomal segment 的 tumour founder 具有兩條 parental copy lineages。 clone-tree edge 上的 loss 刪除一條具名 lineage，gain 複製一條具名 lineage， [[whole-genome doubling]] 複製該 edge 當時存在的全部 lineages。 事件序列決定所有 {{m: C_{sgh}}}，而不只決定最後的 total CN。

固定 atomic-bin grid 後，令 {{m: B}} 為相鄰 bins 的 boundary indicators， {{m: S(B)}} 為其導出的 CN-segment partition。所有 copy-event records 均以 {{m: S(B)}} 中的 segment 為 target；因此 segmentation 改變時，copy-history 的 support 與 normalizer 亦隨之改變。

令 {{m: H^{CN}_e=(h^{CN}_{e1},…,h^{CN}_{eJ_e})}} 為 edge {{m: e}} 上的 ordered copy-event history，其中 {{m: J_e=N^{CN}_e+W_e}}。每個 segmental event record 包含 segment、gain／loss type 與在該時點存在的 target lineage；若 {{m: W_e=1}}，history 中另含一個 WGD token。由 founder lineages 依序 replay {{m: H^{CN}}}，唯一導出每一時點可用的 physical lineages 與最終 {{m: C}}。

somatic mutation {{m: m}} 的 placement 為 {{m: z_m=(e_m,ℓ_m,t_m)}}：acquisition edge {{m: e_m}}、physical lineage {{m: ℓ_m}}， 以及相對於該 edge 上 CN events 的 timing slot {{m: t_m}}。 mutation 由後代繼承；帶 mutation 的 lineage 被 gain 或 WGD 複製時，multiplicity 隨之增加； 該 lineage 被 deletion 移除時，mutation 訊號消失。

{{eq}} μ_{mg} = \sum_{ℓ} G_{gℓm}, \qquad CCF_m = \sum_g π_g · 1(μ_{mg}>0) {{note}} {{m: G_{gℓm}}} 表示 clone {{m: g}} 的 physical lineage {{m: ℓ}} 是否攜帶 mutation {{m: m}}。 CCF 與 multiplicity 均由 event history 導出，不再有彼此獨立的先驗。 {{/eq}}

第一版的 tree component 採 one-acquisition、no-back-mutation boundary。 每個 candidate mutation 另有 mutation-level class {{m: R_m∈\{tree,artifact,recurrent\}}}：tree 使用單一 acquisition； artifact 使用由 negative controls 校準的 site／read artifact emission； recurrent 允許至多兩個 acquisition edges 並接受額外 event penalty。 如此可表達多 molecules 一致支持的 recurrent event，而不把它混入 whole-read background 或強迫建立新 clone。

information audit

每個 mode 另計 depth、single-locus marks、multi-locus co-occurrence、SV marks、external evidence 與 priors 的 log-posterior contribution。移除某一 evidence class 後 mode ranking 的改變， 用以區分 data-identified、prior-resolved 與 observationally equivalent。 窄 posterior 本身不證明資料具資訊；強 clonal prior 亦可產生窄但 prior-dominated 的區間。

七、推論演算法

  1. precomputation。依固定 genome grid 建立 disjoint read-start bins； 由 discovery fold 建立 atomic CN candidate bins，再由 inference fold 建立 read coverage masks、 observed allele-pattern sufficient statistics 與 phase-connectivity graph；evaluation fold 只建立相同格式的 predictive summaries，不參與 posterior。不同 split seeds 只作獨立敏感度分析。
  2. calibration。由 matched normal、high-confidence homozygous loci、spike-ins 與 excluded repeat strata 估計並在 SMC 前固定 {{m: a,E,E^{SV},B_u}} 及其 hyperparameters；另建立 {{m: χ,q,(δ_u,μ_h,τ_h)}} 的 priors 與 TINC initial range。這些 fixed calibration objects 不列入 {{m: Θ_{v1}}}。{{m: ω_0,a_p,b_p,λ_K,α_π,a_{sw},b_{sw}}}、CN event-type probabilities、 boundary probabilities 與 artifact／recurrent class probabilities 亦在 run 前固定。
  3. component-stratified initialization。{{m: Z_0=1}} 與 {{m: Z_0=0}} 各配置預先登錄的最低粒子數； proposal 配額只改善數值覆蓋，不代表 component prior mass。每個 component 內的 initial weights 各自對 conditional prior {{m: P(Θ_z∣Z_0=z)}} 正規化；{{m: (ω_0,1−ω_0)}} 只在最終 evidence 合併時乘入一次。各 component 分別從 prior 取樣大部分 particles；depth＋germline grid、marginal VAF clusters 與 multi-locus local trees 只提供少部分 {{m: Z_0=0}} proposal seeds。所有 data-derived seeds 必須來自可計算密度 {{m: q_z(Θ)}} 的 stochastic proposal，initial importance weight 取 {{m: P(Θ∣Z_0=z)/q_z(Θ)}}；若混合 prior 與多個 proposals，分母使用完整 mixture density。 deterministic optimizer seed 必須以已知密度 jitter，否則只能作不承擔 evidence weight 的診斷起點。
  4. annealed target。production v1 固定使用 annealed sequential Monte Carlo： {{m: P_t(Θ)∝P(Θ)P(D∣Θ)^{β_t}}}，{{m: β_0=0}}、{{m: β_T=1}}。 兩個 {{m: Z_0}} components 各自選擇 tempering schedule 與 systematic resampling，並估計 component evidence； 最後以 {{m: P(Z_0=z∣D)∝P(Z_0=z)P(D∣Z_0=z)}} 合併。下一個 {{m: β_t}} 自適應選至 predicted ESS 為 component particle 數的 0.8；actual ESS 低於 0.5 時 resampling。
  5. analytic marginalization。read origins 在 emission 的 {{m: \sum_o}} 中精確加總，不另抽樣 responsibilities； germline local phase states 與 atomic-bin merge indicators 在可行時用 forward-filter backward-sample 更新。
  6. continuous rejuvenation。production v1 更新 {{m: p,π,χ,b^{cat},λ_{CN},ω_W}}、 {{m: q=(β,u_s,σ_q)}} 與 {{m: (δ_u,μ_h,τ_h)}} 經 logit／simplex／positive transform 後 使用固定的 HMC kernel；full clone-specific-CN stage 才加入 {{m: b^{CN}}}。step size 與 mass matrix 只在 {{m: β_t<0.5}} 的 adaptation phase 更新，之後凍結。
  7. discrete rejuvenation。每個 fixed-{{m: Z_0}} component 內更新 {{m: G^N,H,B_s}}； compatibility mode 另更新 {{m: F,σ_b}}。{{m: R_m}} 與 mutation edge／lineage／timing 以 tree message-passing Gibbs 或 enumerated Metropolis update；CN histories 以 segment dynamic programming proposal 在 v1 僅聯合更新 trunk {{m: (N^{CN}_{e_0},H^{CN}_{e_0},C)}}；{{m: K,T}} 以 subtree-prune-regraft 與 clone split／merge proposals 更新，{{m: W_{e_0}}} 只作 trunk Bernoulli-compatible move。 full clone-specific-CN stage 才開放所有 edges 的 {{m: (N^{CN},H^{CN},C,W)}} 與符合 top-down WGD prior 的 reversible proposals。普通 {{m: Z_0}} toggle 不在 kernel contract 中；跨 component 質量由 evidence 合併。
  8. fixed versus sampled audit。每個 {{m: Θ_{v1}}} variable 必須對應上列 kernel； {{m: a,E,E^{SV},B_u}} 與 calibration hyperparameters 明列為 fixed。 完整 ascertainment stage 另加入 {{m: λ_m,M,S_m,d_m}} 的 conjugate／Metropolis updates，v1 不得更新這些量。
  9. mode extraction。最終 weighted particles 依 {{m: K,T,WGD}} 與 length-weighted major CN states 分群， phase labels 先依每個 component 的 anchor gauge canonicalize，再估計 mode mass；不得只保留最高 MAP mode 或以跨 mode posterior mean 取代。

production v1 固定 candidate atomic boundaries、使用已正規化的 {{m: K≤6}} truncated prior、copy number 上限為 8、 每條 root-to-leaf path 至多一次 WGD，且先以 clonal CN 與 clonal WGD 運行；此階段只有所有 tumour clones 共同繼承的 trunk edge 可承擔 CN events 或作 WGD candidate，off-trunk event counts 與 WGD indicators 固定為 0。 開放 clone-specific CN／subclonal WGD 後才加入 {{m: b^{CN}}} 並使用前述 top-down path prior。 觸及計算上限的 posterior mass 必須產生 STATE_CAP_REACHED，不得在邊界值截斷後仍回報 PASS。 full model 再開放 clone-specific CN 與 breakpoint birth／death proposals。

convergence contract

  • 至少四個 independent SMC runs 對 major mode masses 的 absolute difference 不超過 0.05， 且各 primary mode 內 {{m: p,κ,f}} 的 effective sample size 至少 200；
  • {{m: Z_0=0}} 與 {{m: Z_0=1}} 各自回報 initial quota、component ESS、evidence uncertainty 與 resampling ancestry；任一 component 的 effective particles 低於預先登錄下限時，不回報可靠的 no-tumour odds；
  • proposal kernels 的 acceptance、particle ancestry 與 terminal weight concentration 均寫入 diagnostics；
  • evaluation fold 的 fragment log predictive density 在相鄰兩次完整 run 間差異低於預先登錄閾值；
  • posterior predictive checks 同時涵蓋 depth、germline imbalance、single-site VAF、multi-locus state 與 SV support；
  • 任一 observation class 持續出現系統性 residual 時輸出 MODEL_MISFIT，即使 sampler 已收斂亦停止生物學解讀。

多位點資料的 eligibility report

模型啟動前不以固定的「至少幾個 multi-SNV units」門檻宣告可用， 而是產生 information inventory。必要欄位包括：

  • single-locus 與 multi-locus molecules 的互斥計數，以及每個 coverage mask 的數量；
  • 每個 phase-connected component 的 loci、units、independent molecules 與 Hamming-separated states；
  • 可能連到 truncal scale、互斥 branch covering set、post-gain 或 post-WGD timing 的候選 units；
  • copy-number-neutral、LOH、gain、amplification 與 excluded regions 內的單位數；
  • discovery、inference 與 evaluation folds 的 candidate retention、VAF、depth 與 context 分布；
  • base-error 與 whole-read artifact posterior，以及低頻 states 相對於 error floor 的距離。
  • E-shuffle strata 的 molecule-count distribution、singleton fraction、size 至少 2 的 strata 數、 實際可置換 molecules／somatic-locus pairs 比例、每個 seed 的實際 changed fraction 與 unique non-identity shuffles 數。

少量但連接不同 clone branches 或 WGD timing 的 units 可能排除完整 posterior mode； 大量集中於同一 mutation pair 的 molecules 則主要提高該 local state frequency 的精度。 獨立資訊量由 connected graph position 與 state contrast 決定，不由 raw read count 單獨決定。

simulation 必須交叉改變 cellular purity、ploidy、clone 數、clonal／subclonal WGD、 gain／loss timing、mutation burden、depth、read-length distribution、phase switch、mapping bias、TINC、 ONT／PacBio error profile 與 somatic ascertainment severity。至少另設四個 identifiability strata：

  • 存在與不存在可靠 truncal mutation；
  • {{m: p=0}} normal-only、近零 purity 與 pure tumour boundary；
  • chain、branch 與相同 marginal VAF 但不同 joint state；
  • pure diploid 對 observationally equivalent pure doubled genome、全數 pre-WGD、混合 pre/post-WGD 與 timing 不確定；

尚未解決的問題

  • full clone-specific CN 的可計算性。tree、copy lineage、segmentation 與 WGD 的聯合狀態空間極大； production v1 的 clonal-CN restriction 是否保留關鍵 joint-haplotype gain，須由 simulation 確認。
  • mutation discovery split 的效率。低 purity 下將 reads 分成三 folds 會降低 recall； cross-fitting 的 bias–variance trade-off 尚無實測。
  • copy-lineage equivalence。不同 event orders 可能產生相同 final CN 與 mutation multiplicity； 輸出需合併 observationally equivalent histories，而非回報任意一條。
  • genome-graph events。chromothripsis、ecDNA、templated insertions 與複雜 rearrangements 不一定可由 segmental gain／loss tree 表達。
  • normal-cell baseline。germline CNV、mosaic normal 或非二倍體正常細胞將破壞 normal CN=2 的預設。
  • continuous subclone spectrum。離散有限 clones 對某些 tumour evolution 並不合適； posterior predictive failure 必須優先於增加 {{m: K}}。
  • novelty 搜尋範圍。在使用「first」之前，仍須系統性涵蓋 HATCHet／HATCHet2、PhyloWGS、 PyClone、TITAN、cloneHD、BayClone2、WEAVER、JaBbA、SAVANA、Refphase 與 genome-graph mixture models。
