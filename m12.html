模組 12 · LongPhase-S: matched tumour–normal

LongPhase-S（配對 tumor–normal）

依序說明 GHIR、LCVF、purity 迴歸、purity-aware 過濾與最終 somatic haplotagging，並標示模型假設與限制。

約 80 分鐘建議先修：腫瘤混合體建議先修：評估建議先修：LongPhase

本模組學習目標

  • 畫出 LongPhase-S 的五個階段，並說明為什麼 purity 估計必須排在過濾之前
  • 解釋 GHIR 是什麼，以及它為什麼能反映 tumor purity
  • 說出四個 somatic variant filter 各自在偵測什麼樣的假陽性
  • 在 BAM 裡找到 somatic haplotype 的標籤，並知道 purity 被寫到哪裡

為什麼重要

這是 LongPhase-SLongPhase-S配對 tumor–normal 版本。做 tumor purity 估計、purity 感知的 somatic variant 過濾，以及 somatic haplotagging。The matched tumour–normal version: purity estimation, purity-aware somatic filtering, and somatic haplotagging.完整條目 → 的完整流程，也是 tumor–normal 分析支線的基礎。 後續的 somatic indel CNN 方法與 subclone 重建都會使用它的輸出。

為何 purity 估計先於過濾

回到 M8 的合成示例：purity 0.2（此處與 tumor DNA fraction 相等）、50× coverage，一個 clonal somatic 變異 只有約 5 條 read 支持。

若套用適合 purity 1.0 的嚴格門檻，真變異可能被當成雜訊而漏掉，recallrecall 召回率在指定評估範圍內，所有真陽性中被找出的比例：TP / (TP + FN)。若只對固定的 caller 候選集做後處理，recall 只能維持或下降，不能恢復 caller 從未輸出的真陽性；報告時應說清楚這個候選集範圍。Within a stated evaluation scope, the fraction of true positives that were found: TP / (TP + FN). With a fixed caller candidate set, post-filtering can preserve or lower recall but cannot recover variants the caller never emitted; report the candidate-set scope explicitly.完整條目 → 下降。 若一律放寬，高 purity 樣本的偽陽性則可能增加。

因此此流程先估計 purity，再依估計值調整過濾門檻。

GHIR：用失衡程度估計模型定義的 purity

Under the tutorial's illustrative definition, an ideal unbiased sample is near 0.5. It is not a direct purity measurement; somatic branches, LOH/CNV, TINC, phasing errors, mapping bias and sparse sampling can all shift it. LongPhase-S estimates purity from its distribution only after filtering and model calibration.完整條目 →（Germline Haplotype Imbalance Ratio）的基本原理如下：

  • 在理想且無系統性偏差的正常細胞裡，某個 germline 位點的 HP1 與 HP2 read 預期接近 50:50，GHIR ≈ 0.5
  • 若腫瘤細胞在 HP2 上發生 somatic 突變，部分 read 會被分到 HP2-1， 因此不再計入原本 HP2 分支的比例
  • 在其他條件相近時，tumor DNA fraction（此模型中的 purity）越高，失衡訊號通常越明顯

可量化這個分布的位置（例如取中位數與四分位距）， 再以驗證資料建立「分布特徵 → 模型定義的 purity」的迴歸關係，估計樣本的 purity。

實際分布與 LCVF

真實資料的 GHIR 分布可能受到低信心位點干擾。因此 LongPhase-S 設計了 LCVF（Low-Confidence Variant Filtering），以四個條件過濾：

Filter排除什麼
Germline Haplotype Imbalance在 normal 樣本裡就已經失衡的位點（多半是 CNVcopy number 拷貝數某段基因體在細胞內的拷貝數。多數正常常染色體區段為 2，可再分為 major 與 minor allele copy number。How many copies of a genomic segment a cell carries; a typical diploid autosomal segment has two. It can be split into major- and minor-allele copy numbers.完整條目 → 造成）
Germline Haplotype Read Ratio大量 read 沒被分配到任何 haplotype 的位點（例如大片段 deletion）
Read Count（static）read 數太少的位點 —— 分母太小，GHIR 會亂跳
Read Count（dynamic）用 bimodal valley thresholding 自動找雙峰之間的谷點當門檻

最後一項不是固定單一數字，而是依資料分布形狀決定門檻 —— 先高斯平滑、找兩個主峰，再取中間的谷點。此作法可降低對固定門檻的依賴；穩健性仍需由驗證資料評估。

四個 somatic variant filter

purity 估好之後，用它動態調整門檻，跑四個過濾器：

Filter偽陽性訊號判斷依據
TINC可能是 germline，或 normal 含有腫瘤污染檢查該位點在 normal 樣本的 VAFVAF 變異等位基因頻率在某個位點上，支持 alt allele 的 read 佔全部 read 的比例。VAF 不等於帶有這個突變的細胞比例。Variant Allele Frequency: the fraction of reads supporting the alternate allele. Not the same as the fraction of cells carrying it.完整條目 →；較高時增加 germline/TINC 疑慮
Read-level比對或 read 證據混亂造成的可疑訊號帶變異的 read 若同時帶有 HP1 與 HP2 的 germline allele → 提高疑慮
Haplotype origin同一問題的整體統計支持 read 若多來自同一條 germline haplotype，則增加來源一致性的支持
Variant cluster密集 read pattern 造成的可疑訊號檢查變異是否集中於同一群 read；以 z-score 識別異常模式，仍需配合其他證據

這四個 filter 都檢查haplotype 來源的一致性或 read pattern 的異常， 但各自的指標與閾值不同，應合併判讀。

HP3 的後續指派

重建 somatic haplotype 時，未涵蓋 germline 錨點的 read 會先標為 HP3。之後再依其攜帶的 somatic 變異證據，嘗試指派到對應的 somatic haplotype （見 M6 的下半部示意）。

並非所有 HP3 都能完成指派。如果某個 somatic 變異的支持 read 同時來自兩條 germline haplotype，來源證據互相衝突，則保留為不可指派。

使用 IGV 驗證輸出

本模組術語

Clair3
以深度學習做 germline variant calling 的工具，長 read 上常用。
ClairS
配對 tumor–normal 的 somatic variant caller。tumor-only 版本叫 ClairS-TO。
GHIR（生殖系單倍型失衡比）
Germline Haplotype Imbalance Ratio：在已分到 HP1／HP2 的 germline 位點上，量化兩個 haplotype 分支的 read 比例；在本教材的示意定義中，理想且無偏差時接近 0.5。它不是直接的 purity 讀數：somatic mutation branch、LOH/CNV、TINC、錯誤 phasing、mapping bias 與抽樣不足都可能造成偏移。LongPhase-S 需在過濾與模型假設下，利用其分布估計 purity。
LOH（異型合子性喪失）
原本 heterozygous 的區域變成只剩一種 allele。LOH 不等於缺失 —— 也可能是一條 haplotype 遺失後另一條被複製（copy-neutral LOH）。
LongPhase-S
配對 tumor–normal 版本。做 tumor purity 估計、purity 感知的 somatic variant 過濾，以及 somatic haplotagging。
TINC（腫瘤污染正常樣本）
Tumour-in-normal contamination：配對正常樣本含有腫瘤來源訊號，使 genuine somatic 變異也可能在 normal 中被觀察到，因而可能被錯誤過濾。
VAF（變異等位基因頻率）
在某個位點上，支持 alt allele 的 read 佔全部 read 的比例。VAF 不等於帶有這個突變的細胞比例。
basecalling（鹼基判讀）
把定序儀的原始訊號（ONT 是電流）轉成 A/C/G/T 字母的步驟。不同 basecaller 版本會產生不同的錯誤特性 —— 所以「同一個細胞株、不同 basecaller」是兩份不同的資料集。
copy number（拷貝數）
某段基因體在細胞內的拷貝數。多數正常常染色體區段為 2，可再分為 major 與 minor allele copy number。
phasing（定相）
為可判定的 variants 建立其位於不同實體染色體拷貝上的相位關係；VCF 常以 0|1 等形式表示。長 read 可提供跨位點的分子層級觀測證據。
recall（召回率）
在指定評估範圍內，所有真陽性中被找出的比例：TP / (TP + FN)。若只對固定的 caller 候選集做後處理，recall 只能維持或下降，不能恢復 caller 從未輸出的真陽性；報告時應說清楚這個候選集範圍。
somatic haplotagging
把帶有 somatic 突變的 read 指派到它們源自的 germline haplotype。這是 LongPhase-S 的核心產出。
tumour purity（腫瘤純度）
樣本中腫瘤細胞所佔的比例。purity 越低，somatic 訊號被正常細胞稀釋得越嚴重，偵測越困難。
